# 格式规范知识图谱

> 本文档是项目所有文件格式的**唯一真相源**。
> 任何模板修改或代码逻辑修改，必须同步更新本文档。

## 一、章节范围格式

- **首选格式**：`第X章 - 第Y章`（AI 生成时使用）
- **兼容格式**：`X-Y`（纯数字，解析器也支持）
- **不允许**：其他变体

## 二、卷名格式

- **格式**：`**卷名**：《卷名》`
- **解析器**：提取 `《》` 内文字作为卷名

## 三、分卷大纲字段

| 字段 | 格式 | 说明 |
|------|------|------|
| 卷名 | `《卷名》` | 书名号包裹 |
| 章节范围 | `第N章 - 第M章` | 起止章号 |
| 核心冲突 | 自由文本 | 本卷核心矛盾 |
| 主要事件 | 自由文本 | 事件列表 |
| 人物弧光 | 自由文本 | 角色成长线 |
| 本卷字数 | 数字 | 预估字数 |
| 本卷高潮 | 自由文本 | 高潮描述 |
| 结尾过渡 | 自由文本 | 过渡描述 |

## 四、章节分配表格

| 列名 | 说明 |
|------|------|
| 章号 | 数字 |
| 核心冲突 | 一句话描述 |

## 五、Frontmatter 字段

| 字段 | 值域 | 说明 |
|------|------|------|
| title | 自由文本 | 章节标题 |

| status | 待写/草稿/已完稿/需修改 | 章节状态 |
| tags | 字符串数组 | 标签 |
