## 衔接冲突自查（生成前内部执行·禁止把自查过程写进正文）
【为什么需要自查】上方"前一章结尾实际文本"与"当前章节大纲首段"来源不同，可能存在矛盾（前章正文有时会把剧情写得超出原大纲预期，导致本章大纲首段所设定的人物状态已经过期）。开始撰写前必须在内部完成以下核对：
1. 【空间一致性】大纲首段把人物放在哪？前章实际结尾人物已经身处何地？两者是否同一空间或合理可达？是否让人物回到了已经离开的场景？
2. 【动作一致性】大纲首段让人物在做什么？前章结尾人物刚刚完成了什么？是否存在重做、回退或撤销已完成动作的情况？
3. 【时刻一致性】大纲首段的时刻是否严格晚于前章结尾时刻？严禁倒流或与前章并行。
4. 【在场人物一致性】前章结尾已离场/已分别/已下车的角色，本章首段是否莫名又出现在主角身边？

【冲突修复规则·按 A→D 顺序适用，命中即执行】
A. 完全不矛盾 → 直接按大纲首段推进，无需调整
B. 仅是时间紧邻差异（人物已到目的地但大纲首段仍设在到达过程） → 用一句过渡承接快速翻篇（如"刚下车没多久"、"几步路之后"），让大纲首段在新位置自然成立
C. 存在空间倒退/动作回滚/时刻倒流（例：前章已下车步行至小区，大纲首段却让人物坐在车上经过更早的关卡） → 必须使用时间跳跃桥接（如"次日清晨"、"几小时后"、"待安顿好再次出门时"），让人物从前章实际结尾状态自然过渡到大纲首段所要求的状态；大纲剧情点仍需在本章后续段落完整落实，不得删减
D. 地理硬冲突且无法用跳跃桥接（例：大纲首段要求人物身处前章已离开且不可能再回到的场景） → 以"前一章结尾实际文本"为最高锚点，重写首段开篇方位，将大纲首段所设定的事件合理后挪或重定位到主角下一次途经该场景时；本章其余大纲剧情点仍需逐一落实

【硬性约束】
- 必有取舍：严禁同时保留"前章结尾状态"和"与之矛盾的大纲首段动作"，那会写出空间倒退/动作回滚的硬伤
- 自查只在内部执行：禁止把规则字母（A/B/C/D）、自查过程、冲突结论以任何形式写入正文
- 大纲剧情点不得因为自查而被丢弃：即使采用 C/D 规则跳跃/重定位，大纲中的关键事件、关键对话、写作要点仍要在本章后续段落完整落实

【与上方写作要求 #1「不得遗漏、不得跳过」的边界声明】
- 自查命中 C 时：仅允许调整本章【章首衔接段落】（开篇位置/时间桥接/到达过程描写）；大纲中的事件链、关键对话、写作要点、章末走向必须 100% 在本章后续段落完整落实，不视作"遗漏"
- 自查命中 D 时：仅允许把章首发生地从"已不可能回去的场景"重定位到"主角下一次途经该场景时"；事件本身、关键对话、写作要点的内容/因果/结果不得删减或改写
- 任何情况下都不得借"为衔接连贯"、"避免冲突"为由删减或合并大纲事件点；大纲点 = 本章必须落实的剧情骨架，仅章首衔接是允许微调的过渡
