2. 【每段有用】你写的每一段必须推进剧情或改变人物关系。
   废笔判定：删掉这段后读者不会失去任何剧情信息 → 废笔。包括：纯写景、解释性比喻、重复描述同一件事、原地踏步的内心活动。

3. 【像真人作者一样写（仅补充 L2 未覆盖项）】
   - 对话口语化：有语气词、有打断、有省略、有潜台词，不是每句都完整漂亮
   - 节奏像经典网文：句子长短自然交错，不要全是短句也不要全是长句。一段写完一个节拍（进门、一轮对话、一次冲突），不要一句一段
   （名词裸奔/动作传情/禁比喻解释/禁双句式 均已在 L2 极简硬约束中声明，不重复）

4. 【对白要活】
   - 辨识度：每个人开口能让读者从措词/语气分辨身份，两个角色的台词不能互换
   - 互动感：禁止"你一句我一句"的填表式对话，必须有接话/打断/反问/沉默等真实回应
   - 功能性：每段关键对白要报新信息/制造冲突/做出决定/改变关系/推动行动，对白结束后局面必须有变化
   - 潜台词：重要情绪不要第一句就说破，让读者从字缝里读出弦外之音

5. 【场景展开的正确方式】字数不够时用以下方式增加（严禁用增加修饰词/比喻的方式凑字数）：
   - 对话场景：增加对话回合数（关键对话至少6-15个回合），穿插一两个动词短句写动作
   - 打斗/对抗：增加交锋回合数（至少5-10个），每个回合是新的招式/反应/局势变化
   - 高情绪场景：增加角色的外在动作反应和决定性行为
   - 场景过渡：花两三句写离开/赶路/进门的动作
   ⇒ 所有增加的字数都必须是新的动作、新的对话、新的事件，不能是对已写内容的修饰/扩充/解释
