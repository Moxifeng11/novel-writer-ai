## ⚠️ 输出前·最终四维自检（必须在内部完成，禁止写入正文）
完善后的章节内容生成完成后、正式输出紧凑行（C|/R|/L|/G|/P|/CF|/M|/EL|/T| 等）之前，请在内部按下表逐项核对，任一项不达标必须自我修订后再输出：

### 一、逻辑性自检（完善后的内容是否合规）
1. 完善后的摘要是否与本章【现有摘要 P1】所设定的核心事件保持一致？未发生"被完善后核心事件偏移"？
2. 章内角色行为是否符合上文【主要角色】中其性格内核、当前境界、所属势力的设定？
3. 力量使用/突破描写是否遵守【力量体系】的境界递进与修炼路径，未出现"无修无突破直接施展高阶能力"？
4. 出场场景与移动是否遵循【地理地图】的层级（地点→城市→区域→大陆），未出现地理跳跃？

### 二、故事性自检（完善是否真的"加强了"叙事）
1. 完善后是否保留并强化了本章原有的钩子/悬念/转折，而非把它们冲淡或替换？
2. **悬念浓度检查**：本章摘要中是否至少存在1个"本章提出但未回答的问题"？如果所有信息都在本章交代完毕，则不达标
3. **信息留白检查**：是否有至少1个角色的动机/1个事件的原因在本章未完全揭示？如果所有角色行为都被解释清楚，则像论文
4. 章尾悬念是否满足"三要素"（具体画面+信息缺口+情绪冲击）？是否像论文总结（"他意识到事情很复杂"式废话）？
5. 关键情绪与节奏（紧张/缓冲/爆发）是否与前后章衔接自然，未制造"突兀的情绪断层"？
6. 整体叙事是否像"在讲一个故事"而非"在汇报一串事件"？是否有至少一处让读者想知道"然后呢？为什么？"的钩子？

### 三、协调性自检（与全书脉络是否对齐）
1. 完善后涉及的角色姓名是否与【主要角色】完全一致，未把已设定主角/女主替换为新名字？
2. 章内 CF 伏笔标记是否与【已设定伏笔】的"埋设→暗示→呼应→回收"链路一致，解密程度是否符合该章所处节点？
3. 势力立场、阵营关系是否与前序章节、上文【主要势力】一致，未出现"立场无过渡反转"？
4. T 行时间范围是否符合【批次内链式约束】：本章起始日期 ≥ 前一章结束日期；若发生跳跃，本章摘要必须出现"次日/数日后/闭关 X 月/赶路 Y 日"等显式关键词？

### 四、因果关系自检（完善后是否首尾可溯）
1. 完善后本章每个关键事件的"起因"是否可在【现有摘要】【前章上下文】或【已设定伏笔】中找到对应触发点，避免"无因之果"？
2. 完善后本章产生的"后果/状态变化"是否给后章留下接口（开放未决冲突 / 角色状态变化 / 伏笔暗示），避免"无果之因"？
3. 章内若引入新角色/新道具/新势力，是否能溯源到一个合理的出现契机，未出现"凭空冒出"？
4. EL 事件线是否能用 30 字内清晰描述"起因→冲突→结果"的因果链路，且与本章 CF 伏笔变化呼应？

### 自检结果处理规则
- 任一项不达标 → 在内部静默修订对应紧凑行（摘要/CF/EL/T 等）后再输出
- 严禁把"自检过程""不达标项""修订思路"等任何核对痕迹写入任何紧凑行字段
- 严禁输出"经检查无问题""自检通过""已自检"等元描述
- 自检要求与上文【P0 用户额外要求】冲突时，以 P0 用户要求为准（仅限冲突项）
