> 另外两个项目不能动」。全程只读 GET，未触发任何生成或写入。

## 一、提示词资产库（核心）

**云笔最值得拿的东西。** 它把正文生成拆成 32 个可开关模块：

| 模式 | 模块数 | 合计 tokens |
| --- | ---: | ---: |
| 普通 | 30 | **23250** |
| 专注 | 7 | 3750 |

专注模式强制保留「衔接三件套 + 动笔提醒」——**文采可省，衔接不能省**。

**最有价值的 5 个模块**：

| 模块 | tokens | 价值 |
| --- | ---: | --- |
| 叙事铁律（1-9） | 3000 | 10 条铁律全文，每条对应一个具体 AI 病灶 |
| 文笔技法（四层） | 2000 | 骨架/调色/构图/风格四层工具箱 |
| 优先级体系（L0-L3） | 400 | 规则冲突时的仲裁依据 |
| 协议行输出 | 1500 | CR/CI/NE/BT，省一次 distill LLM 调用 |
| 动笔前提醒 | 300 | 「默念三遍」+ 否定对比禁令，放 prompt 末尾 |

详见 [`prompts/README.md`](./prompts/README.md)。

## 二、数据契约

**核心洞察**：章节大纲不是笔记，是 **36 字段的施工图**。

包含：
- 36 字段章节蓝图（TS 接口，含摘要固定格式）
- 11 步探讨模式 schema（含依赖链：情节脉络依赖前 9 步全部）
- 协议行 CR/CI/NE/BT 字段约定 + 解析函数
- 时间线整数排序编码（`公元纪年-2-4-15` → `10002041500`）

**9 条可直接抄的设计原则**详见 [`contracts.md`](./contracts.md) §三。

## 三、前端设计规范

| 发现 | 说明 |

| 33 个抽屉面板 | 一切编辑在右侧抽屉完成，不跳页 |
| 六档宽度语义 | 560 管理 / 520 主数据 / 480 辅助 / 450 只读 / 420 编辑 / 380 轻详情 / 320 助手 |

## 复刻边界（必须说清）

### ✅ 可以复刻

- 所有字符串常量（提示词、UI 文案、配置表）
- 数据结构与 API 契约
- 逻辑流程（读压缩代码的语义）
- 设计决策（宽度档位、四态、文案策略）

### ❌ 不能复刻

| 内容 | 原因 |
| --- | --- |
| Vue 组件源码 | bundle 是 webpack 压缩产物，变量名 `Te`/`ue`/`Ve` 大量重名，结构信息已丢失 |
| 后端业务逻辑 | 服务端执行（蒸馏调度、状态机、事务），前端只发请求收结果 |
| 数据库表结构 | 只能从 API 响应形状反推，看不到 DDL |
| Few-shot 示例原文 | 70KB prompt 里的大段示例故事未逐字提取 |
| 密钥与计费 | 后端管理 |

**能复刻的是设计，不是代码。**

## 与本仓的交叉验证（重要）

抄云笔提示词时**必须对照实测数据**，它的数值型约束有几处是错的：

| 云笔规定 | 实测（139 段真人网文） | 处置 |
| --- | --- | --- |
| 铁律 9：长句 ≥36 字占 10–20% | ≥35 字占 **39.13%**（P25 26.98） | ❌ 改为 ≥25% |
| 省略号禁止 | 中位 **2.38/千字**，真人在用 | ❌ 不禁 |
| 对话 ≥50% | 引号 18.53/千字，非 50% | ❌ 不采用该数值 |
| 口语词要多 | 1.17/千字，很克制 | 本仓 1.44 已达标 |

依据：`docs/audits/2026-11-25-zhuque-criteria-correction.md`

**云笔自己的产物也过不了朱雀**：项目 6153 全 10 章 softmax 0.9999。
它的价值在「人读着像人写」的技法设计，不在「过检测」。
