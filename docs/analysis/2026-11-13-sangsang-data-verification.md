# 桑桑那条数据核对结论（阶段 D 收尾）

## 核对对象

评测中真实基线出现的 1 条：

```
第5章「桑桑」11 岁，到第6章反而变成 8 岁——年龄不可能倒退。
```

## 核对结果：**抽取噪声，不是矛盾**

查原始数据（`knowledge-batch.json`）：

| 章 | 谓词 | 值 | 原文引文 |
|---|---|---|---|
| 第5章 | 年龄 | 将将十一二岁 | 「不像是个出身凄苦将将十一二岁的小侍女」 |
| 第6章 | **被提亲起始年龄** | 八岁 | 「桑桑**才八岁的时候**你就开始提亲」 |

第 6 章是**回溯叙述**（"她八岁的时候发生过某事"），不是"她现在八岁"。
LLM 如实抽取成了 `被提亲起始年龄`，**抽取本身没错**；错的是我的 R1 规则把它当成当前年龄参与比对。

## 修正

谓词匹配从「包含」改为「**前缀锚定**」：

```ts
const AGE_PREDICATE_PREFIXES = ['年龄', '年纪', '岁数'];
a.predicate.startsWith(prefix)   // 而不是 includes
```

效果：

| 谓词 | 是否参与当前年龄比对 |
|---|---|
| 年龄 / 年龄约 / 年纪 / 岁数 | ✅ 参与 |
| 被提亲起始年龄 | ❌ 排除（回溯） |
| 请求远嫁时年龄 | ❌ 排除（回溯） |
| 入初境年龄 | ❌ 排除（回溯） |

## 修正后的评测结果

| 指标 | 值 |
|---|---|
| **真实数据误报** | **0 / 456 条** |
| 当前年龄类注入召回 | **2 / 2 = 100%**（李渔 16→13、桑桑 11→8） |
| 回溯类注入 | 2 处（四公主/柳白）——**按新规则正确排除**，不参与比对 |
| 合法变化误报 | **0 / 10** |

> 上一轮报的 "4/4" 里，四公主（请求远嫁时年龄）与柳白（入初境年龄）
> 本就是回溯限定谓词，把它们当成当前年龄才是错的。修正后是 2/2，更准确而非退步。

## 教训

**"含关键词"是一种偷懒的匹配。** 中文谓词里限定词动辄前置于核心名词
（被提亲起始年龄 / 请求远嫁时年龄 / 入初境年龄），包含匹配会把它们全部吞进来。
锚定前缀才是对的语义边界。
