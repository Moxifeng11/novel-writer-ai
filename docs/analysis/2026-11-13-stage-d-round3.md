# 阶段 D 第三轮：R1 修复后评测

## 修复

R1 年龄规则原要求谓词**恰好等于**「年龄」，而 LLM 实际产出「年龄约」「年纪」等变体
→ 整类事实被过滤掉（长篇评测中四公主 13→10、柳白 6→3 漏报即由此而来）。

修法：改为**包含匹配**（`年龄` 或 `年纪`）。

## 结果（同一注入集）

| 指标 | 修复前 | 修复后 |
|---|---|---|
| 注入矛盾召回 | 1/3 有效 | **4/4 = 100%** |
| 合法变化误报 | 0/10 | **0/10** |
| 真实基线误报 | 0/456 | **1/456** |

### 召回 100% 是可核对的

```
✓ 四公主：第35章注入 10（原值 13）
✓ 桑桑：第36章注入 8（原值 11）
✓ 李渔：第37章注入 13（原值 16）
✓ 柳白：第38章注入 3（原值 6）
```

注入器也加了自检：只注入原值 > 3 的主体，并断言 `regressed < original`，
避免上一轮「0→1 其实是增长」的无效注入。

### 真实基线出现 1 条，需要人工核对

```
第5章「桑桑」11 岁，到第6章反而变成 8 岁——年龄不可能倒退。
```

这可能是：
1. **抽取噪声**：正文里「八岁」指的是别的事物（如某物八年前），被错误归到桑桑年龄；
2. **或真实矛盾**（原著笔误）。

**在核对原文之前，不把它算作真矛盾，也不算作误报**——这是待确认项。

## 规模效应（合成放大，非真实数据）

| 跨度 | 事实 | 误报 |
|---|---|---|
| 30 章 | 456 | 1 |
| 60 章 | 912 | 7 |
| 100 章 | 1521 | 34 |

随复制层数上升。原因可能是复制后同主体年龄事实变多、抽取噪声也被放大；
**需真实 60/100 章数据复测才能定性**（约 ¥2–4 LLM 成本）。

## 阶段 D 结论

| 项 | 值 |
|---|---|
| 真实数据误报 | 0–1 / 456（1 条待核对） |
| 注入矛盾召回 | **4/4 = 100%** |
| 合法变化误报 | **0/10** |

框架可用、等级序正确、R1 修好；规模效应与那条待核对项留作后续。
