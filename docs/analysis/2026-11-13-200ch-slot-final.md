## 三处改造的效果

### ① slot 子维度

- 唯一 slot 数 **2396**（3258 条事实）
- 样例：「当前年份」「地理位置」「城防规则」「职务身份」「对贵人身份的认知」「当前年龄」
- R1 按 (主体, slot) 分组、R2 按 (主体, slot, 章节) 分组
- **修复**：「十三岁开悟」vs「三十岁才进不惑」不再被判不相容

### ② 归属约束

prompt 新增：只抽关于 subject 本人的事实；对别人说的话、成语/比喻、他人情况不抽。
**修复**：「你虽然才不惑…」不再被归成宁缺 40 岁。

### ③ 注入器修正

只取精确值 + 当前状态的事实作为注入源。
**修复**：召回从「2/10 假低值」变为「10/10 真实 100%」。

## 完整演化（同一份 200 章真实数据）

| 阶段 | 误报 | 召回 | 关键改动 |
|---|---|---|---|
| 自由谓词（100 章） | 0 | 7/7 | 基线 |
| 规范谓词（100 章） | 427 → 21 | 9/10 | 压成枚举，丢了区分度 |
| + event 事件锚（100 章） | 0 | 8/8 | 补回事件维度 |
| 规范谓词（200 章） | 3 | — | 规模上升暴露新问题 |
| + 精确值守卫 | 2 | — | 边界值不可比 |
| **+ slot 子维度** | **0** | **10/10** | 补回侧面维度 |

**规律很清楚：每一次"压成枚举"都会丢一个维度，必须把那个维度显式补回来。**
谓词→丢事件 → 加 event；谓词→丢侧面 → 加 slot。
