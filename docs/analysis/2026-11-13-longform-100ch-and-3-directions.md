## 三、评测中发现并修复的两个真实缺陷

### ① 引文回溯（本轮新增）

谓词写成「年龄」，但引文是「我**那年才**四岁」——只看谓词会误报。
新增 `isRetrospectiveQuote(quote)`，回溯引文不参与当前年龄比对。

### ② 0 岁解析噪声

「十五六岁年龄便杀过很多人」被 LLM 给了 `numeric: 0`，
产生「15 岁 → 0 岁」的假矛盾。规则层排除 `numericValue <= 0`。

修复后：真实数据误报 **4 → 0**。

## 五、结论

**关键词匹配确实是 bug 温床，但可被系统性收敛**：

1. 统一谓词匹配器（前缀锚定 + 别名表 + 回溯限定排除）
2. 引文层也要判回溯（谓词中性但句子说过去）
3. 数值噪声（0 岁）要有守卫

三层都加上后，真实 100 章 1576 条事实 **零误报**。
