# event 事件锚对照评测（2026-11-13）

## 对照三组（同 100 章真实数据）

| 组 | prompt 形态 | 事实数 | 真实误报 | 有效召回 | 成本 |
|---|---|---|---|---|---|
| A 旧 | 自由谓词 | 1576 | 0 | 7/7 | ¥1.03 |
| B 新 | 规范谓词 + isCurrentState | 1656 | 427 → 21 | 9/10 | ¥1.11 |
| **C 新+event** | 规范谓词 + isCurrentState + **事件锚** | **1622** | **0** | **8/8 = 100%** | ¥1.25 |

## C 组结果（最终）

```
真实数据：1622 条事实 / 99 章
真实数据误报：0 条
注入矛盾：10 处 → 检出 8 处
合法变化误报：0 / 10
```

## event 字段质量

| 指标 | 值 |
|---|---|
| 覆盖 | **1622 / 1622 = 100%** |
| timeline 唯一事件数 | 113 / 138 条（同一事件可有多条事实） |
| 样例 | 渭城春雨 / 贵人过渭城 / 马士襄推荐宁缺 |

事件锚是**有意义的名词短语**，不是主体名重复——正是 R5 需要的分组键。

## 关键教训：B 组 427 条误报的完整因果链

```
规范谓词 → 时间类全归一为「时间」
        → R5 按 (主体,谓词) 分组 → 同一主体的不同事件混在一起比
        → 427 条假矛盾
加 event 事件锚 → R5 按事件分组 → 0 条
```

**规范化不是免费的**：把自由文本压成枚举会丢掉"天然区分度"，
必须同时补上被丢掉的维度（事件身份），否则规则层失去分组依据。

## 结论

| 判断 | 结论 |
|---|---|
| 规范谓词是否可用 | ✅ 可以——**前提是配 event 事件锚** |
| 是否优于旧 prompt | ✅ 是（0 误报 + 100% 有效召回 + 谓词可枚举 + 回溯显式标记） |
| 是否可替换线上 | ✅ 可以 |
| 成本变化 | ¥1.03 → ¥1.25（+21%，多出的 event 字段） |

## 新增测试

- event 贯穿：prompt 要求、解析保留、缺省兜底（主体·谓词）
- R5 按事件分组：同主体不同事件不报、同事件不相容仍报、缺 event 回退主体
