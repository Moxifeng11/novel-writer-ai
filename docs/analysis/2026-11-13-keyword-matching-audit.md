## 二、两种失效模式（都真实发生过）

### 模式 A：严格等值 → 整类漏报

```ts
a.predicate === '年龄'      // LLM 给的是「年龄约」「年纪」→ 全部漏掉
```

《将夜》评测中四公主（13→10）、柳白（6→3）漏报即此因。

### 模式 B：包含匹配 → 回溯语义假矛盾

```ts
a.predicate.includes('年龄')  // 「被提亲起始年龄」也被纳入 → 报 11岁→8岁 假矛盾
```

《将夜》第 6 章原文「桑桑才八岁的时候你就开始提亲」是回溯叙述，
被 LLM 如实抽成「被提亲起始年龄=八岁」，包含匹配把它当当前年龄。

## 三、统一方案：`engine/consistency/predicate-match.ts`

```ts
matchesPredicate(predicate, concept)   // 唯一推荐入口
```

两条规则：

1. **前缀锚定**（不是包含）：`年龄约` ✅ / `被提亲起始年龄` ❌
2. **别名表**：每个概念列全变体（年龄/年纪/岁数；位置/地点/所在；又名/化名/道号…）
3. **回溯限定词排除**：起始/初始/当年/当时/曾/之前/以前/从前/旧称/少时/幼时/儿时/年前/此前/原来

**坑**：回溯词不能放裸「时」「初」——会把「时间」「时刻」误杀（实测踩到，已加注释锁定）。

19 条测试锁住：4 类变体命中、4 类回溯排除、负例、宽松/严格模式差异。
