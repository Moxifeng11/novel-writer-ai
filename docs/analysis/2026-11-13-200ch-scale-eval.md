### 规模效应：误报确实出现了，但极小

100 章 0 条 → 200 章 3 条（3354 条事实的 0.089%）。
**不是指数恶化**，而是"事实量翻倍、噪声累积"的自然结果。

## 三条误报的根因（各不相同）

### ① 边界值 vs 精确值 —— 已修

```
第170章「宁缺」20 岁（原文「未满二十不惑」）
第184章「宁缺」18 岁（原文「我已经十八了」）
→ 判「20 岁 → 18 岁 倒退」
```

**「未满二十」是上界，与「十八」完全相容。** R1 只看 numericValue 就误判。
修法：新增 `isExactNumericValue`（未满/不到/将近/约/左右…），R1/R2 只比精确值。

### ② 抽取归属错误 —— 数据问题

```
第176章「宁缺」40 岁（原文「你虽然才不惑，但本命物总应该有些想法？」）
```

这句是对**六师兄**说的，被错误归到宁缺。属抽取归属错误，需在拆解层加"说话对象"维度。

### ③ 同一事件内的不同里程碑 —— 需要新维度

```
第128章「大师兄」13 岁（十三岁开悟）vs 30 岁（三十岁才进不惑）
→ 同章同谓语被判不相容
```

这是**同一主体的两个不同侧面**（开悟年龄 / 入不惑年龄），
与「宁缺入楼十七日 vs 苦求十余年」同源：**缺少"子维度"（slot）**。
event 锚帮不上（它们本就同一事件）。

## 结论与下一步

| 判断 | 结论 |
|---|---|
| 200 章是否仍可用 | ✅ 可用（误报率 0.06%） |
| 误报是否随规模恶化 | 轻微上升（0 → 3 → 修后 2），非指数 |
| 是否可接受 | 是：3354 条事实里 2 条需人工判读 |
| 召回数字 | **不可信**：注入器取"最早一条"事实，可能取到边界值被新守卫正确排除，需修注入器才能给召回 |

### 下一步（结构化，不是打补丁）

1. 拆解新增 `slot` 子维度（同一主体的不同侧面：开悟年龄 / 入境界年龄 / 当前年龄）
2. 拆解新增"说话对象"（修复归属错误）
3. 修注入器（只取精确值事实作为注入源）后再报召回
