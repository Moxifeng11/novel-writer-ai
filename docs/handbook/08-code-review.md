# 08 · 代码评审清单

> 评审结论只有三种：通过 / 需修改 / 阻塞（数据或安全风险）。
> 评论必须给出「文件:行 + 为什么 + 建议」，不要只说「优化一下」。

---

## 1. 数据与写入（最高优先级）

- [ ] 正文是否只经 `engine/body-writer.ts` 写入？
- [ ] 同一路径的读-改-写是否在同一 `withWriteLock` 内（快照与写入不分离）？
- [ ] 覆盖用户内容前是否有备份/版本？
- [ ] 重复执行是否幂等（章名/内容哈希/结构化键去重）？
- [ ] 失败是否可回滚（journal / `hasPartialFailure` / 清理新文件）？
- [ ] 是否避免用 `vault.adapter.write` 写索引内 `.md`（除明确隐藏目录/data 目录并注明理由）？

## 2. 并发与生命周期

- [ ] 新增长任务是否有取消/超时？取消后 UI 是否恢复？
- [ ] 定时器、Worker、子进程、事件监听是否在 `dispose()` 中释放？
- [ ] `running` 守卫是否会导致可重试错误被短路？
- [ ] `Map`/缓存是否按项目/章节隔离，避免跨项目污染？

## 3. 错误可见性

- [ ] 用户操作型 `catch` 是否有 `Notice`/`showError`/`setAiStatus`？
- [ ] 是否存在空 catch、只 `console.log`、或 `void promise` 无 catch？
- [ ] 错误信息是否包含可操作线索（路径/字段/下一步）且不泄露密钥？
- [ ] 失败后是否恢复了按钮/输入框/进度条状态？

## 4. 分层与注册

- [ ] import 方向是否符合 `check:deps`（ui → engine/services/shared/core；engine → services/shared/core；services → shared/core；shared 只依赖自身）？
- [ ] 新增 Engine/Service/Store 是否通过 `EngineRegistry` 注册或已白名单登记？
- [ ] token 是否来自 `shared/engine-names.ts`，没有裸字符串？
- [ ] 是否把类型下沉到 `shared/` 而不是让两层互相 import？

## 5. 设置与迁移

- [ ] 新设置是否同时改接口、默认值、迁移？
- [ ] 迁移是否幂等、是否保留用户旧值？
- [ ] 密钥字段是否加密/脱敏，输入框不回填密文？
- [ ] 删除/重命名字段是否处理旧数据？

## 6. 性能

- [ ] 热路径是否避免 `getFiles()` 全库扫描（`check:hotpaths`）？
- [ ] 是否按目录/索引精确读取？
- [ ] 是否有不必要的全量重渲染/重复计算？
- [ ] 大对象是否避免进入日志/账本？

## 7. 兼容与契约

- [ ] 公开面（命令/事件/frontmatter/设置键/路径）是否只增不改？
- [ ] 破坏性变更是否有 `@deprecated` + 迁移说明 + 版本说明？
- [ ] 是否更新 `docs/regression/LINKED-SCENARIOS.md` 的锚点？

## 8. 测试

- [ ] 是否有覆盖失败/边界/并发的用例？
- [ ] 测试是否断言行为而不是私有实现？
- [ ] 是否有永久为真的占位测试或 `describe.skip` 留尸？
- [ ] 覆盖率是否不低于阈值？

## 9. 注释与文档

- [ ] 新文件是否有四段式文件头？
- [ ] 导出声明是否有 JSDoc（`@param`/`@returns`/`@throws`）？
- [ ] 事故修复是否写了「事故背景/不变量/回归路径」？
- [ ] 文档是否只改真相源，没有复制数字/门禁表？

## 10. 安全

- [ ] 是否有密钥/Token/真实路径进入日志或仓库？
- [ ] 子进程/命令执行是否走窄接口并做平台守卫？
- [ ] 外部输入（文件名/项目名/模型输出）是否校验与转义（路径穿越、`$` 替换、HTML）？

---

## 评审意见示例

```text
[P1] engine/xxx.ts:123
问题：快照读取在 withWriteLock 之外，写入前可能被并发修改，回滚会写回过期值。
建议：把 snapshotField 与 processFrontmatter 放进同一个 withWriteLock。
```

- `P0`：数据损坏/安全/阻塞发布。
- `P1`：正确性/并发/静默失败。
- `P2`：可维护性/性能/文档。
