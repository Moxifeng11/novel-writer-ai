# v4.24 规则思路 × 正文模板组合实验

- 日期：2026-10-31
- 目的：新建「不同思路」的写作规则版本与正文提示词模板，用组合注入实测哪些注入内容真正影响人工特征。
- 结论先说（**已按重复采样修正**）：
  1. 单样本排名不可信：同一提示词重跑，rubric 可从 60 掉到 20；11 组单样本里看似清晰的因果（如「锚点规则把短叙述压到 0.27」）在 n=3 复测后落回噪声（基线自己就出现过 0.29）。
  2. n=3 复测：C0 基线均值 33、C4（场景节拍 + V3）**40（三次全是 40，最稳定）**、C9（真人特征 + V4 + 可数硬指标）均值 27（60 是离群值）。三组短叙述均值都在 0.39–0.40，对话 18–20%。
  3. **没有任何组合稳定跨过 rubric 的对话/口语/锚点三项**；对话占比仍由台词骨架决定。
  4. 朱雀：C9、C4 均判「未发现明显的人工创作特征」（额度 27→25）。

## 一、新增的版本（可切换、可归因）

### 1.1 写作规则（`shared/writing-rules-variants.ts`）

| 版本 | 思路 | 关键主张 |
|---|---|---|
| `3.7.0-anchor` 正向锚点 | 只给「怎么写」的正例 | 段落只留一条硬规则「自然段 2–6 句、80–220 字」；对话三成；句长 8–40 波动；写身体不写形容词 |
| `3.8.0-scene-beat` 场景节拍 | 一场戏 = 一次交换 | 目标/阻碍/交换/变化四格；入场 1–3 句落地、交锋 ≥6 来回、收束停在动作；叙述只写镜头能拍到的 |
| `3.9.0-voiceprint` 真人特征 | 只描述「真人文本长什么样」 | 八条可观察特征（短叙述 50–65%、对话 ≥30%、口语 ≥2/千字、锚点 ≥6、段落 80–220 字…），明确「不要逐项打勾」 |

三者都保留 `## 一、…` 编号章结构；设置页「写作规则版本」下拉直接可选，账本与步骤 frontmatter 记录生效版本 + 哈希。

### 1.2 正文模板（`engine/prompts/body-v3-prompts.ts` / `body-v4-prompts.ts`）

| 模板 | 思路 | 与 V2 的结构差异 |
|---|---|---|
| `bodyGeneration.v3@3.0.0` 节拍先行 | 台词清单前置 | 台词清单放在 user 最前并注明「每条都要出现、不许改成转述」；system 只留三条硬要求 + 规则 + 人味块；**不注入禁用清单/工艺块**；动笔前先排「谁要什么/谁在拦/交换了什么/谁变了」 |
| `bodyGeneration.v4@4.0.0` 对话主干 | 录音机视角 | system 压到 1.4k 字符（V2 是 6.3k）；按台词编号写成连续对话，每两三条对话之间最多 1–3 句叙述；每场开头用具体时间/序数落地 |

切换方式：设置页「正文模板变体」（auto / v1 / v2 / v3 / v4），`getStepTemplateAuto` 读 `vars._bodyVariant` 强制路由，留空仍按灵魂层自动走 V2。

## 二、实验方法（可复现）

`scripts/humanness-combo.mjs`：

- **不手抄提示词**：用 esbuild 把 `scripts/fixtures/prompt-exports.ts` 打包成 ESM 再 import，实验里的模板/规则/人味块/工艺块与插件运行时是同一份源文件。
- 固定项：第 1 章真实上下文（大纲/信息规划/情节蒸馏/场景展开/世界观/设定库/人物）、台词骨架（从该章现有正文抽取 48 条对话行，落在 `data/experiments/ch1-skeleton.txt`）、`deepseek-flash`、temperature 0.9、thinking 关闭、seed 20261101。
- 本地指标：`shared/human-feature-rubric.ts`（对话占比、对话块/千字、短叙述占比、口语/千字、时间锚点），与朱雀判定同向但**不等价**。
- 产物：`data/experiments/combo/<组>.md|json`、`summary.json`。

### 3.5 重复采样（n=3，决定性结果）

对三组代表各重跑 3 次（同章、同骨架、同参数、同 seed）：

| 组 | 组合 | rubric 均值 | 范围 | 对话均值 | 短叙述均值 | 口语均值 | 锚点均值 |
|---|---|---|---|---|---|---|---|
| C0 | 现状基线（V2 + 3.6.0 + 配额 + 禁用/工艺） | 33 | 20–40 | 18% | 0.40 | 0.09 | 0.0 |
| C4 | 场景节拍 + V3 + 样文 | **40** | 40–40 | 19% | 0.40 | 0.00 | 0.0 |
| C9 | 真人特征 + V4 + 样文 + 可数硬指标 | 27 | 20–40 | 20% | 0.39 | 0.10 | 0.3 |

读法：

- 单样本里 C9 的 60 分是离群值（另两次 20/40）；C0 单样本里出现过的短叙述 0.29 同样是离群值（另两次 0.40/0.50）。
- 三组的**短叙述均值几乎相同（0.39–0.40）**，对话 18–20%，口语与锚点接近 0 —— 组间差异落在采样噪声内。
- 唯一稳定的是 **C4 三次都是 40**：V3 + 场景节拍是「不塌节奏」的稳定配置，但没有跨过任何新阈值。
- 因此上一节按单样本做的因子归因（4.1–4.4）只能视为**假设**，不构成权重证据；需要 n≥5 才能定量。

## 四、哪些注入内容「可能」影响人工特征（单样本假设，待 n≥5 验证）

### 4.1 规则文本：可能决定「叙述密/碎」，方向会过冲

- C1→C2（只换规则 3.6.0→3.7 锚点）：短叙述 0.52→0.27。锚点版把「不要碎」理解成「把句子写长」，直接冲出人工区间（0.35–0.85）。但 C0 复测也出现过 0.29，需更多样本确认。

### 4.2 模板：可能是最大的交互项

- 同一条 3.8 场景节拍规则：V3 下短叙述 0.63（单样本正中人工样本），V2 下 0.19（C10）。但两者 n=1，且 C4 复测均值只有 0.40 —— 「模板是解释器」这个方向仍成立（V3 的输出结构确实不同），幅度待确认。
- V3 比 V2 少 4.5k 字符（不注入禁用清单/工艺块），输出更接近自然段节奏。

### 4.3 禁用清单 / 工艺块：可能轻微抑制口语与锚点

- C1→C7（去掉这两块，其余不变）：短叙述 0.52→0.45、口语 0→0.28、锚点 0→1。单样本；C0 复测口语均值为 0.09，方向一致但不显著。
- 结论（弱）：这两块不是人味来源，去掉后模型更容易写出口语和「第几次」，但单独去掉不足以提升 rubric。

### 4.4 可数硬指标：能推动，但会换走节奏

- C8（V3 + 硬指标）：口语 0.87，锚点仍 0，短叙述 0.19——模型为凑指标牺牲自然段节奏。

- C9（V4 + 硬指标）：单样本对话 21→24%、锚点 0→2、口语 0.32→0.35，短叙述 0.46；三次复测均值 rubric 27、对话 20%、锚点 0.3 —— **离群值，不能当结论**。

### 4.5 台词骨架：对话占比的天花板

所有组对话都停在 17–24%（骨架给了 48 条原章对话行），复测均值 18–20%。模板能上浮 2–5 个点，但突破不了 25% 下限——骨架本身是陈述式对话。要提高对话占比，只能改骨架（让更多信息由台词承载），不是改提示词。

## 五、朱雀验证（额度 27 → 25）

| 组 | 送检时的本地表现（单样本） | 朱雀判定 |
|---|---|---|
| C9 | rubric 60、对话 24%、锚点 2 | 未发现明显的人工创作特征 |
| C4 | 短叙述 0.63（正中人工区间） | 未发现明显的人工创作特征 |

对照：上一轮真人样文（2306 字，对话 38%）判「人工创作特征显著」。

**判读**：即使送检样本是本轮「最好看」的两份，判定仍不变；复测又证明这两份的分数本身是离群值。与前一轮 6 组消融一致：外部检测卡的是模型 token 分布层面。

## 六、落地建议（按复测结果修正）

1. **默认不换**：没有组合稳定通过 rubric；三组均值 27–40，对话/口语/锚点仍不达标。
2. **保留为可选项**：规则 `3.9.0-voiceprint` / `3.8.0-scene-beat`、模板 V3/V4、可数硬指标（`countableHumanHints`，默认关）都已进设置页；想复现 C4（最稳定，三次 40）用「场景节拍 + V3 + 样文」。
3. **下一步必须有重复采样**：任何组间比较至少 n=3、最好 n=5，用均值与区间而不是单次分数；脚本已支持 `--tag` 重跑并在 `data/experiments/combo/` 留档。
4. **有增量的方向只剩数据**：把台词骨架升级为「信息动作清单」（每条台词完成哪个信息交换、谁在拦），让对话占比从数据结构上超过 25%；提示词与规则继续微调的边际收益已接近零。
5. **验收口径**：`human-feature-rubric` + 人工抽读；朱雀只作旁证。

## 七、复现

```bash
node scripts/humanness-combo.mjs --dry                     # 只看组装后的 prompt 与占比
node scripts/humanness-combo.mjs --groups C4               # 跑单组（消耗 1 次 API 调用）
node scripts/humanness-combo.mjs --groups C4 --tag r2      # 重复采样（结果落 C4-r2.md/json）
node scripts/humanness-combo.mjs --chapter 2               # 换章（骨架自动从该章正文抽取）
```

产物在 `data/experiments/combo/`；台词骨架在 `data/experiments/ch<N>-skeleton.txt`（都在本机 `data/`，不入库，也不会被 Playwright 清空）。
