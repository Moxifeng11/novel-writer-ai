## 一、实现内容

### 1.1 五套故事结构

新增 `shared/story-structure.ts`：

| 结构 | 阶段与比例 | 硬约束 |
| --- | --- | --- |
| 起承转合 | 起 25 / 承 35 / 转 25 / 合 15 | 转必须改变读者理解；合必须回应开篇问题 |
| 三幕式 | 建置 25 / 对抗 50 / 解决 25 | 激励事件 ≤20%；中点主角转主动；结局由主角选择决定 |
| 五幕式 | 铺垫 15 / 发展 25 / 高潮 25 / 转折 20 / 结局 15 | 每幕改变力量格局；第四幕胜利必须付出代价 |
| 英雄之旅 | 启程 20 / 试炼 30 / 磨难 25 / 归来 25 | 磨难中失去旧东西；归来改变与平凡世界的关系 |
| 序破急 | 序 30 / 破 40 / 急 30 | 破改变日常认知；急明显提速且不能靠新设定硬解 |

每套结构包含阶段目标、关键节点、适用题材和硬约束；阶段比例合计 100%。

### 1.2 九组创作设定

`STORY_OPTION_GROUPS`：

- 主角起点（落魄者/普通人/天才/继承者/重生者/穿越者/被放逐者/隐世者）
- 核心冲突（复仇/守护/生存/争霸/求真/救赎/归乡/反抗命运）
- 力量体系（修炼/武道/科技/异能/神话/现实/混合）
- 金手指（系统/重生记忆/穿越知识/血脉/神秘器物/读心/时间回溯/无金手指）
- 人物原型（废柴逆袭/天才流/退婚流/系统流/群像/反英雄/日常流/权谋）
- 主角性格（冷静/热血/腹黑/温和坚韧/偏执/幽默）
- 叙事基调（热血爽文/悬疑冷峻/温情治愈/黑暗史诗/轻松诙谐/悲壮苍凉）
- 感情线（无/弱/中/强）
- 推进节奏（快/中/慢）

`validateStorySettings()` 实时检查组合矛盾，例如：

- 科技体系 + 血脉觉醒；
- 现实体系 + 超自然金手指；
- 系统流 + 非系统金手指；
- 天才流 + 非天才/继承者起点；
- 轻松诙谐 + 复仇/争霸/生存；
- 日常流 + 复仇/争霸/生存；
- 三幕式 + 慢热铺陈。

### 1.3 智能随机

`generateRandomStorySettings()`：

- 随机源为 `shared/true-random.ts` 的 CSPRNG（WebCrypto + 拒绝采样）；
- 先按题材权重选择结构，再按“已选字段 + 校验结果”过滤候选池，逐项抽样；
- 最多重试 80 次，失败时回退到该结构的预置自洽组合；
- 每个结果带随机种子，写入 `.project`；
- 结构化随机源可注入，测试可复现，生产默认不可复现。

- `ui/story-settings-form.ts`：创建弹窗与编辑弹窗共用编辑组件；五张结构卡、九组 chips、实时自洽提示、随机种子展示、锁定结构随机。
- `ui/create-project-modal.ts`：新增故事结构区；创建时写入 `CreationModeMeta.storySettings`。
- `ui/story-settings-modal.ts`：已有项目编辑入口；保存后写 `.project`、`故事结构指南.md`、`创作模式指南.md`。
- `shared/creation-mode.ts`：`CreationModeMeta` 增加可选 `storyStructure/storySettings`；解析/生成 `.project` 元数据；长篇 `creationModePrompt` 注入结构阶段与设定；旧项目仍返回空块。
- `ui/full-writer/wizard-types.ts`：原创长篇第一步新增 `story_structure`；同人长篇放在原作设定导入之后。
- `wizard-controller` / `wizard-step-renderers` / `wizard-step-executors` / `wizard-step-validators`：读取 `.project` 判定完成、展示结构摘要、打开编辑弹窗、阻止未配置时前进。
- `ui/project-utils.ts` + `project-selector-controller.ts`：项目卡片显示 `🧬 结构名` 徽章。

## 三、边界与未覆盖

- E2E 不复制本机 `data.json`，不调用真实 AI；结构提示词对实际正文生成的影响未做生成质量评估。
- 随机组合保证字段级自洽，不等于故事一定好看；用户仍可手动调整。
- 旧项目不迁移：只有重新配置并保存后才会注入结构提示词。
- 短篇/剧本项目不受影响，仍使用各自模式与前期调研。
