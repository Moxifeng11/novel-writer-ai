# v4.19.0 AI 辅助前期调研与真随机创作验证报告

- 日期：2026-10-27
- 版本：4.19.0（本地工作树）
- 范围：短篇/剧本 AI 前期调研、热点素材、固化创作框架、多层真随机因子、调研产物落盘

## 一、实现内容

### 1.1 真随机引擎

- `engine/harness/true-random.ts`
- 使用 WebCrypto CSPRNG（`crypto.getRandomValues` / `randomUUID`）。
- 拒绝采样消除模偏差；提供 `pick/pickMany/shuffle/weightedPick/uuid`。
- `createSeededRandom` 仅用于测试重放校验；生产路径全部走 `trueRandom`。

### 1.2 热点/行业调研

- `engine/harness/trend-research-service.ts`
- 支持 Bing / Brave / Serper / Tavily；`manual` 或无 key 时不发请求。
- 查询按模式区分：短篇“番茄小说 短篇 题材 榜单”，剧本“红果短剧 题材 榜单 卡点”。
- 返回标准化 `TrendSource[]`；失败返回空数组并交由上层降级。

### 1.3 固化创作框架

- `engine/harness/creative-frameworks.ts`
- 番茄短篇：`short.fanqie.v1`，5–10 万字/单主线/3–5 反转/每节钩子，S1–S6 阶段与校验节点。
- 红果短剧：`script.hongguo.v1`，3 秒钩子/40–120 集/3–6 场/付费卡点，T1–T6 阶段与校验节点。
- `frameworkPromptBlock()` 输出行业依据、结构、阶段交付与硬约束。

### 1.4 多层真随机因子

- `engine/harness/creative-randomizer.ts`
- 四层因子：
  - 前提层：主角身份、能力/限制、压力源、期待破坏
  - 结构层：反转类型、情绪曲线、升级方式、推进器/集节奏
  - 质感层：对白风格、细节通道、场景节奏
  - 差异化层：避免套路、要求动机/代价/视角约束
- 每次生成随机种子（UUID）与禁用套路清单。

### 1.5 AI 前期调研服务

- `engine/harness/ai-assisted-premise-service.ts`
- 输入模式/分类/受众；搜索可用时把实时来源注入 prompt，否则要求 AI 明确标注“未经实时核实”。
- 单次 AI 调用输出热点分析 + 3 个差异化候选（不同身份/冲突/情绪曲线）。
- 候选字段：名称、一句话故事/卖点、核心冲突、情绪承诺/爽点、钩子、结尾兑现、人物、场景。

## 二、UI 接入

短篇/剧本前期调研弹窗新增：

- `🤖 AI 前期调研`：执行热点 + 框架 + 随机因子生成；输出框架与候选。

## 四、运行时验证

### 4.1 弹窗入口

- 短篇调研弹窗显示 `🤖 AI 前期调研` 与 `🎲 随机灵感`。
- 初始状态：`尚未执行 AI 调研`。

### 4.2 随机灵感

- 点击后显示统一「🎲 真随机种子」卡片：种子值、复制、重置，以及前提/结构/质感/差异化/禁用套路分组 chips。
- 「复制」写入剪贴板并显示“已复制”反馈；「重置」用 CSPRNG 生成新种子与新因子。
- 多次点击/重置种子变化；卡片样式与插件卡片/徽章变量一致。
- 短篇与剧本场景使用同一组件与样式。

### 4.3 AI 前期调研

- 未配置搜索 API：状态为“模型调研草稿（未经实时核实）”，AI 输出显式带“未经实时核实”前缀。
- 输出 3 个候选，`应用候选` 按钮可用。
- 应用候选 1 后：项目名、一句话故事、核心冲突、情绪承诺等字段被填充。
- 创建项目 `短篇小说/夜班担保人` 后：
  - `.project`、`作品信息.md`、`写作配置.md` 正常；
  - `00-前期调研/调研数据.json` 含 `insight`；
  - `调研报告.md` 含「五、AI 前期调研」「未经实时核实」「固化创作框架」「多层真随机因子」。

### 4.4 已有项目复跑

- 对已有短篇项目再次执行 AI 调研：
  - 生成新随机种子与新候选；
  - 应用候选后保存；
  - 旧调研报告与五维分类自动备份；
  - 新报告覆盖为最新调研结论。

### 4.5 清理

- 测试项目已删除，未留下测试数据。

### 4.6 随机种子卡片重构验证

- 短篇场景：卡片包含标题「🎲 真随机种子」、等宽字体种子值、复制/重置按钮，以及 5 组 chips。
- 剧本场景：同一卡片结构、同一 CSS 类与视觉样式，chips 数量一致。
- 重置：两个场景均生成新 UUID 种子，原种子与新种子不同。
- 复制：按钮进入「已复制」状态并回弹；使用 clipboard API，异常时 Notice 提示。
- 样式：卡片背景/边框/圆角/阴影使用 `--nw-card-*`、`--nw-radius-*`、`--nw-surface` 等插件变量。
- AI 调研冒烟：点击「AI 前期调研」仍进入“正在检索热点/行业素材…”状态，核心生成逻辑未被 UI 重构影响。

## 六、边界与说明

1. “真随机”指 CSPRNG 非确定性采样，不承诺绝对不可能重复；目标是消除固定 prompt/温度/缓存导致的同质化。
2. 未配置搜索 API 或检索失败时，热点内容为模型调研草稿，显式标记“未经实时核实”，需人工核实。
3. 框架是固化结构，不随随机因子变化；随机只作用于题材方向、人物、细节、对白与场景。
4. AI 前期调研为一次主调用；不自动二次修复，失败由用户重跑。
5. 版本仍为 4.19.0 工作树，未提交、未推送远端。
