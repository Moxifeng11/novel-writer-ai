## 三、控制变量实验（关键设计）

前作曾发现「人工率与章节字数强负相关 r=-0.721」，那可能是**长度混淆**（短文本易判人工）。
所以本次全部样本**截取前 2000 字**，消除长度因素。

### 3.1 同长度下两项目对比（n=22，全部 ≈2000 字）

| 项目 | 引号/千字 | 人工率均值 | softmax 均值 |
| --- | ---: | ---: | ---: |
| 5570 巅峰榜（12 章） | **25.0** | **42.3%** | 0.6339 |
| 6153 超神（10 章） | **1.6** | **0%** | 0.9999 |

**对话密度差 15.6 倍 → 人工率差 42 个百分点。**

### 3.2 5570 内部为什么还有 0% 的章？

5570 里有引号 56.8/千却仍 0% 的章（ch126），说明对话密度**必要但不充分**。
挖第二因子：

| 组 | 段落均字 | 段落长度 std |
| --- | ---: | ---: |
| 高分组（84–100%） | 57.7 / 102.1 / 55.7 / 41.8 | 33.5 / 29.2 / 31.4 / 22.2 |
| 零分组（0%） | 36.1 / 37.2 / 45.2 | 16.3 / 17.3 / 24.6 |

真人基线段落均字中位 **41.76**（P25 35 / P75 58.7）。零分组的段落全在 P25 附近或以下。

### 3.3 四象限验证（决定性）

阈值：引号 ≥ 12/千字（真人 P25 是 11.97）、段落均字 ≥ 41.76（真人中位）

| 象限 | n | 人工率均值 | 人工率 ≥50% 的章数 |
| --- | ---: | ---: | ---: |
| **对话高 + 段长合格** | 7 | **61.1%** | **4/7** |
| 对话低 + 段长合格 | 8 | 8.4% | 0/8 |
| 对话高 + 段短 | 3 | 4.2% | 0/3 |
| 对话低 + 段短 | 4 | 0.0% | 0/4 |

**结论：两个条件必须同时满足。** 单独满足任一个都塌到 0–8%。
两因子同时满足时，人工率从 0% 抬到 61.1%，有 4/7 章过 50%，最高 100%。

### 3.4 相关性

| 指标 | Pearson r（vs 人工率） |
| --- | ---: |
| 引号/千字 | 0.453 |
| 段落均字 | 0.450 |
| 段落长度 std | 0.398 |

两因子相关系数接近，说明是**并列的两个必要条件**，不是某个单一主因。

## 四、修正后的朱雀判据模型

```
人工率 ≈ f(对话密度 ≥ 12/千字, 段落均字 ≥ 42, ...)
         ↑ 两个必要条件，缺一即塌
```

**仍然不确定的部分**：
- 两因子都满足的 7 章里，3 章是 0% 或 12.5% → 还有第三因子未找到
- 候选：口语词密度（r=0.217 偏弱）、短对话占比、段落长度方差
- 需要更多样本（5570 有 301 章可挖）

## 五、为什么 6153 和 5570 差这么多（配置线索）

| 项目 | 蒸馏状态 | 章节数 | 类型 |
| --- | --- | --- | --- |
| 6153 超神 | 9/10 已完成蒸馏 | 10 | 衍生同人 |
| 5570 巅峰榜 | **全部「未蒸馏」** | 301 | 全民向甜燃电竞 |

两个关键差异：

1. **5570 的 301 章全部未蒸馏** → 说明它的写作流程**没有走「正文→摘要回流」的闭环**，
   可能是纯正文生成模式（或人工介入多）
2. **题材不同**：电竞文天然是「对话+操作细节」密集，科幻同人天然偏「设定说明」

第 2 点很可能是根本原因：**题材决定了对话密度天花板**。
6153 的瓶颈不只是提示词，而是「硬核科研流」这个题材本身要求大量说明性叙述。

### 本仓的可行动项

**P0-1 对话密度是最大杠杆**（本仓产物 3.12/千字，真人 18.53，5570 是 25.0）

本仓问题不只是"提示词没要求"，而是：
- `HUMAN_VOICE_WEAK_RULES` 第 1 条说「对话争取占全文三分之一」，但**没有量化密度**
- 实测产出 3.12/千字 = 真人下限的 1/6
- 需要把「每千字至少 X 段对话」写成可数指标

**P0-2 段落长度是第二杠杆**（本仓 27.24 字，真人 41.76，5570 高分组 41–102）

本仓 `human-voice` 写的是「80–220 字」，但实测只有 27.24 字——
说明**提示词说的和实际产出完全脱节**。要查为什么模型没遵守。

**P0-3 题材适配**
硬核设定流（科研/系统/升级）天然低对话。若要提高人工率，
需要在提示词里对这类题材给出**替代方案**：
用「人物讨论设定」代替「叙述者说明设定」——把说明文变成对话。

## 九、三因子模型（第三因子已找到）

两因子达标但人工率仍低的 3 章，它们与高分组的关键差异在**单句成段占比**：

| 组 | 单句成段占比 |
| --- | --- |
| 高分组（84–100%） | 2.9% / 10% / 16.2% / **0%** |
| 落选组（0–42%） | **42.9% / 18.2% / 40%** |

高分组最高 16.2%，落选组最低 18.2% —— **干净分离，无重叠**。

### 三因子判定规则

```
条件：引号 ≥ 12/千字  AND  段落均字 ≥ 41.76  AND  单句成段 ≤ 20%
（三个阈值全部来自 139 段真人基线：引号 P25、段落中位、单句成段）

达标 n=5  → 人工率均值 77.1%，4/5 章 ≥50%（两章 100%）
未达 n=17 → 人工率均值  7.2%，0/17 章 ≥50%
```

## 十、修正后的完整结论

### 朱雀的可测判据（已验证）

| 因子 | 阈值 | 依据 | 权重 |
| --- | --- | --- | --- |
| **对话密度** | ≥ 12 引号/千字 | 真人 P25（11.97） | 必要条件 |
| **段落均字** | ≥ 42 字 | 真人中位（41.76） | 必要条件 |
| **单句成段** | ≤ 20% | 真人 P75（20.78） | 必要条件 |

三者 **AND** 关系。同时满足 → 人工率均值 77.1%；任一缺失 → 7.2%。

### 这三个都是本仓可操作的

| 因子 | 本仓产出 | 真人 | 差距 | 提示词现状 |
| --- | ---: | ---: | --- | --- |
| 对话密度 | **3.12**/千 | 18.53 | 需 ×6 | weak rules 只说「占全文三分之一」，无数值 |
| 段落均字 | **27.24** | 41.76 | 需 ×1.5 | 写的是「80–220 字」，实测 27——**完全脱节** |
| 单句成段 | 需实测 | ≤20.78% | — | 无此判据 |

**关键洞察**：本仓 `human-voice` 写的段落长度是「80–220 字」，
但实测产出只有 27.24 字——**提示词说的和模型做的完全不同**。
这说明「写数值上限」这条路本身无效（模型理解不了「一段 80–220 字」这种复合约束）。

云笔 5570 能做到 42–102 字，靠的不是配额，而是：
- 铁律 4「段落焦点单一」——每段只做一件事，自然撑出长度
- 铁律 9「长句合法用途」——复杂场景/心理/信息揭示必须用长句
- L2 第 3 条「段尾硬停」——具象收尾，不用抽象话结束

**这三条是「结构性约束」而非「数值配额」**，这是关键区别。

## 十五、给本仓的具体建议（基于已确认的三因子）

### 6153 式「说明流」的双病灶与对应方案

| 病灶 | 6153 实测 | 目标 | 云笔对应手法 |
| --- | ---: | --- | --- |
| 对话密度不足 | 1.6/千 | ≥12 | 铁律 3「对话归属」+ L2 第 2 条「信息由人物说出来」 |
| 单句成段过多 | 38.6% | ≤20% | 铁律 4「段落焦点单一」+ 铁律 9「一句一段最多连续 3 处」 |

**注意：6153 的段落均字是达标的（47.4）**，说明它的段落"长度够但结构碎"——
平均 47 字，却有 38.6% 的段落只有一句。这是典型的「长短混编但缺少句间组织」。

### 本仓的对策（结构性，非数值配额）

本仓当前问题（`human-voice` 写「80–220 字」，实测 27.24 字）说明**数值配额无效**。
应改用云笔的三条结构性约束：

1. **铁律 4「段落焦点单一」**：每段只做一件事（一个动作单元/一段心理/一轮对话）
   → 自然把段落撑到 40+ 字，且不产生单句成段
2. **铁律 9「一句一段最多连续 3 处，且必须是重击点」**
   → 直接压制单句成段比例
3. **铁律 3「对话归属 + 每句对话必须承担功能」**
   → 逼出对话，且对话有信息量

这三条的组合正好对应三个因子，且都是**结构约束**而非数字配额。
