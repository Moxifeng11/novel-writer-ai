# v4.19.0 UI、叙事模式与场景描写升级验证报告

- 日期：2026-10-27
- 版本：4.19.0（本地工作树）
- 范围：CSS 设计系统、故事结构面板、章节叙事模式切换、创作引擎稳定性、协同写作/整章生成的场景描写

## 一、CSS 设计系统 v2

### 1.1 新增令牌与通用规则

在 `styles.css` 末尾新增设计系统终层：

- 表面令牌：`--nw-surface-base/raised/sunken`；
- 输入令牌：`--nw-field-bg/border/radius`；
- 焦点令牌：`--nw-focus-ring`；
- 动效令牌：`--nw-motion-fast`。

通用规则：

- `.nw-scope :is(button,input,textarea,select)` 统一字体与 `-webkit-tap-highlight-color`；
- `button/[role=button]` 统一 `touch-action: manipulation`；
- `:focus-visible` 使用统一 2px accent 外轮廓；
- `input/textarea/select` 统一 `accent-color`；
- `prefers-reduced-motion` 下禁用动画与过渡。

### 1.2 故事结构面板重排

- 结构卡改为 5 列（窄屏 2 列/1 列）；
- 新增当前结构详情区：图标、说明、阶段比例轨道（按比例 `flex`）；
- 九组配置拆为「核心设定」「风格与节奏」两栏；
- 一句话故事、自洽提示、随机种子分区展示；
- 结构弹窗宽度提升到 `min(960px, 94vw)`，内容区独立滚动，底部操作区固定；
- 面板背景改用 `--background-secondary`，避免自定义 `--nw-card-bg` 被主题色染成整块高饱和底色。

响应式断点：760px 单栏设置、2 列结构卡；520px 单列结构卡、随机操作整行。

## 二、章节叙事模式切换

- 移除 `status-bar-controller` 中固定的 `'起承转合'` 默认值，场景节奏缺失时显示“自然节奏”；
- 状态栏新增 `.nw-narrative-select`：起承转合、三幕式、五幕式、英雄之旅、序破急可自由选择；
- `FullWriterView.switchNarrativeStructure()`：
  - 生成中或 `isLoading` 时拒绝切换并写入执行事件；
  - 校验结构 ID；
  - 读取 `.project`，保留原有九组设定，仅替换 `structureId`；
  - 写回 `.project`、`故事结构指南.md`、`创作模式指南.md`；
  - 重渲染后 `buildTemplateVars` 重新生成 `narrativeStructure` 与 `creationModePrompt`；
  - 已生成内容不自动改写，只影响后续步骤。
- `buildTemplateVars` 新增 `narrativeStructure/narrativeStructureName/narrativeStructureStages`；解析失败时不再假定起承转合。
- 场景节奏默认文案从“起承转合 — …”改为“对话推进 — …”，避免把整体结构与场景节奏混为一谈。

## 三、场景描写融合

### 3.1 整章生成

`BODY_GENERATION_USER_TEMPLATE_V2` 在场景卡后新增硬约束：

- 每场开头 1–3 句落地地点、时间/光线、至少一个感官细节；
- 必须使用场景卡 `sensory_hook` 与 `body_reaction`；
- 场景切换写清时间/地点过渡；
- 环境描写只服务人物行动与情绪。

### 3.2 协同写作

- `CO_WRITE_DIRECTION_PROMPTS.description` 改为使用当前场景卡地点/时间/感官钩子，只写环境与身体感受，不推进剧情、不写对白、不引入新地点；
- `CO_WRITE_PROMPTS.sentenceSystem` 增加“具体地点/时间/感官细节”要求；
- 协同写作核心操作区新增「🎬 场景描写」按钮：自动写入场景描写临时指令并触发生成。

## 四、稳定性处理

- 叙事结构切换在生成中直接拒绝，避免步骤执行与项目元数据写入交错；
- 切换只修改结构字段，保留主角、冲突、力量体系等既有设定；
- 结构 ID 白名单校验；
- 写入顺序：`.project` → 故事结构指南 → 创作模式指南 → 执行事件 → 重渲染；
- 失败写入执行事件错误，不改变当前内存状态；
- 现有功能未改：短篇/剧本、11 步完成判定、失效传播、导出均未触碰。

## 六、边界

- E2E 不调用真实 AI，场景描写/叙事结构对实际文本质量的影响未做生成评估；
- CSS 重构集中在令牌层、通用交互与故事结构面板，未逐条重写全部历史选择器，避免大范围视觉回归；
- 切换叙事结构不会重写已完成内容，只影响后续生成；
- 旧项目未配置结构时显示“未设置”，不注入长篇结构提示词。
