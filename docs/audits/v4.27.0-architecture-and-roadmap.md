已具备的工程骨架：`EngineRegistry` 生命周期、`Repository + ports`、`shared/project-catalog` 项目单一来源、`engine/prompt-resolver` 步骤提示词单一解析、`services/rules-service` 写作规则单一来源、`shared/body-path` 正文路径判定、`ui/settings/section-factory` 设置分区单一装配、`preflight` / `preflight:release` 门禁链、mock AI 全旅程 E2E。

问题不在“没有架构”，而在**同一事实仍有多份实现、部分门禁空转、三模式能力严重不均衡、入口与资产概念过载**。

## 3. 下一阶段路线（A→B 渐进，里程碑交付）

### M1（第 1 周）可信门禁 + 安全止血 · v4.27.1

- ESLint flat config 修复；关键规则生效；存量 warn 设上限；故意违规自测。
- Agent 覆盖已有文件默认 `ask`，设置开关默认开。
- dsh 固定版本、启动前校验、Key 解密后注入。
- v1 密文自动升级 v2 + 计数；设置迁移前 `data.json.bak`。
- `BODY_CONTENT_ROOTS` 派生修复；`check:write-entry` 门禁。
- 审计报告、PRODUCT、ROADMAP、ADR、缺失 release notes。

**验收**：`preflight:release` 全绿；lint 真实规则生效；Agent 覆盖需确认；v1 残留 0；短/剧统计回归通过。

### M2（第 2–3 周）统一入口 + 任务中心 + 首启 · v4.28.0

- 创作主页（长篇/短篇/剧本三卡 + 最近项目 + 下一步），四视图降为子页/深链；命令分组。
- `JobService`：批量/结算/拆解/导出统一注册，支持进度、取消、重试、失败汇总。
- 首启向导：选提供商 → 填 Key → 连通性测试 → 示例项目 → 第一章。
- 统一错误/空态组件；项目体检 MVP（重复章节、孤儿文件、未结算章、坏 frontmatter）。

### M3（第 3–5 周）短篇/剧本最小闭环 · v4.29.0

- 抽 `ModeRuntime`：项目/章节/实体/故事核/场景圣经/RAG/指纹统一上下文。
- 短篇：AI 故事核 → 分节大纲 → 开篇三屏 → 单元写作 → 六维质检 → 单元结算。
- 剧本：分集大纲 → 场景圣经 → 分镜表 → 分集写作 → 可拍质检 → 单元结算。
- `QualityProfile` 按模式配置维度与阈值；导出平台包（番茄短篇/红果短剧）。

### M4（第 6–10 周）体验跃迁 · v4.30.0

- 资产模型收敛：模板/提示词/规则/文笔风格/指纹统一“资产”层级与生效顺序；`AssetRegistry`。
- 全模式接入知识库/指纹/实体；RAG 混合检索（BM25 + 向量）与 rerank。
- 成本/调用账本 UI：每章/每步/每模型 token、费用、重试。
- 版本/备份中心；大文件第一批切片（协同视图/协同引擎/知识库视图）。

### M5（第 11–12 周+）平台化评估 · 不默认实施

仅在 M1–M4 指标达成后评估：公共插件 API、MCP、模板市场、云同步/协作。实时协作/账号/计费暂缓。

## 4. 执行纪律

1. 每个里程碑先写 ADR / 验收清单，再按“门禁 → 数据 → UI → 模式 → 资产”顺序。
2. 短/剧与 M4 使用 feature flag / strangler，不做一次性大重构。
3. 每批改动补回归；禁止用下调阈值掩盖失败。
4. 每个里程碑本地稳定提交；push / tag / Release 另行授权。

## 6. 量化目标

- Lint：关键规则真实启用；存量违规只降不升；故意违规样例必须失败。
- 覆盖率：保持 64.62/56.87/67.05/65.96；`engine` branches ≥52；UI/`domains` 纳入统计；0 覆盖文件 83 → ≤40。
- 安全：Agent 覆盖已有文件默认 `ask`；dsh 固定版本且 Key 解密；v1 残留 0；设置迁移前有 `.bak`。
- 数据：白名单外用户可见 md 裸 adapter 写入 0；核心写路径锁覆盖 ≥80%；卸载 flush 有完成/超时记录。
- 产品：新用户 3 分钟内完成配置 + 示例第一章；短/剧创建→导出无手填断点；任务中心可取消/重试。
- 性能：`main.js` ≤5 MB；空闲 CPU <5%；堆增量 <256 MB。
