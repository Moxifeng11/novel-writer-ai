## 二、RAG 管线

```
查询计划（多来源，带权重）
  → Promise.allSettled 并行 search
  → 合并去重（book|dimension|position|sample 前缀，保留最高分并合并标签）
  → 邻块扩展（同书同维度 ±1，分数取最低分的 0.95，不抢主命中）
  → 阈值过滤（默认 0.35）
  → MMR（λ=0.7）
  → 预算打包（最高分必保、尾条可截断）
  → citation（〔书名·维度〕）
```

接入点（9 处，8 处统一 + 1 处有意例外）：

| 注入方法 | 维度 | topN | 预算字符 |
|---|---|---|---|
| `buildSceneCharacterInjection` | character | max(3, round(strength×5)) | 900 |
| `buildSceneWorldviewInjection` | structure | max(2, round(strength×3)) | 700 |
| `buildSceneTechniqueInjection` | technique | max(3, round(strength×4)) | 800 |
| `buildSceneRhythmInjection` | rhythm | max(2, round(strength×4)) | 700 |
| `buildKbCharacterInjection` | character | max(2, round(strength×5)) | 900 |
| `buildKbWorldviewInjection` | structure | max(2, round(strength×4)) | 700 |
| `buildKbTechniqueInjection` | technique | max(3, round(strength×6)) | 800 |
| `buildKbRhythmInjection` | rhythm | max(2, round(strength×4)) | 600 |

遥测：`KnowledgeInjector.lastInjectionMeta.retrieval` 累计 queries/hits/deduped/neighborMerged/dropped/cacheHits/cacheMisses，`formatInjection()` 后清零（每轮独立）；`step-runner` 把它拼进 `prompt-ledger` 的 source 与 `truncated` 标记。

## 三、Agent 会话运行时

| 能力 | 实现 | 关键约束 |
|---|---|---|
| read_file | `host-tools.ts` + `agent-port.ts` | 200 行 / 8192 字符；`offset` 续读；行窗口受行数与字符数双重限制；越界返回空窗口 |
| search_vault | 同上 | 只搜文本扩展名；跳过隐藏目录/大文件；最多 3000 文件、50 条命中 |
| 路径守卫 | `shared/file-path-guard.ts` | 拒绝对路径/盘符/`..`/隐藏目录（`.sessions/` 白名单）/控制字符；去包裹引号 |
| spill | `spill-store.ts` + `agent-spill-store.ts` | >6000 字符；→ `.sessions/spill/agent/<项目>/`；日志留 locator + 头 600/尾 200 字；写盘失败保留原文；7 天清理 |
| @ 引用 | `shared/file-mention.ts` + textarea | 只注入路径清单；候选 20 条；`@"带 空格"`；气泡显示用《》替换 `@` |
| 引用消息 | 视图悬停按钮 + 引用条 | `> 原话` 前置；控制令牌不引用 |
| 时间上下文 | `shared/time-context.ts` | 分钟级去重；不进恢复历史气泡 |
| 会话快照 | `session-snapshot.ts` + `agent-session-store.ts` | JSONL 1s 节流追加；>512KB 只留最新行；坏行宽容；callSeq 由 callId 反推 |
| token 计量 | `harness-engine.ts` | derive 字符 ÷1.5；窗口按 `findModelCapability(defaultModel).maxContext` |

## 六、遗留与边界

- 会话恢复只回填用户/助手消息，工具行不回填（避免恢复时重放长结果）；spill 存档不随「新会话」删除，按 7 天保留期清理。
- `buildKbStyleInjection` 保留 style/original 双维度独立检索（配额不同），仍复用查询向量缓存。
- 未引入 tokenizer：token 与窗口占用均为字符估算（÷1.5），量级判断足够，不用于硬切预算。
- 未改 Obsidian 全局设置；`.sessions/` 为插件自有隐藏目录，不参与 Bases/标签/搜索（`search_vault` 显式跳过）。
- 本轮未提交、未推送（沿用版本节点统一提交的惯例）。
