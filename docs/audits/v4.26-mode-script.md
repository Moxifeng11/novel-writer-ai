# 剧本：v4.26 路径与设置优化说明

> 2026-11-03 · 插件 4.26.0

## 1. 路径优化

- **项目库根目录**：`剧本` 来自 `CREATION_MODE_SPECS.script.rootDir`；内容根 `剧本创作` 由 `shared/mode-content.ts` 的 `SCRIPT_CONTENT_ROOT` 单点提供。
- **模块引用**：统一 `@/` 别名（如 `@/shared/mode-content`、`@/domains/kernel/project-locator`），跨目录不再出现深层 `../`；依赖门禁已识别 `@/` 为仓内引用，分层检查照常生效。
- **内容结构**：`剧本创作/01-人物与场景 · 02-分集大纲 · 03-剧本 · 04-分镜 · 05-质检 · 06-导出`，由 `SCRIPT_DIRS` 单点定义。
- **验证**：tsc / esbuild / vitest 别名解析通过；真实 Obsidian 设置页与项目创建 E2E 通过。

## 2. 设置界面

- 「创作模式」分区展示剧本的根目录、内容结构与单元规格（默认每集 900 字、40–120 集），并提示使用「单元写作」与剧本附录（场景标题/动作行/台词）。
- 写作配置、模式附录、规则唯一来源与长篇/短篇共用同一套设置，所有原有设置项保留。
- 字数上下限实时校验对剧本同样生效。

## 3. 验证

- 单测覆盖模式根目录单源、别名约束、设置分区结构。
- E2E 覆盖设置页三模式总览；剧本单元写作链路沿用既有用例，无回归。
