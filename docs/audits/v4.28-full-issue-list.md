## 一、严重（必须修）

### S-1 伏笔库多入口写覆盖（写锁仍不完整）

| | |
|---|---|
| 位置 | `engine/foreshadow-manager.ts`（已加锁）、`engine/analysis-report-engine.ts`（已加锁）、`engine/settlement-engine.ts:979-1025`（**未加锁**）、`engine/context-manager.ts`（未加锁） |
| 现象 | 结算引擎 `settleStep_createTimelines` 与 `settleStep_updateForeshadows` 仍直接 `getFS().write(fp, content)` 不走 `withWriteLock`；`context-manager.writeStoryLinkageIndex` 用 `vault.modify` 也不走锁 |
| 影响 | 结算与协同同时写伏笔库 → 后写覆盖前写 → 伏笔丢失或状态回退 |
| 修复 | 所有写伏笔库/时间线看板的路径统一走 `withWriteLock` |
| 验证 | 单测：模拟并发写 → 断言文件内容不丢失 |

### S-2 设置迁移失败后 `saveSettings` 仍可能覆盖原文件

| | |
|---|---|
| 位置 | `core/settings-service.ts:129-140`（已修 `loadSettings` 路径）但 `saveSettings()` 在任何地方被调用时**无条件**写 `schemaVersion: CURRENT` |
| 现象 | 用户在迁移未完成的会话中改任何一个设置（如切主题）→ `saveSettings()` → schemaVersion 被写为 5 → 下次启动不再重试迁移 |
| 影响 | 同 S-1 但触发面更广（任何设置变更都触发） |
| 修复 | `saveSettings()` 在 `migrationIncomplete` 非 null 时跳过 schemaVersion 覆盖 |
| 验证 | 单测：模拟迁移失败 → saveSettings → schemaVersion 仍为旧值 |

### S-3 `contextCache` 无容量上限（内存泄漏）

| | |
|---|---|
| 位置 | `engine/context-manager.ts:206` |
| 现象 | `contextCache` Map 以 `项目::章节` 为 key 存完整 GatheredContext（单条 0.1–1MB），无 LRU、无上限；100 章切过后常驻 10–100MB |
| 影响 | 长篇项目长时间使用后内存爬升，Obsidian 可能崩溃或卡顿 |
| 修复 | 套 `LruCache`（上限 8–16 章）；或用 `maxSize` + `pruneExpired()` |
| 验证 | 单测：写入 >16 章后 cache.size ≤16；DevTools 内存曲线不爬升 |

### S-4 `settings-tab.ts` 5111 行 → 已拆为 `ui/settings/*` 但残留 103 个默认键无 UI

| | |
|---|---|
| 位置 | `main.ts:159` 7 个字段（`panelSizes/budgetTier/thinkingLevel/thinkingIntensity/themeColors/themePresets/panelLayout`）在 `core/settings-service.ts:254` 的 103 个键中缺失默认值 |
| 现象 | `deepMergeSettings` 合并时这 7 个键用 `undefined` 而非默认值 → UI 读到 undefined → 靠零散 fallback 不崩但行为不可预期 |
| 影响 | 新用户首次启动这些设置行为不可预期 |
| 修复 | ①补齐 7 个字段默认值到 `getDefaultSettings()` ②审计 103 个键与 UI 的一致性 |
| 验证 | 单测：`getDefaultSettings()` 返回的所有键在 `NovelWriterSettings` 接口中都有类型 |

### S-5 批量 N 章失败后无一键重跑

| | |
|---|---|
| 位置 | `ui/full-writer/batch-pipeline-runner.ts:167/194` |
| 现象 | 批量 N 章，单章失败仅记 failed；批量结束无「重跑失败章节」汇总按钮 → 100 章失败 8 章需人工逐个找 |
| 影响 | 批量体验极差（尤其中小模型用户） |
