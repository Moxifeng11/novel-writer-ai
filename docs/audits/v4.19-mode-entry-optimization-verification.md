# v4.19.0 三模式入口与前期调研优化验证报告

- 日期：2026-10-26
- 版本：4.19.0（本地工作树）
- 范围：短篇/剧本前期调研、独立创建入口、按项目类型切换右侧工具、批量建章项目上下文

## 一、本次改动

### 1. 独立「前期调研」模块

- 新增 `shared/pre-research.ts`：调研数据结构、报告生成、五维分类/剧本定位文档、读写与备份。
- 新增 `ui/pre-research-modal.ts`：短篇/剧本独立调研弹窗。
- 调研结果写入项目内独立目录：

```text
{项目}/00-前期调研/
  调研数据.json
  调研报告.md
  五维分类.md      # 短篇
  剧本定位.md      # 剧本
```

- 短篇调研字段：主分类、目标字数/节数、一句话故事、核心冲突、情绪承诺、反转、结尾兑现、情节/角色/情绪/背景标签、受众、参考、备注。
- 剧本调研字段：红果类型、目标字数/集数、单集时长、卖点、3 秒钩子、核心冲突、爽点、付费卡点、人物/场景、受众、参考、备注。
- 已创建项目的「前期调研」只写调研文件，项目类型与目标规格锁定，避免与 `.project` 脱节。

### 2. 独立创建入口

- 通用命令 `novel-writer-create-project` 收敛为长篇小说/同人，模式选择器隐藏并锁定长篇。
- 新增命令：
  - `novel-writer-create-short`：新建短篇项目（前期调研）
  - `novel-writer-create-script`：新建剧本项目（前期调研）
  - `novel-writer-short-research`：编辑当前短篇前期调研
  - `novel-writer-script-research`：编辑当前剧本前期调研
- 新增工具目录：`SHORT_TOOL_GROUPS`、`SCRIPT_TOOL_GROUPS`；长篇工具仍为 `TOOL_GROUPS`。
- 工作台空状态提供「创建长篇 / 创建短篇 / 创建剧本」三个独立按钮。
- 脑洞构思、黄金开篇的创建路径锁定长篇，避免绕过独立入口创建短篇/剧本。

### 3. 项目类型识别与动态工具

- 项目卡片选中后，`renderRightPanel()` 读取 `getProjectMeta()`，按 `creationMode` 选择工具目录与项目级操作。
- 短篇工具：新建短篇、前期调研（当前项目）、批量建节、成稿导出、协同写作、文笔风格、实体/设定、标签/提供商。
- 剧本工具：新建剧本、前期调研（当前项目）、批量建集、成稿导出、协同写作、文笔风格、实体/设定、标签/提供商。
- 长篇工具保持原样：项目向导、全书规划、批量建章、章节结算、跨卷状态等。
- 短篇/剧本项目操作使用「全部节/全部集」「下一节/集」，章节选择弹窗也映射为节/集显示。

### 4. 批量建章上下文

- `BatchCreateModal` 新增 `preferredProject` 参数；命令执行器传入 `plugin.getActiveProject()`。
- 从项目卡片选中后点击批量建节/建集，下拉框默认当前项目，不再落到项目列表第一个长篇项目。

## 二、运行时验证

### 2.1 通用入口锁定长篇

- 执行 `novel-writer-create-project`。
- 弹窗标题：`新建长篇小说项目`。
- 模式按钮组 `display:none`，短篇/剧本按钮不可见。
- 创建按钮：`创建长篇小说项目`。

### 2.2 短篇前期调研与创建

- 执行 `novel-writer-create-short`。
- 弹窗标题：`📚 短篇前期调研`。
- 字段完整：项目名称、番茄主分类（24+1 选项）、目标字数、目标节数、故事核、反转、五维标签等。
- 填写「验证短篇调研入口 / 婚姻家庭 / 80000 字 / 20 节」后进入锁定模式的创建弹窗。
- 创建成功：
  - `.project`：`创作模式 short`、`短篇分类 婚姻家庭`、`目标字数 80000`。
  - `00-前期调研/调研数据.json`、`调研报告.md`、`五维分类.md` 均生成。
  - 调研报告包含故事核、反转、结尾兑现与五维标签。

### 2.3 剧本前期调研与创建

- 执行 `novel-writer-create-script`。
- 弹窗标题：`🎬 剧本前期调研`。
- 字段完整：剧名、红果类型（12+1 选项）、目标字数/集数、单集时长、3 秒钩子、爽点、付费卡点、人物/场景等。
- 创建成功：
  - `.project`：`创作模式 script`、`剧本类型 都市逆袭`、`目标字数 60000`、`目标集数 80`。
  - `00-前期调研/调研报告.md`、`剧本定位.md`、`调研数据.json` 均生成。

### 2.4 右侧快捷工具按类型切换

| 选中项目 | 工具标题 | 项目操作 | 工具组 |
|---|---|---|---|
| 长篇《九霄逆脉行》 | ⚡ 快捷工具 | 项目向导、继续写作、全部章节… | 核心写作、项目规划、章节生成、设定与实体、审查与优化、工具与维护 |
| 短篇「验证短篇调研入口」 | ⚡ 短篇快捷工具 | 前期调研、继续写作、全部节… | 短篇创作、写作辅助、设定与实体、工具与维护 |
| 剧本「验证剧本调研入口」 | ⚡ 剧本快捷工具 | 前期调研、继续写作、全部集… | 剧本创作、写作辅助、设定与实体、工具与维护 |

- 短篇工具中不再出现「全书规划」「批量建章」「章节结算」「跨卷状态继承」。
- 剧本工具中不再出现上述长篇动作。
- 切换回长篇卡片后，长篇工具与项目操作恢复。

### 2.5 批量建章跟随当前项目

- 选中短篇项目点击「批量建节」：
  - 项目下拉框：`验证短篇调研入口`
  - 标题：`📦 批量建节（短篇模式）`
  - 按钮：`创建 20 节骨架`
- 选中剧本项目点击「批量建集」：
  - 项目下拉框：`验证剧本调研入口`
  - 标题：`📦 批量建集（剧本模式）`
  - 按钮：`创建 80 集骨架`

### 2.6 已创建项目的调研编辑

- 选中短篇项目点击「前期调研」：
  - 弹窗回显名称、主分类、故事核等；
  - 项目名称/主分类/目标规格禁用，避免与 `.project` 脱节；
  - 按钮为「保存调研」。
