# 长篇小说：v4.26 路径与设置优化说明

> 2026-11-03 · 插件 4.26.0

## 1. 路径优化

- **项目库根目录单一来源**：`长篇小说` 由 `shared/creation-mode.ts` 的 `CREATION_MODE_SPECS.long.rootDir` 提供，`domains/kernel/project-locator.ts` 只做再导出；项目识别、新建、导出、设置页都读同一份。
- **模块引用别名**：运行时代码跨目录引用统一为 `@/layer/file`（全仓 2043 处），不再出现 `../../..`；同目录仍用 `./`。别名同时配置在 `tsconfig.json`、`scripts/build.js`（esbuild alias）、`vitest.config.ts`。
- **内容路径**：正文/步骤结果仍由 `shared/paths.ts` 统一拼接；长篇章节目录 `03-大纲与章节/正文/第N卷` 未改动，保证存量项目直接可用。
- **开发/构建/部署**：`npx tsc --noEmit`、`npm run build`、`npm test`、E2E 均通过；esbuild 产物中别名已在打包期解析，部署包无运行时路径依赖。

## 2. 设置界面

- 新增「📚 创作模式」分区：展示长篇的项目库根目录、内容结构与单元规格，作为三类项目的路径总览。
- 「写作配置」保持五组：篇幅与字数 / 正文形态 / 上下文与模型 / 质量闸门与修订 / 阈值与词表；新增字数上下限实时校验（最小≤默认≤最大，不一致时行内提示）。
- 「写作规则」页：唯一来源 `元文件/00-系统模板/写作规则.md`，显示版本、模式附录说明，可重新检查/查看/在 Obsidian 中打开；删除版本下拉与漂移告警。

- 单测：路径别名测试（无 `../` 引用、三处别名配置、模式根目录一致）+ 设置结构测试。
