# v4.19.0 三分类导航与内容隔离验证报告

- 日期：2026-10-26
- 版本：4.19.0（本地工作树）
- 范围：左侧三分类入口、短篇/剧本独立目录、专属卡片/工具、批量与导出链路、长篇回归

## 一、本次改动

### 1. 左侧三分类导航

项目与章节页左侧新增：

```text
创作分类
📖 长篇小说  N
📄 短篇小说  N
🎬 剧本      N
```

- 按 `.project` 的 `creationMode` 过滤项目；缺失按长篇。
- 切换分类后只显示本类项目，并同步切换右侧工具与项目操作。
- 从外部高亮项目时自动切到其所属分类。
- 空分类显示本类专属创建入口。

### 2. 短篇/剧本独立内容结构

短篇新项目：

```text
{项目}/
  00-前期调研/
  00-系统模板/创作模式指南.md
  短篇创作/
    01-故事核/故事核.md
    02-分节大纲/分节大纲.md
    03-正文/第NN节.md
    04-质检/
    05-导出/
```

剧本新项目：

```text
{项目}/
  00-前期调研/
  00-系统模板/创作模式指南.md
  剧本创作/
    01-人物与场景/场景圣经.md
    02-分集大纲/分集大纲.md
    03-剧本/第NN集.md
    04-分镜/分镜表.md
    05-质检/
    06-导出/
```

- 新短篇/剧本项目不再复制长篇 `03-大纲与章节`。
- 批量建节/建集只写 `短篇创作/03-正文` 或 `剧本创作/03-剧本`，不生成长篇步骤文件。
- 导出、列表、卡片统计统一读取模式正文目录；旧项目保留长篇结构作为兼容回退。

### 3. 专属卡片与工具

- 短篇卡片：`前期调研 / 写作 / 全部节`，显示 `N节`、已完稿/下一节。
- 剧本卡片：`前期调研 / 写作 / 全部集`，显示 `N集`、已完稿/下一集。
- 短篇工具：新建短篇、前期调研、故事核、分节大纲、批量建节、成稿导出。
- 剧本工具：新建剧本、前期调研、场景圣经、分集大纲、分镜表、批量建集、成稿导出。
- 移除短篇/剧本的协同写作工作台、全书规划、批量建章、章节结算、跨卷状态等长篇动作。
- 新增 `ModeDocumentModal`，用于编辑故事核/分节大纲/场景圣经/分集大纲/分镜表。

### 4. 项目上下文修复

- 批量建章/导出/调研/模式文档命令优先使用工作台当前选中的项目，其次 activeFile；
- 从短篇/剧本卡片点击批量建节/建集，不再落到项目列表第一个长篇项目。

## 二、运行时验证

### 2.1 分类切换

| 分类 | 显示项目 | 右侧工具标题 |
|---|---|---|
| 长篇小说 | 仅长篇项目 | ⚡ 快捷工具 |
| 短篇小说 | 仅短篇项目 | ⚡ 短篇快捷工具 |
| 剧本 | 仅剧本项目 | ⚡ 剧本快捷工具 |

- 短篇分类下不显示长篇/剧本卡片；剧本分类下不显示长篇/短篇卡片。
- 切回长篇后，长篇工具与项目操作恢复。

### 2.2 短篇全流程

1. 新建短篇 `验证短篇独立目录`。
2. 目录生成 `短篇创作/01-故事核`、`02-分节大纲`、`03-正文`、`04-质检`、`05-导出`；无 `03-大纲与章节`。
3. 批量建节 2 个：生成 `短篇创作/03-正文/第01节.md`、`第02节.md`。
4. 卡片显示 `2节`，详情显示 `总节：2 / 下一节：第1节`。
5. 「继续写作」直接打开 `第01节.md`，不进入长篇 11 步向导。
6. 导出弹窗显示 `共 2 节`，导出稿为 `# 第1节 / # 第2节`，无卷标题。

### 2.3 剧本全流程

1. 新建剧本 `验证剧本独立目录`（40 集）。
2. 目录生成 `剧本创作/01-人物与场景`、`02-分集大纲`、`03-剧本`、`04-分镜`、`05-质检`、`06-导出`；无 `03-大纲与章节`。
3. 批量建集 1 个：生成 `剧本创作/03-剧本/第01集.md`。
4. 卡片显示 `0集`（未写正文）与专属按钮；批量建集默认当前剧本。
5. 「分镜表」打开展示镜号/景别/运镜/台词模板；保存后文件更新。
6. 模式正文骨架包含 `# 第1集`、场次、人物、动作、对白。

### 2.4 长篇回归

- 长篇分类仍显示原有项目。
- 长篇卡片保留「向导 / 写作 / 句级协同 / 全部章节」。
- 长篇右侧仍为原六组工具：核心写作、项目规划、章节生成、设定与实体、审查与优化、工具与维护。
- 长篇 `03-大纲与章节`、11 步流程未改。

1. 长短篇/剧本项目仍在 vault 根目录下，通过各自 `短篇创作/`、`剧本创作/` 内容根隔离；项目名空间仍共享。

3. 短篇/剧本生成流程目前仍由模式内文档、批量骨架和导出组成；完整 AI 10 步/9 步 Runner 仍属于后续架构任务。
4. 短篇/剧本工具保留文笔风格、实体、同人等通用能力；长篇专属规划/结算/跨卷动作已移除。
