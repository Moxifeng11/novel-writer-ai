## 3. 问题清单

| 编号 | 等级 | 问题 | 状态 |
|---|---|---|---|
| B-1 | 阻断 | 声明 `minAppVersion=1.5.0`，却调用晚于 1.5 的 `Vault.getAllFolders()` | ✅ 已修复 |
| B-2 | 阻断（需求） | `Modal.setTitle()` 仅 1.5+，与「支持 Obsidian 1.4」要求冲突 | ✅ 已修复（类型级验证） |
| S-1 | 严重 | 桌面宠物 SVG 常驻动画导致空闲主线程 CPU 10.2%，超过 5% 阈值 | ✅ 已修复 |
| G-1 | 一般 | `splitBy:'paragraph'` 模拟流丢失 `\n\n`，正文段落粘连 | ✅ 已修复 |
| O-1 | 优化 | 开发依赖（Vitest/Vite 链）39 条安全告警 | ⏳ 登记，不阻塞 |
| O-2 | 优化 | macOS/Linux/移动端与 1.4/1.5 实机未执行 | ⏳ 残余风险 |

### B-1 阻断：最低版本声明与实际 API 不符

- **复现**：用 `obsidian@1.5.7` 类型定义编译源码 → `shared/file-system-port.ts` 报 `Property 'getAllFolders' does not exist on type 'Vault'`。运行期在 1.5.x 调用 `listFolders()`（知识库刷新会走到）会抛 `TypeError`。
- **影响范围**：声明支持但实际会崩的 1.5.x–该 API 引入前的版本；知识库目录列举失败。
- **修复**：`listFolders()`/`getFolders()` 改为沿 `TFolder.children` 递归，语义等价且只依赖 1.4 已有 API。
- **回归**：新增 `tests/unit/shared/file-system-port-folders.test.ts`，断言递归结果正确且 `getAllFolders` 从未被调用。

### B-2 阻断（需求）：Obsidian 1.4 不可用

- **复现**：用 `obsidian@1.4.0` 类型定义编译 → `ui/batch-import-modal.ts` 两处 `Modal.setTitle()` 报错。
- **影响范围**：Obsidian 1.4.x 用户无法通过最低版本校验，或运行到批量导入时出错。
- **修复**：改为 `pickerModal.titleEl.setText(...)`（1.4 起可用）；`manifest.minAppVersion` 下调为 `1.4.0`，`versions.json` 同步 `4.25.0 → 1.4.0`。
- **回归**：全源码对 `obsidian@1.4.0` 与 `obsidian@1.5.7` 类型编译均 0 error。
- **残余风险**：未安装 Obsidian 1.4 实机，运行时行为（弹窗标题布局）未做视觉回归。

### S-1 严重：桌面宠物空闲 CPU 超阈值

- **复现**：`E2E_PERF=1` 启动真实 Obsidian，空闲 5 秒采样；插件相对无插件基线 CPU 增量 **10.22%**。
- **根因**：SVG 内层 `nw-pet-float` / `nw-pet-tail` / `nw-pet-blink` 无限动画触发逐帧重绘；`transform` 作用在 SVG 子元素上无法走合成层。
- **修复**：新增内层 `.nw-pet-float` HTML 容器承载浮动动画（合成层）；移除尾巴与眨眼常驻动画；点击目标 `.nw-pet-body-wrap` 保持几何稳定。
- **回归**：空闲 CPU 增量降至 **0.21%–0.23%**（两次采样）；堆增量 24–30 MB、5 秒堆增长 0；宠物单击/双击 E2E 通过。

### G-1 一般：段落流式输出粘连

- **复现**：`splitTextIntoChunks('第一段。\n\n第二段。', { splitBy: 'paragraph' })` 再 `join('')` 得到 `第一段。第二段。`。
- **影响范围**：按段落模拟流式输出的调用方；默认 `sentence` 模式不受影响。
- **修复**：手动扫描分隔符并把 `\n\n` 保留在前一段末尾；新增 `chunks.join('') === 原文` 断言。

### O-1 / O-2 优化建议

- 开发依赖 39 条告警集中在 Vitest 1.6 / Vite 链（含 3 critical），均为构建期工具，不进入 `main.js`；建议单独排期升级到 Vitest 3+ 并回归覆盖率。
- macOS/Linux/移动端与 1.4/1.5 实机缺口，建议在 CI 增加 macOS runner 的构建冒烟，并在发布前用 1.4.0 安装包做一次手工冒烟；移动端至少验证插件启用、项目打开、正文读写三条路径。

## 6. 残余风险

1. 1.4/1.5、macOS/Linux、移动端均为类型/静态级验证，未做真机执行。
2. 长时稳定性仅做 5 秒空闲堆采样与 3 轮生命周期，未覆盖小时级连续写作。
3. 开发依赖告警未升级；不影响发布产物，但建议在下一迭代处理。
4. 性能阈值基于渲染进程主线程 `TaskDuration`，与操作系统任务管理器的整机 CPU 口径不同；基线对照已消除 Obsidian 自身开销。
