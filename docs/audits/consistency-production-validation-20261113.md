# 一致性审核 · 生产端验证报告（2026-11-13）

> 目的：验证 v4.88.0 的 19 子类检测在**真实 vault + 真实 AI** 下的**召回率与误报率**。
> 这是 MVP 唯一还没被检验的假设——"功能做得全"不等于"真的抓得到、且不乱报"。

## 一、方法与样本

构造一部 10 章的中式修真小说骨架（真实 vault、真实插件、真实命令路径）：

- **植入 6 处矛盾**（预期应命中）
- **植入 3 处"合法变化"陷阱**（预期**不该**命中）
- 断言 20 条，正文 301 字

| # | 植入项 | 类型 | 章节 |
|---|---|---|---|
| 1 | 林轩 18 岁 → 16 岁 | 数量不符 | 第1 / 第5章 |
| 2 | 记得青铜钥匙 → 忘了青铜钥匙 | 记忆矛盾 | 第1 / 第20章 |
| 3 | 设定「不能御空飞行」→ 后文御空飞行 | 核心规则违规 | 第1 / 第8章 |
| 4 | 试炼「持续三日」→「历时两个月」 | 时长矛盾 | 第12 / 第30章 |
| 5 | 化名「林三」→ 化名「林四」 | 命名混淆 | 第12 / 第25章 |
| 6 | 第40章 第一/第三人称混用 | 视角混乱 | 第40章 |

**误报陷阱**（合法变化，绝不该报）：
- 修为等级 练气三层 → 筑基一层（进阶）
- 所属势力 青云宗 → 血刀门（转投）
- 外貌特征 新增左眉有疤（剧情发展）

## 二、结果

| 指标 | 值 |
|---|---|
| 断言抽取 | 20 条（浮出 6 种 kind） |
| **命中** | **3 / 6 = 50%** |
| **误报** | **0 / 3 = 0%** |
| 疑似（交复核） | 0 |
| 高风险段定位 | 10 段 |
| CED | 99.67 处/万字符（3 处 / 301 字） |

### 命中（正确）

| 类型 | 结论 | 置信度 |
|---|---|---|
| 数量不符 | 第1章「林轩」18 岁，到第5章反而变成 16 岁——年龄不可能倒退 | 92% |
| 记忆矛盾 | 林轩记得「青铜钥匙」，第20章又说忘了「青铜钥匙」 | 82% |
| 视角混乱 | 同一章内第一人称 3 处、第三人称 3 处，比例接近 | 60% |

### 未命中（3 处漏报，均为可修的实现缺口）

| 漏报 | 根因 | 修法 |
|---|---|---|
| 核心规则违规 | 违规文本「林轩御空飞行」未成为**断言**（无数字/无匹配模式），而规则匹配只扫断言集合 | 规则层应同时扫**原始 facts 文本**，不只扫断言 |
| 时长矛盾 | 「试炼持续三日 / 历时两个月」这类**事件时长埋在 facts 自由文本**里，未被抽成 `absolute-time` 断言（当前只从 timeSpan 与台账事件抽取） | 新增 facts 中的「事件 + 时长」抽取模式 |
| 命名混淆 | 抽取正则要求「化名**是/叫/为** X」，而实际写法是「林轩化名林三」（无系词） | 放宽为「化名 + 名字」直接相邻 |

### 误报（0 —— 这是本报告最重要的结论）

3 处**合法变化陷阱全部未被误报**：

```
修为等级 练气三层 → 筑基一层      ✓ 未报
所属势力 青云宗 → 血刀门          ✓ 未报
外貌特征 新增左眉有疤             ✓ 未报
```

说明 v4.88.0 「7 个子类只进疑似、不做值比对」的取舍**在真实数据上成立**：
没有把合法成长判成 bug。

## 三、结论

1. **精度设计有效**：误报 0，合法成长没有被误伤。这是体检类工具能否被信任的前提。
2. **召回 50%**，缺口全部是**抽取覆盖面**问题，不是判定逻辑问题——三处漏报都有明确的小修法，且不影响已通过的精度。
3. 检测链路本身在真实环境工作正常：断言落盘、矛盾落盘、证据双侧带章节、CED 与高风险段都有输出。
