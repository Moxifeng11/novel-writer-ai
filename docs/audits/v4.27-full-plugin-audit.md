## 六、同源根因（归并）

1. **「同一事实多处各自解释」**（P0-2/3/5、P1-1/2/4）：正文/伏笔/指纹/缓存都有多个读写入口，锁与失效键不统一。→ 修法是**收口到单一入口 + 统一键**，而不是逐处打补丁。
2. **「失败被降级为日志」**（P0-1、P1-10/11/12）：迁移、配置、结算、frontmatter 失败都只 warn。→ 修法是**失败必须可见**（Notice/账本/阻断），与 v4.25「上下文体检」同一思路。
3. **「门禁只防新增、不防存量」**（G-4）：基线棘轮是刻意的，但不能替代「存量清单化」。→ 不修语义，只补文档与到期日。
4. **「实现与守卫两套口径」**（P1-7/8/9）：命令能做什么（catalog）与允许做什么（mode-rules）分处两文件且无一致性测试。→ 修法是**双向一致性单测**。
