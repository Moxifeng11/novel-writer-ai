# v4.19.0 写作指纹库与知识库优化验证报告

- 日期：2026-10-25
- 版本：4.19.0（本地工作树，未提交远端）
- 范围：写作指纹库 / 知识库管理界面的布局与响应式、数据加载与错误处理、指纹与知识匹配算法、识别结果自动分类与标签化

## 一、动因与问题定位

本轮针对四类问题：

1. **布局与响应式**：指纹库与知识库主布局使用固定宽度左栏，窄面板下左右栏互相挤压；指纹列表计数每次渲染追加到侧栏，重复累积。
2. **稳定性**：书籍列表/详情读取失败时页面只显示空白或停留在“加载中”；指纹加载失败没有可重试入口；重新加载后选中项可能已不存在。
3. **算法准确率**：
   - 指纹统计把分号当句末，中文长句被拆成多句，平均句长偏低；
   - 段落只按空行切分，网文“一行一段”会把整章算成一段；
   - 英文双引号规则重复匹配，同一段对话被计两次，对话占比可超过 100%；
   - 向量检索只看向量分数，关键词/标签完全没参与重排，同分结果顺序不稳定。
4. **自动分类缺失**：指纹和书籍没有统一的、可复现的分类规则，也没有把分类结果写成结构化标签的入口。

## 二、实现内容

### 2.1 自动分类器

新增 `shared/content-classifier.ts`：

- 维度：节奏、语言、情绪、对话、结构、题材、技法、商业、受众。
- 指纹规则：
  - 平均句长 ≤12 / ≥28 / 其余 → 短句快节奏 / 长句舒展 / 句长均衡；
  - 短句占比 ≥40%、长句占比 ≥20%、句长标准差 ≥18；
  - 对话占比 ≥35%、对话段占比 ≥30%、对话占比 ≤12%；
  - 描写占比 ≥55% 或 ≤30%、平均段长 ≥180 或 ≤60、词汇多样性 ≥55%；
  - 特征描述关键词：冷峻克制、细腻抒情、轻松诙谐、悬疑紧张、宏大悲壮、古风雅致、强冲突快节奏、治愈温暖。
- 书籍规则：频道、主题材、题材/自定义标签、技法标签、文案关键词、字数区间、质量均分（忽略 `vectorEnabled` 等非数值字段）。
- 所有规则确定性执行；同输入同结果，不调用 AI。
- 分类标签统一使用 `分类:` 前缀，`mergeClassificationTags()` 会替换旧分类标签、保留用户标签、去重并限制 30 条。
- 统计全零（旧指纹或提取失败）时不产出“叙述为主”等假阳性标签。

### 2.2 指纹库界面

`ui/views/writing-fingerprint-view.ts`：

- 列表项显示自动分类主标签与标签数量；详情页新增“🏷️ 自动分类”区块，展示摘要、维度徽章、置信度与命中原因（tooltip）。
- 工具栏新增“🏷️ 自动归类”，按 template/global/project 写回当前指纹标签。
- 修复计数重复：计数节点保存引用，重渲染前移除，不再累积。
- 加载失败显示错误态与“重试”；重载后若选中指纹已不存在，清空选中并回到引导页。
- 统计卡片“平均段长”单位由错误的“句”改为“字”。

### 2.3 知识库界面

`ui/views/knowledge-base-view.ts`：

- 书籍卡片显示自动分类主标签与前 3 个维度标签；详情页标题下新增分类摘要条，可一键“写入标签”。
- 详情操作区新增“🏷️ 维度归类”；工具栏新增“🏷️ 批量归类”，逐本写入、已最新则跳过，结束提示更新/跳过数量。
- `loadBooks()` 增加异常捕获与错误态；列表提供“重试”。
- `loadBookDetailData()` 捕获 `getBook` 失败，详情区显示错误与重试，不再停留在加载态。
- 复用原有 `updateBook()` 写入，其他字段与拆解数据不变。

### 2.4 指纹统计口径

新增 `engine/fingerprint-stats.ts`，从 `fingerprint-extractor.ts` 抽出可测试的统计函数：

- 句子按 `。！？!?…` 切分，分号不再算句末。
- 段落按单换行切分，适配网文“一行一段”。
- 对话字符去重统计，修复重复引号规则导致的翻倍；补齐中文弯引号 `“”`。
- 输出句长标准差、短/长句占比、对话段占比、段长标准差、词汇多样性。
- `fingerprint-extractor.ts` 改为调用该模块；AI 特征为空时继续使用本地统计兜底。

### 2.5 检索算法

- 新增 `shared/keyword-tokens.ts`：中文 2-gram + 英文/数字词，统一指纹库与知识库的分词口径。
- 指纹库 `searchSimilarStyles`：
  - 向量结果叠加关键词命中（上限 0.08）与标签命中（每个 0.03，上限 0.06）；
  - 同一指纹只保留最高分结果，再统一排序。
- 知识库 `search`：
  - 最终分数 = 向量相似度 × 0.9 + 关键词覆盖率 × 0.1；
  - 按 `bookId|dimension|sample 前缀` 去重后再过滤与截断。

### 2.6 响应式与视觉

`styles.css` 新增 `.nw-fingerprint-*` / `.nw-kb-class-*` / `.nw-*-error`：

- 视图启用 `container-type: inline-size`，按面板实际宽度而非窗口宽度响应。
- ≤860px 主布局改为纵向：左栏占满宽度，高度受限并可滚动；知识库导航改为横向换行。
- 分类徽章、维度标签、摘要条、错误态统一使用主题变量，不新增硬编码颜色。
- ≤560px 进一步压缩工具栏间距与分类摘要布局。

### 3.3 兼容性

- 旧指纹统计字段仍为可选；缺少扩展字段时分类器不抛错，只跳过对应规则。
- `classifyFingerprint`/`classifyBook` 使用结构化入参接口，不反向依赖 `engine`，避免分层违规。
- 分类标签只写 `customTags`，保留原有题材、技法、拆解结果与用户标签；重复执行结果稳定。
- 知识库未新增文件格式或迁移；`updateBook()` 原有改名/向量文件同步逻辑不变。
- 长篇、短篇、剧本既有流程未改动。
