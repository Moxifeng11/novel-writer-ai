## 同人设定硬门禁（本轮新增）

```text
05-同人设定库/
  {作品}设定.md                 # 仅 approved
  _待审核/{作品}设定.md          # pending / rejected
  _资料/{作品}/sources.json      # 官方来源、摘录、哈希
  _审核/{作品}_审核记录.md       # 人工审核记录
```

- 只接受官方/官方 Wiki 作为事实依据；同人、改编、外传、动画/影视/游戏/漫画等默认排除。
- 没有官方来源时只能生成骨架或“待核实”，不能凭模型记忆补全。
- 审核通过前：
  - 不能绑定 `.project`；
  - `readFanficRules` 返回 `unreviewed`；
  - 协同写作不注入任何同人约束。
- 审核通过后修改文件或来源，来源哈希不匹配 → 自动失效，需重新审核。
- 旧文件无 `审核状态` 按 legacy 兼容，但提示建议重新审核。
