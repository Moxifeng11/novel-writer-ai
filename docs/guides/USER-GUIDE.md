# 小说工坊使用手册（Agent 对话 + 多步骤协同写作）

> 适用版本：v4.52.0+ · 更新：2026-11-06
> 面向：长篇 / 短篇 / 短剧作者。目标是在 Obsidian 内完成「设定 → 大纲 → 正文 → 质检 → 结算 → 导出」全流程，数据全部留在自己的 Vault。

## 1. 安装与首次配置

1. 在 Obsidian 中启用 `novel-writer-ai` 插件（设置 → 第三方插件）。
2. 打开插件设置，填写一个兼容 OpenAI 协议的 API Key 与 Base URL（云端或本地 Ollama 均可）。
3. 选择默认模型；对话与正文可使用不同模型，工作台输入条上方可随时切换。
4. 可选：导入知识库 / 文笔指纹库，用于 RAG 注入与风格一致性检查。

## 2. 三分钟创建第一个项目

1. 打开「Agent 创作工作台」（命令面板搜索 `Agent 创作工作台`）。
2. 直接对 Agent 说：`新建一部长篇，都市异能，男频，主角能看见他人寿命`。
3. Agent 会补齐缺失项并给出设定摘要；确认后调用创建工具。
4. 创建完成后，左栏「创作阶段」会显示当前项目真实进度与下一步。

## 3. Agent 工作台怎么用

- **对话即操作**：自然语言描述目标，Agent 会调用插件工具（创建项目、打开章节、运行命令、读取文件等）。
- **阶段面板**：左栏显示当前模式的全部阶段（长篇：初始化 → 章节写作 → 结算 → 导出；短篇/剧本见第 4 节），显示完成百分比、下一步与阻塞原因。点击任一阶段会把「继续该阶段」预填到输入框，由你确认后发送。
- **人工确认**：写入文件、批量生成、结算、导出等高成本操作会弹确认框；Agent 不会静默执行。
- **会话存档**：每个回合写入 `.sessions/agent/<项目>.jsonl`；工具结果过大时落盘到 `.sessions/spill/`，可用 `read_file` 按路径读取。
- **项目切换**：点击左栏项目卡即可切换 Agent 的当前项目；输入框支持 `@` 引用库内文件。

常用话术：

| 目标 | 可以对 Agent 说 |
|---|---|
| 补设定 | `把主角的动机改成「为妹妹筹钱」，并补进人物卡` |
| 调方向 | `这一章不要打脸，改成调查线索；重写第 3 章大纲` |
| 生成章节 | `写第 5 章，3000 字，结尾留钩子` |
| 润色 | `第 5 章对白太 AI，按人物口吻润色，保留剧情` |
| 风格检查 | `对照文笔指纹检查第 5 章，列出最不一致的三段` |
| 质检 | `运行第 5 章质检并给出修改建议` |
| 结算 | `把第 5 章的实体、伏笔、时间线变动结算回设定库` |
| 导出 | `导出 EPUB，作者填「某某」，开启严格出版检查` |

## 4. 三模式流水线

| 模式 | 阶段 | 主要产物 |
|---|---|---|
| 长篇 | 初始化与全书规划 → 章节写作 → 章节结算 → 成稿导出 | 世界观/人物/势力、分卷章节、11 步章节产物、结算表 |
| 短篇 | 前期调研 → 分节大纲 → 分节写作 → 导出 | 五维分类、故事核、分节目标/冲突/反转、平台包 |
| 剧本 | 前期调研 → 分集大纲 → 分镜表 → 分集写作 → 导出 | logline、分集钩子、镜号表、可拍性质检 |

单章正文有两条路径，共用同一正文文件与格式契约：

- **整章生成**：一键成文 / 批量成文，适合快速出稿。
- **句级协同**：进入协同写作视图，逐句接受/修改建议，适合精修与风格控制。

## 5. 导出与出版检查

导出入口：命令面板 `成稿导出`，或在 Agent 工作台说「导出成稿」。

- 支持 Markdown / TXT / HTML / EPUB / DOCX；EPUB 可嵌入项目内 `封面/cover.png`。
- 作者字段用于 EPUB/DOCX 元数据；不写进正文。
- 导出前会提示未结算、未过质控、未完成单元，以及商业化出版检查结果。
- 勾选「严格出版检查（阻断导出）」后，缺作者、空正文、严重字数不足等阻断项会中止导出。该模式按**整包交付**口径校验（含任一空节/空集），只导样章或部分单元时请保持关闭。

## 6. 数据在哪里

| 数据 | 位置 |
|---|---|
| 项目正文/大纲/设定/结算 | Vault 内对应项目目录（`长篇小说/`、`短篇小说/`、`剧本/`） |
| 插件设置 | `.obsidian/plugins/novel-writer-ai/data.json`（Vault 内，Obsidian 标准位置） |
| Agent 会话 | `.sessions/agent/*.jsonl`、`.sessions/spill/` |
| 版本快照/步骤产物/配置备份 | 项目目录与备份中心（命令 `版本与备份中心`） |

建议把整个 Vault 纳入 Git 或同步盘；`.sessions/` 与缓存可按需排除。

## 7. 常见问题

- **Agent 无法回复**：检查 API Key、Base URL、模型名；无凭据时会自动降级为规则引擎，只能做导航。
- **阶段面板显示「阶段读取失败」**：切换一次项目或重新打开工作台；仍失败时检查项目 `.project` 文件是否损坏。
- **导出被阻断**：按提示补作者、补空章正文、确认字数；临时关闭严格模式可跳过阻断（不建议用于正式投稿）。
- **字数统计口径**：导出与出版检查使用 CJK 字数；frontmatter 的 `word_count` 仅作摘要展示。
- **批量生成中断**：在任务中心查看失败原因；可重试或改用单章生成。
