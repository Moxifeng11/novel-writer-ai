# 剧本场景分镜创作规范

## 一、适用范围与基本口径

- 平台：红果短剧快车道
- 形态：竖屏短剧优先，单集 60–120 秒，40–120 集
- 单集场次：3–6 场
- 内容层级：**集 → 场 → 镜 → 节拍**
- 核心原则：**3 秒抓人、每集一个冲突、每集一个兑现、每集结尾一个钩子、全部可拍**

剧本不是“把小说分行”。小说可以写心理、铺环境、多线并行；剧本必须把一切转成可见画面、可听对白、可执行动作。

---

## 二、九步独立创作流程

```text
T0 项目初始化（类型/集数/时长/受众）
  ↓
T1 一句话卖点与首集钩子
  ↓
T2 人物、关系与场景圣经
  ↓
T3 分集大纲（40–120 集）
  ↓
T4 前 3 集强钩子与付费点设计
  ↓
T5 分集剧本（场次）
  ↓
T6 分镜表（镜号）
  ↓
T7 商业节奏与可拍性质检
  ↓
T8 导出与平台适配
```

### T0 项目初始化

**输入**：剧本类型（红果 12 类）、目标集数、单集时长、目标受众、竖屏/横屏。

**输出**：`00-剧本配置/创作配置.md`、`流程状态.json`。

**规则**

- 集数 40–120；单集 60–120 秒；总字数 5–10 万。
- 类型必选：都市逆袭、战神归来、甜宠、虐恋、复仇、家庭伦理、古装权谋、悬疑、脑洞、年代、民国、萌宝。
- 明确“主场景清单”：主要 2–4 个场景，控制置景成本。
- 明确“付费卡点集数”：默认第 10–15 集。

### T1 一句话卖点与首集钩子

**输出**：`01-卖点/一句话卖点.md`、`首集钩子.md`。

**必须回答**

- 主角是谁、被谁压迫、失去什么？
- 观众前 3 秒看到什么冲突/羞辱/危机/身份错位？
- 主角的金手指/隐藏身份/核心秘密是什么？
- 第一集结尾钩子是什么？
- 观众追下去的情绪承诺是什么（爽/甜/虐/悬/燃）？

**质量门**

- 3 秒钩子必须是一个**可见事件**，不是旁白介绍。
- 一句话卖点 ≤ 60 字，包含主角 + 压迫 + 反转预期。

### T2 人物、关系与场景圣经

**输出**：`02-人物/人物小传.md`、`关系图.md`、`场景圣经.md`。

**人物小传**

- 主角：身份、欲望、伤口、秘密、能力边界、说话方式、标志动作。
- 对手：压迫手段、资源、弱点、动机。
- 关键关系人：爱人/家人/盟友/证人；与主角的权力与情感关系。
- 功能角色：萌宝、助攻、反派打手；总核心人物 ≤ 8。

**场景圣经**

- 场景名、内外景、日/夜、空间布局、关键道具、可拍条件。
- 每个场景至少服务 2 集，避免一次性场景。
- 明确危险动作、儿童/动物、特殊道具的拍摄限制。

### T3 分集大纲

**输出**：`03-分集大纲/分集大纲.md`。

**每集必须写**

| 字段 | 要求 |
|---|---|
| 集号/标题 | 第N集 + 一句钩子式标题 |
| 本集核心冲突 | 谁要什么、谁阻止 |
| 情绪升级 | 从什么情绪到什么情绪 |
| 可兑现爽点/甜点/虐点 | 具体画面或台词 |
| 结尾钩子 | 下一集必须回答的问题 |
| 场次数 | 3–6 场 |
| 预计时长 | 60–120 秒 |

**结构**

- 前 3 集：主角处境、核心冲突、金手指/身份悬念、第一次强兑现。
- 第 10–15 集：强付费卡点。
- 每 5–10 集：升级一次冲突/对手/目标。
- 最后 3 集：连续兑现，主线收束，最后一个反转或情绪落点。

### T4 前 3 集强钩子与付费点

**输出**：`03-分集大纲/前3集钩子.md`、`付费点设计.md`。

**前 3 集硬指标**

- 第 1 集前 3 秒出现冲突/羞辱/危机/身份错位。
- 第 1 集结尾必须让观众想知道“主角会怎么反击/身份什么时候揭晓”。
- 第 2 集升级压迫，第 3 集完成第一次强兑现。
- 第 3 集结尾埋付费卡点：真相、身份、关系或生死危机。

**付费点**

- 默认第 10–15 集设置强卡点；此前每 2–3 集有小钩子。
- 卡点必须是“情绪/信息/生死”三选一，不能只是“请看下一集”。

### T5 分集剧本（场次）

**输出**：`04-剧本/第NN集.md`。

**格式**

```markdown
## 第01集 标题

- 时长：90 秒
- 本集钩子：
- 本集核心冲突：
- 本集兑现：
- 结尾钩子：

### 1-1 日/内 客厅

人物：林晚、婆婆、丈夫

△林晚端着汤进门，婆婆抬手打翻，汤泼在她手背上。

婆婆：（冷）连碗汤都端不稳，你还能干什么？

林晚：（低头，手背通红）我重新做。

△丈夫低头看手机，没有抬头。

（特写：林晚手背上的烫伤；手机屏幕上是婆婆发来的“离婚协议”。）

### 1-2 夜/内 卧室

...
```

**场次规则**

- 每场必须有冲突或信息变化；没有变化的过场删除。
- 每场开头用场景标题交代：集-场、日/夜、内/外、地点。
- 每场结尾有一个小钩子或情绪推进。
- 单集 3–6 场；单场 10–40 秒为主。

### T6 分镜表

**输出**：`05-分镜/第NN集-分镜.md` 或 `第NN集-分镜.csv`。

**镜头表字段**

| 字段 | 说明 |
|---|---|
| 镜号 | `E01-S01-SH01` |
| 景别 | 远景/全景/中景/近景/特写/大特写 |
| 角度 | 平视/俯拍/仰拍/过肩/主观 |
| 运镜 | 固定/推/拉/摇/移/跟/手持 |
| 时长 | 秒，精确到 0.5 秒 |
| 画面 | 观众看到什么 |
| 动作/表演 | 演员做什么，表情/身体反应 |
| 台词/音效 | 对白、VO、环境声、音效 |
| 转场 | 切/淡/黑/叠化 |
| 目的 | 这场戏/这个镜头完成什么 |

**示例**

| 镜号 | 景别 | 角度 | 运镜 | 时长 | 画面 | 动作/表演 | 台词/音效 | 转场 | 目的 |
|---|---|---|---|---|---|---|---|---|---|
| E01-S01-SH01 | 中景 | 平视 | 固定 | 2.5s | 客厅，婆婆坐在沙发主位 | 婆婆抬眼打量林晚 | 环境声：电视 | 切 | 建立权力关系 |
| E01-S01-SH02 | 特写 | 俯拍 | 固定 | 1.5s | 汤碗被抬手打翻 | 汤泼向林晚手背 | 音效：瓷碗碎裂 | 切 | 3 秒内制造羞辱 |
| E01-S01-SH03 | 近景 | 平视 | 手持 | 2.0s | 林晚手背通红 | 她咬牙不哭 | 婆婆：连碗汤都端不稳 | 切 | 情绪压迫 |
| E01-S01-SH04 | 特写 | 平视 | 推 | 1.5s | 丈夫手机屏幕 | 他拇指划过“离婚协议” | 无台词，消息提示音 | 切 | 埋信息钩子 |

**分镜规则**

- 3 秒内至少一个特写或强动作，抓住注意力。
- 每 10–15 秒有一次景别/机位变化，避免画面呆板。
- 关键信息用特写：手机、合同、伤疤、照片、监控、戒指。
- 竖屏优先：人物近景/特写比例高；避免大远景和横向群像。
- 单集镜头数建议 20–45 个；总时长与剧本时长误差 ≤ 5 秒。
- 每个镜头必须能回答“为什么用这个景别/角度”。

### T7 商业节奏与可拍性质检

**输出**：`06-质检/第NN集-质检.md`、`全剧质检.md`。

**评分（每项 0–20，总分 100）**

| 维度 | 检查点 |
|---|---|
| 3 秒钩子 | 首镜是否有冲突/羞辱/危机/身份错位 |
| 单集冲突 | 是否有明确目标与阻力 |
| 情绪升级 | 是否从一种情绪推到另一种 |
| 兑现 | 是否有可感知的爽点/甜点/虐点 |
| 结尾钩子 | 是否让观众想点下一集 |
| 可拍性 | 场景/动作/道具是否可执行 |
| 对白 | 是否口语、短句、有潜台词 |
| 连续性 | 人物、服装、道具、时间线是否连贯 |

**通过线**：≥ 80 分，且“3 秒钩子/单集冲突/结尾钩子”均 ≥ 12 分。

**红线**

- 靠旁白解释核心冲突。
- 单集没有冲突，只是过场。
- 结尾没有钩子。
- 出现无法拍摄的心理描写/抽象比喻。
- 台词像小说对白，不像人说。
- 付费卡点没有情绪或信息增量。

### T8 导出与平台适配

**输出**

- `07-导出/剧名候选.md`
- `07-导出/人物小传.md`
- `07-导出/分集大纲.md`
- `07-导出/完整剧本.md`
- `07-导出/分镜表.csv`

**规则**

- 剧本标题使用「第N集」；场次使用「N-N 日/内 地点」。
- 导出剧本不含小说式章节标题、卷标题、作者旁白。
- 分镜表可单独导出 CSV，供拍摄/剪辑使用。
- 平台元数据：红果类型、集数、单集时长、受众；不混用短篇五维标签。

## 三、单集节奏模板

以 90 秒为例：

| 时间 | 功能 | 内容要求 |
|---|---|---|
| 0–3s | 强钩子 | 冲突/羞辱/危机/身份错位，必须可见 |
| 3–15s | 处境 | 主角是谁、被谁压迫、失去什么 |
| 15–45s | 升级 | 对手加码，主角尝试失败或隐忍 |
| 45–75s | 转折/兑现 | 主角反击、身份线索、关系变化、爽点兑现 |
| 75–90s | 结尾钩子 | 新危机/真相/误会/下一集问题 |

120 秒版本在 45–100 秒增加一次小高潮或第二次压迫，结尾钩子不变。

### 3.1 前 3 集

- 第 1 集：建立主角处境 + 最大羞辱/危机 + 身份/金手指悬念 + 结尾钩子。
- 第 2 集：对手加码，主角第一次尝试反击失败，暴露代价。
- 第 3 集：第一次强兑现（打脸/身份线索/救援），结尾埋付费卡点。

### 3.2 付费卡点

- 默认第 10–15 集。
- 卡点类型：真相即将揭晓、身份即将曝光、亲人/爱人命悬一线、主角即将反杀。
- 卡点前必须有情绪蓄力；卡点后下一集必须快速兑现，不能拖 3 集以上。

## 四、场景写作规范

### 4.1 场景标题

统一格式：

```text
### 集号-场号 日/夜 内/外 地点
```

示例：

```text
### 1-1 日/内 客厅
### 1-2 夜/外 医院走廊
### 2-1 日/内 公司会议室
```

### 4.2 场景目的

每场必须至少完成两项：

- 推进主线冲突
- 改变人物关系/权力
- 揭示新信息
- 制造情绪转折
- 埋/回收钩子

只有“交代背景”的场景删除或合并。

### 4.3 场景长度

- 单场 10–40 秒为主；重场可 60 秒。
- 单集 3–6 场；超过 6 场会碎，少于 3 场会拖。

### 4.4 场景连续性

- 场景圣经记录：入口/出口、关键道具、人物服装、时间、天气、声音。
- 同一道具在第 1 集和第 10 集出现时，位置与状态必须一致。
- 手机屏幕、合同、病历、监控等特写道具必须提前准备。

---

## 五、对白规范

### 5.1 基本要求

- 说人话：短句、口语、可打断、可有停顿。
- 每句台词至少完成两项：塑造人物、推进冲突、埋信息、情绪变化。
- 潜台词优先：人物说 A，意思是 B。
- 避免“如你所知”式解释；背景信息用冲突/动作/道具带出。
- 单句建议 ≤ 25 字；长信息拆成对话交锋。

### 5.2 对白格式

```text
角色：（情绪/动作提示）台词
```

示例：

```text
林晚：（压住手背的伤，声音很轻）我重新做。
婆婆：（不看她）做完就搬出去。
```

### 5.3 禁止

- 大段旁白解释人物关系。
- 角色互相称呼全名来解释身份。
- 台词里直接说“我们的计划是……”。
- 所有人都用同一种语气说话。

---

## 六、动作与表演规范

### 6.1 动作行

- 统一用 `△` 开头。
- 只写镜头能拍到的动作、表情、身体反应。
- 不写“她心里翻江倒海”，改写为“她攥紧衣角，指节发白”。
- 危险动作标注安全/替身/特效需求。

示例：

```text
△林晚把手缩进袖口，手背的烫伤被布料蹭到，她肩膀轻轻一抖。
```

### 6.2 表演提示

- 情绪提示放在括号内，简短：`（压着火）`、`（强撑笑）`、`（声音发抖）`。
- 不写导演无法执行的抽象指令：`（演出一种被时代抛弃的孤独）`。

### 6.3 镜头与动作配合

- 关键动作拆成 2–3 个镜头：准备 → 发生 → 反应。
- 打脸/摔倒/泼水/撕合同等爽点，必须有特写或慢动作设计。
- 竖屏构图：人物居中偏上，关键道具靠近镜头。

---

## 七、环境与美术规范

### 7.1 环境写法

- 场景标题交代基本时空；正文只写服务剧情的 2–3 个可视细节。
- 环境细节必须服务情绪/权力/信息，不做纯风景描写。
- 用光线、声音、温度、空间压迫感传递情绪。

示例：

```text
△客厅只开了一盏顶灯，婆婆坐在主位，林晚站在茶几旁，影子被压得很短。
```

### 7.2 场景圣经

每个主场景记录：

- 平面布局与入口/出口
- 主光/色温/时间
- 关键道具与位置
- 环境声
- 可拍限制（噪音、邻居、天气、场地许可）
- 连续性问题（哪一集发生过破坏/更换）

### 7.3 制作友好

- 主场景 2–4 个，复用率越高越可控。
- 避免大量群演、复杂特效、儿童/动物长时间拍摄。
- 夜外/雨戏/车祸/跳楼等高风险场景必须提前标注替代方案。

## 八、分镜规范

### 8.1 景别

| 景别 | 用途 |
|---|---|
| 远景 | 交代空间/孤立感；竖屏少用 |
| 全景 | 人物全身关系/动作 |
| 中景 | 对话/关系/肢体冲突 |
| 近景 | 情绪/表情/压迫 |
| 特写 | 关键信息/情绪爆点/道具 |
| 大特写 | 眼神/伤口/手机屏幕/合同字 |

### 8.2 角度

- 平视：常态/对话。
- 俯拍：压迫、弱势、被审视。
- 仰拍：权力、威胁、强势。
- 过肩：对话关系/窥视。
- 主观：观众代入/惊吓。

### 8.3 运镜

- 固定：对话/信息展示。
- 推：情绪逼近/发现。
- 拉：孤立/真相揭示。
- 摇/移：空间关系/跟踪。
- 手持：混乱/冲突/追逐。

### 8.4 镜头节奏

- 3 秒钩子：特写/强动作/冲突台词。
- 对话段：中近景交替，每 5–10 秒切一次。
- 爆点：短镜头 + 特写 + 音效。
- 结尾钩子：定格/特写/黑场 + 一句钩子台词。

### 8.5 时长

- 单镜头 1–5 秒为主；情绪镜头可 5–8 秒。
- 单集镜头总时长与剧本时长误差 ≤ 5 秒。
- 竖屏短剧平均镜头时长建议 2–3 秒，爆点段更短。

## 九、与长篇要素的适配规则

| 长篇要素 | 剧本适配 | 禁止 |
|---|---|---|
| 清晰表达 | 每场目的明确；每句台词有功能；画面可拍 | 长篇式叙述/解释 |
| 设定规范 | 人物小传 + 场景圣经 + 道具连续性表 | 长篇世界观/势力/时间线全套 |
| 分镜演绎 | 集→场→镜→节拍；镜头表 | 长篇 Scene 展开器 |
| 动作表达 | △动作行；可拍身体动作 | 心理独白/抽象比喻 |
| 环境描写 | 场景标题 + 2–3 个可视细节 + 音效 | 长篇环境铺陈 |
| 多线/群像 | 单集单主线；群像服务主线 | 多线并行/视角跳跃 |
| 章节结算 | 集级质检 + 全剧质检 | 长篇章节结算/信息债 |

**核心转换口诀**：能拍出来的留下，拍不出来的改掉；对白推进，动作说话，环境服务情绪。

---

## 十、验收标准

1. 单集 60–120 秒，3–6 场，场场有冲突或信息变化。
2. 前 3 秒有可见钩子；每集有核心冲突、情绪升级、兑现、结尾钩子。
3. 第 10–15 集有强付费卡点；每 5–10 集冲突升级。
4. 每集有分镜表；镜头总时长与剧本时长误差 ≤ 5 秒。
5. 对白口语化、短句、有潜台词；无大段解释。
6. 动作行可拍；无心理描写和抽象比喻。
7. 场景/道具/服装/时间线连续；主场景复用率符合制作条件。
8. 导出剧本使用「第N集 / N-N 场」格式；分镜表可独立导出 CSV。
9. 剧本流程不导入长篇 Runner/步骤/模板；静态导入测试通过。
