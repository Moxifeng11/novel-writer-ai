# 长篇小说领域 Harness

## 一、目标

在几十万字连续叙事中保持事实、人物、动机、节奏与承诺一致。

## 二、内容 Schema

```text
Project → Volume → Chapter → StepResult
```

- Project：`.project`、写作配置、全书规划。
- Volume：分卷大纲、卷目标。
- Chapter：章节状态、正文、步骤结果。
- StepResult：11 步产物。

## 三、创作主链

```text
全书规划 / 卷纲
  → 章节上下文装配
  → 合并规划（1 次调用）
  → 正文生成（1 次逻辑调用）
  → 质量控制（1 次调用 + 本地零 AI 校验）
  → 分析报告（1 次调用）
  → 结算 / 快照 / 记忆确认
```

## 四、必备上下文

1. 当前章目标。
2. 前章结尾与摘要。
3. 已确认事实索引。
4. 人物关系与状态。
5. 未回收伏笔与信息债。
6. 本卷目标。
7. 文风样本与反 AI 约束。

## 五、规则重点

- must：未确认实体不得入正文；不得重复已发生事件；字数下限；章末钩子；视角一致。
- should：避免连续解释；控制形容词密度；保持场景目标.
- hint：可增加感官细节；可强化关系张力。

## 六、工具

章节状态解析、事实索引查询、实体/关系/伏笔/时间线查询、文风采样、连贯性检查、合并规划解析、正文格式校验、章节快照写入。

## 七、记忆

- FactIndexManager 为确认事实层。
- 章节结算写 ChapterStateSnapshot。
- AI 实体状态默认 pending。
- 跨卷状态由 CrossVolumeIntegrator 提供。

## 八、质量门

连贯性、逻辑一致性、剧情冗余、情绪曲线、反 AI、字数、格式、视角、章末钩子、结算可用。
