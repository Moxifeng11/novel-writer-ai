# 短篇小说领域 Harness

## 一、目标

在 5–10 万字内完成强情绪、单主线、高密度反转，并保证每次生成不同质化。

## 二、内容 Schema

```text
Project → StoryCore → SectionOutline → Section → SectionReview
```

- StoryCore：主角/目标/阻力/反转/情绪承诺/终局兑现。
- SectionOutline：8–40 节，每节目标/冲突/信息增量/情绪/钩子/字数。
- Section：1,500–4,500 字。
- SectionReview：钩子/推进/冲突/情绪/连贯/文风六维。

## 三、创作主链

```text
五维分类 + 热点调研
  → 固化框架 + 真随机因子
  → 故事核 / 人物 / 反转表
  → 分节大纲
  → 开篇三屏
  → 逐节生成 + 节级质检
  → 全篇收束 + 兑现检查
  → 书名 / 简介 / 导出
```

## 四、必备上下文

1. 主分类与读者预期。
2. 故事核。
3. 反转表。
4. 当前节目标、冲突、钩子。
5. 前一节 200–300 字摘要。
6. 人物当前状态。
7. 目标字数与当前节字数。

## 五、规则重点

- must：每节钩子；单主线；结尾兑现；字数范围；禁止长篇式铺陈。
- should：每 1,000–1,500 字推进；控制支线；保持情绪曲线。
- hint：可强化反转伏笔；可增加感官细节。

## 六、工具

五维分类校验、随机因子生成、故事核校验、反转表解析、分节大纲构建、节字数校验、节级质检、反转覆盖检查、结尾兑现检查、短篇导出。

## 七、记忆

- 反转账本。
- 钩子账本。
- 人物状态。
- 情绪兑现账本。
- 每节摘要。
- AI 记忆默认 pending，节级质检后确认。

## 八、质量门

分类合法、五维齐全、节字数、每节钩子、3–5 反转落位、情绪兑现、主冲突闭合、伏笔回收 ≥80%。
