# 剧本领域 Harness

## 一、目标

产出可拍摄的纯文本剧本与分镜，每个镜头有目的，每一集有商业节奏。

## 二、内容 Schema

```text
Project → Episode → Scene → Shot → Beat
```

- Episode：集号、时长、钩子、冲突、兑现、结尾钩子。
- Scene：场 ID、日夜内外、地点、人物、目的、冲突、转折。
- Shot：镜号、景别、角度、运镜、时长、画面、动作、台词/音效、转场、目的。

## 三、创作主链

```text
类型 + 卖点 + 3 秒钩子
  → 人物小传 / 场景圣经
  → 分集大纲
  → 前 3 集与付费卡点
  → 分场剧本
  → 分镜表
  → 商业节奏与可拍性质检
  → 纯文本导出
```

## 四、必备上下文

1. 当前集目标与冲突。
2. 本集爽点与结尾钩子。
3. 主场景约束。
4. 人物在场关系。
5. 道具与连续性。
6. 前 3 秒钩子。
7. 时长 / 场次 / 镜头预算。

## 五、规则重点

- must：3 秒钩子；单集冲突；每场可拍；禁止心理旁白；镜头时长误差 ≤5 秒；纯文本交付。
- should：对白口语化；场景复用；每集一次兑现。
- hint：可增加视觉意象；可强化结尾钩子。

## 六、工具

类型校验、集/场/镜 ID 生成、镜头时长求和、3 秒钩子校验、场景连续性检查、对白可拍性检查、分镜导出、纯文本导出。

## 七、记忆

- 集/场/镜状态账本。
- 道具、服装、时间、地点连续性。
- 付费卡点与兑现账本。
- 人物目标变化。

## 八、质量门

单集 60–120 秒；3–6 场；3 秒内可见钩子；每集冲突/升级/兑现/结尾钩子；每场可拍；镜头总时长与剧本误差 ≤5 秒；导出纯文本无小说式旁白。
