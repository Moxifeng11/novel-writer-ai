# 剧本分镜场维度全流程与节点管控规范

## 一、调研结论

短剧剧本与小说最大的差异：

- 小说以“叙述”推进；剧本以“可见画面 + 可听对白 + 可执行动作”推进。
- 小说可以写心理；剧本必须外化为动作、表情、台词、音效。
- 小说按章；剧本按“集 → 场 → 镜 → 节拍”。
- 剧本的商业节奏以秒计：3 秒钩子、60–120 秒/集、第 10–15 集付费卡点。

因此剧本流程采用**分镜场维度全流程记录**：每一集、每一场、每一个镜头都有稳定 ID、状态、目的和可拍性校验。最终交付物只使用纯文本（Markdown/TXT/CSV），不生成视频/图片。

## 二、内容层级与 ID

```text
剧集 Episode
  └─ 场 Scene
       └─ 镜 Shot
            └─ 节拍 Beat（写在镜头目的/台词/动作中）
```

| 层级 | ID 示例 | 必填字段 |
|---|---|---|
| 集 | `E01` | 集号、标题、时长、钩子、核心冲突、兑现、结尾钩子 |
| 场 | `E01-S01` | 日/夜、内/外、地点、人物、目的、冲突、转折 |
| 镜 | `E01-S01-SH01` | 景别、角度、运镜、时长、画面、动作、台词/音效、转场 |
| 节拍 | 镜头内 | 动作节拍/情绪节拍/信息节拍 |

## 三、九步流程与节点管控

```text
T0 项目初始化
T1 一句话卖点与首集钩子
T2 人物与场景圣经
T3 分集大纲
T4 前 3 集与付费点
T5 分集剧本（场）
T6 分镜表（镜）
T7 商业节奏与可拍质检
T8 导出（纯文本）
```

### T0 项目初始化

**输入**：类型（12 类）、目标集数、单集时长、受众、竖/横屏。

**输出**：`剧本配置.md`、`流程状态.json`。

**节点 G0**

- 40–120 集；60–120 秒/集；总字数 5–10 万。
- 类型必选；付费卡点集数默认 10–15。
- 主场景清单 2–4 个。

### T1 一句话卖点与首集钩子

**输入**：类型、受众、参考作品。

**输出**：`01-卖点/一句话卖点.md`、`首集钩子.md`。

**节点 G1**

- 一句话卖点 ≤60 字，包含主角 + 压迫 + 反转预期。
- 3 秒钩子必须是可见事件：冲突/羞辱/危机/身份错位。
- 第 1 集结尾有明确追看问题。

### T2 人物与场景圣经

**输入**：卖点、类型、主场景清单。

**输出**：`02-人物与场景/人物小传.md`、`关系图.md`、`场景圣经.md`。

**节点 G2**

- 核心人物 ≤8；每人有欲望、阻力、秘密、说话方式、标志动作。
- 主场景 2–4 个；每个场景至少服务 2 集。
- 记录光线、道具、环境声、可拍限制、连续性风险。

### T3 分集大纲

**输入**：人物/场景圣经、目标集数。

**输出**：`03-分集大纲/分集大纲.md`。

**每集记录字段**

| 字段 | 必填 | 说明 |
|---|---|---|
| 集号/标题 | 是 | 第N集 + 钩子式标题 |
| 核心冲突 | 是 | 谁要什么、谁阻止 |
| 情绪升级 | 是 | 从什么情绪到什么情绪 |
| 爽点/兑现 | 是 | 具体画面或台词 |
| 结尾钩子 | 是 | 下一集必须回答的问题 |
| 场次数 | 是 | 3–6 场 |
| 预计秒数 | 是 | 60–120 秒 |
| 状态 | 是 | pending/written/reviewed/locked |

**节点 G3**

- 每集有冲突、升级、兑现、钩子；缺一项退回。
- 前 3 集完成主角处境、核心冲突、金手指/身份悬念、第一次强兑现。
- 第 10–15 集有强付费卡点；每 5–10 集升级冲突。

### T4 前 3 集与付费点

**输入**：分集大纲、卖点。

**输出**：`前3集钩子.md`、`付费点设计.md`。

**节点 G4**

- 第 1 集前 3 秒有可见冲突。
- 第 3 集完成第一次强兑现，结尾埋付费卡点。
- 卡点类型：真相/身份/生死/关系反转，至少一项。

### T5 分集剧本（场）

**输入**：当前集大纲、人物/场景圣经。

**输出**：`04-剧本/第NN集.md`。

**场记录字段**

| 字段 | 必填 | 说明 |
|---|---|---|
| 场 ID | 是 | `E01-S01` |
| 场景标题 | 是 | 日/夜 内/外 地点 |
| 人物 | 是 | 本场出场人物 |
| 目的 | 是 | 本场完成什么 |
| 冲突 | 是 | 谁阻止谁 |
| 转折 | 是 | 关系/权力/信息变化 |
| 对白 | 是 | 口语、短句、潜台词 |
| 动作 | 是 | △ 开头，可拍 |
| 结尾钩子 | 是 | 本场小钩子 |

**节点 G5**

- 单集 3–6 场；每场有冲突或信息变化；无纯过场。
- 每场可拍：地点、道具、动作、光线、音效明确。
- 对白可念、短句、有潜台词；禁止大段解释。

### T6 分镜表（镜）

**输入**：当前集场次剧本。

**输出**：`05-分镜/第NN集-分镜.md` 或 `.csv`。

**镜头字段**

| 字段 | 必填 | 示例 |
|---|---|---|
| 镜号 | 是 | `E01-S01-SH01` |
| 景别 | 是 | 远景/全景/中景/近景/特写/大特写 |
| 角度 | 是 | 平视/俯拍/仰拍/过肩/主观 |
| 运镜 | 是 | 固定/推/拉/摇/移/跟/手持 |
| 时长 | 是 | 2.5s |
| 画面 | 是 | 观众看到什么 |
| 动作/表演 | 是 | 演员做什么、表情/身体反应 |
| 台词/音效 | 是 | 对白、VO、环境声、音效 |
| 转场 | 是 | 切/淡/黑/叠化 |
| 目的 | 是 | 这个镜头完成什么 |

**节点 G6**

- 3 秒内至少一个特写或强动作。
- 每 10–15 秒景别/机位变化；单集镜头 20–45 个。
- 镜头总时长与剧本时长误差 ≤5 秒。
- 关键信息用特写：手机、合同、伤疤、照片、监控、戒指。
- 竖屏优先：近景/特写比例高，避免大远景和横向群像。

### T7 商业节奏与可拍质检

**输入**：剧本、分镜表、集大纲。

**输出**：`06-质检/第NN集-质检.md`、`全剧质检.md`。

**节点 G7**

评分八维（每项 0–20，总分 100）：3 秒钩子、单集冲突、情绪升级、兑现、结尾钩子、可拍性、对白、连续性。

通过线 ≥80，且 3 秒钩子/单集冲突/结尾钩子均 ≥12。

红线：

- 靠旁白解释核心冲突。
- 单集无冲突。
- 结尾无钩子。
- 出现无法拍摄的心理描写/抽象比喻。
- 台词像小说对白。

### T8 导出（纯文本）

**输出**

```text
07-导出/剧名候选.md
07-导出/人物小传.md
07-导出/分集大纲.md
07-导出/完整剧本.md
07-导出/分镜表.csv
```

**节点 G8**

- 标题「第N集」；场次「N-N 日/内 地点」。
- 不含小说式章节标题、卷标题、作者旁白。
- 分镜表可独立交付 CSV。
- 平台元数据：红果类型、集数、单集时长、受众；不混用短篇五维标签。

## 四、全流程记录表

每次剧本生成/修改必须写入：

| 记录项 | 内容 |
|---|---|
| 剧集状态 | pending/written/reviewed/locked |
| 场状态 | pending/written/reviewed |
| 镜状态 | pending/written/reviewed |
| 节点通过时间 | G0–G8 时间戳 |
| 质检分 | 八维分数与总分 |
| 问题清单 | 场/镜号 + 问题 + 修复建议 |
| 版本 | 每次重写保留旧版备份 |

- 本集钩子：
- 核心冲突：
- 本集兑现：
- 结尾钩子：

人物：林晚、婆婆、丈夫

...

## 六、参数与验收

| 参数 | 范围 | 默认 |
|---|---|---|
| 集数 | 40–120 | 80 |
| 单集时长 | 60–120 秒 | 90 |
| 单集场次 | 3–6 | 4 |
| 单集镜头 | 20–45 | 30 |
| 单镜时长 | 1–5 秒 | 2–3 |
| 质检通过线 | 80/100 | 80 |

**验收**

1. 每集有场/镜记录，ID 稳定，状态可追踪。
2. 每集通过 G3/G5/G6/G7 才能导出。
3. 分镜镜头总时长与剧本误差 ≤5 秒。
4. 导出为纯文本，剧本与分镜可独立交付。
5. 剧本流程不导入长篇 11 步；产物只写入 `剧本创作/`。
