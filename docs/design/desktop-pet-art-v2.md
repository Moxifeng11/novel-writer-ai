## 1. 主流桌宠风格研究（2024–2026）

调研结论：主流分三极，共同点是「低细节密度 + 高辨识剪影 + 有限色板」。

| 风格 | 头身比 | 描边 | 阴影 | 配色 | 眼睛 | 典型场景 |
|---|---|---|---|---|---|---|
| 3D 黏土 / 盲盒 | 2.0–2.5 | 无硬描边 | 2–3 阶柔和体积 + 接触阴影 | 奶油/糖果，4–6 色 | 圆瞳 + 单点大高光 | 盲盒 IP、桌面摆件、App 引导 |
| 日系赛璐璐 Q 版 | 2.0–3.0（2.5 最稳） | 1.5–2px 深色 | 2–3 阶硬边 | 高明度粉蓝黄 | 眼占脸 1/3、上睑粗、虹膜渐变双高光 | Live2D 桌宠、二次元陪伴 |
| 厚涂插画 | 2.5–3.5 | 无描边或同色深线 | 柔和笔触、环境反射 | 莫兰迪暖灰 | 柔眼神光、厚睫毛 | 情感陪伴、品牌插画 |
| 扁平治愈 | 2.0–3.0 | 无描边或单色粗边 | 纯色块 + 一层投影 | 6–8 色马卡龙 | 豆豆眼 / 弧眼 + 椭圆腮红 | 效率插件、SVG 图标 |
| 线描极简 | 2.0–3.0 | 2–3px 圆头等宽线 | 无 | 单色 + 1 强调色，留白 40% | 点眼 / 闭眼弧 | 阅读写作工具 |
| 像素 | 16–48px 网格 | 1px selout | 抖动明暗 | 8–16 色 | 2–3px 方眼 | 复古桌宠、独立游戏 |
| 毛绒玩偶 | 2.0–2.5 | 1–2px 绒边起伏 | 绒面高光 + 软阴影 | 奶油/燕麦/雾粉 | 纽扣眼 / 刺绣眼 | 治愈、睡眠 App |

### 1.1 让它「显贵」的 12 个手法（本次采用）

1. 头 2–2.5 身；头宽 ≈ 1.1 倍肩宽。
2. 眼位在头高 50–55%，眼距 ≈ 1 个眼宽。
3. 虹膜三层：深底 / 主色 / 下部反光。
4. 主高光在 10 点方向，直径 ≈ 瞳孔 1/3；次高光在 4 点方向。
5. 上睑线是下睑的 2–3 倍粗，眼尾上翘 5–10°。
6. 描边取填充**同色相深 20–30%**，不是纯黑。
7. 45° 主光 + 反侧 2–3px 轮廓光；暗部偏暖。
8. 投影 blur 4–8px、透明度 15–25%，接触点小而深。
9. 腮红 blur 3–6px、40–60%，位于眼下 1/3。
10. 色板 ≤ 6 色，按 60-30-10 分配；饱和度峰值只给一个点。
11. 不对称记忆点：单侧呆毛 / 猫耳 / 发夹。
12. 一个道具，占画面 <15%，不遮脸。

### 1.2 廉价感的 6 个来源（本次规避）

- 纯黑等宽描边 + 到处渐变；
- 4–5 头身硬套 2 头身五官；
- 完全对称的正面，剪影无记忆点；
- 颜色超过 8 种，暗部直接叠黑；
- 眼睛只有一个椭圆 + 一个白点，没有眼睑厚度；
- 忽略深色模式（黑边消失 / 白高光刺眼）。

## 2. 造型定稿

**角色概念**：熬夜写稿的猫耳作者。抱着稿纸，头顶一缕呆毛，安静陪伴写作。

- 画布：`viewBox="0 0 160 180"`，渲染基准宽 150px（当前 126px 太小，五官糊）。
- 头身比：**2.0**（头高 66、全身 132）——比原 2.4 更 Q，符合主流桌宠的下限。
- 剪影记忆点：猫耳 + 呆毛 + 侧边发夹 + 抱稿姿势；四者只保留一份，不堆叠。
- 描边：同色相深色，2.2–2.4px，`stroke-opacity .55`；不使用纯黑。
- 主光：左上 45°；阴影偏暖（`#E8B99B`，透明度 ≤ .22）；右侧 2px 反侧光。

### 2.2 头发画法（v1 失败点）

v1 的“整片盖住额头 + 波浪底边”会读成头盔。v2 规则：

- 先画**发团外轮廓**（一个椭圆），再画**脸**，最后画**刘海**盖在脸上；
- 刘海底边是**一条平滑弧线**（中间略高），不是波浪、不是直线；
- 露出的额头高度 ≥ 8px，眉毛完整可见；
- 允许 1–2 根细发丝，但**不加浅色横向发带**——横向浅色会读成发箍。

## 3. 三种材质方向

同一套几何，三种材质。UI 里以设置项 `petStyle` 切换，默认 A。

| | A · 奶油软胶（推荐） | B · 日系赛璐璐 | C · 线描极简 |
|---|---|---|---|
| 体积 | 径向渐变皮肤 + 线性渐变头发 | 平涂 + 2 阶硬阴影 | 无填充变化，留白 |
| 描边 | 同色相深 2.4px，opacity .55 | 深色 2.6px | 2.1px 单色线 |
| 发色 | 薰衣草 `#D3C0F5 → #A486DB` | 珊瑚粉 `#FFA8BE / #F2799B` | 线稿（发色 = 背景色） |
| 衣服 | 薄荷 `#A8DEC9` | 汽水蓝 `#BFE3FF` | 线稿 |
| 点缀 | 蜜桃 `#FFC2AE` | 芥末黄 `#FFD36B` | 单强调色 |
| 明暗 | 柔光 + 反侧轮廓光 | 硬阴影 + 高光块 | 无 |
| 适合 | 主流 3D 盲盒观感 | 二次元、浅色主题 | 极简/阅读主题 |

### 3.1 令牌（A 方案）

```
--nw-pet-skin:       #FFF2E5 → #FBD9C2
--nw-pet-hair:       #D3C0F5 → #A486DB
--nw-pet-hair-back:  #B79EE9 → #8E70CB
--nw-pet-cloth:      #A8DEC9
--nw-pet-accent:     #FFC2AE
--nw-pet-book:       #FFCBB8
--nw-pet-ink:        #5B4A69（同色相深）
--nw-pet-blush:      #FFB3C1
--nw-pet-paper:      #FFFDF6
```

深色主题：皮肤提亮 4%、发色降饱和 8%、描边透明度提到 .7；**不要**把描边改成纯黑。

## 4. 与分层 / 状态的映射

| 层 | 造型元素 | 动画 |
|---|---|---|
| `shadow` | 地面椭圆 | 呼吸缩放 4.2s；`happy` 弹跳、`error` 收缩 |
| `aura` | 可选光晕环 + 星点 | 旋转 12s；`thinking` 加速 |
| `body` | 发团、猫耳、脸、连衣裙、手臂、腿、鞋 | 浮动 4.2s ±3px；`writing` 点头、`happy` 跳 |
| `detail` | 刘海、呆毛、五官、腮红、围巾、稿纸、发夹 | 随 body 同周期；眨眼 5.2s、`writing` 笔摆 |
| `fx` | Zzz / 墨点 / 省略号 / 彩纸 / 汗滴 | 按状态切换 |

- 猫耳与呆毛属于 `body` / `detail`，不是独立层；它们的“抖耳”作为 `detail` 内的局部动画（`happy`/`error`）。
- 稿纸是唯一道具，挂在 `detail`，`writing` 时轻微上浮。

## 5. 验收

- [ ] 150px 渲染下，眉毛、上睑线、腮红边界清晰可辨。
- [ ] 灰度截图下，剪影可由“猫耳 + 呆毛”识别。
- [ ] 浅色、深色、图片背景三种底上，描边与反侧光都可读。
- [ ] A/B/C 三套材质切换只改颜色与阴影，不改几何。
- [ ] 与 v1 相比，头部占比 ≥ 45%、眼睛占脸宽 ≥ 45%。
