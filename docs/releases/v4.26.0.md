# v4.26.0 — 引导型写作规则体系 v4 与三模式路径收口

发布日期：2026-11-03

## 为什么发这一版

旧写作规则由数值禁令堆成（禁用词、段落句数、字数区间、占比阈值），生成结果僵硬、容易为了过指标而牺牲叙事；同时三个创作模式各自硬编码根目录，路径事实多处漂移。

## 主要变化

### 1. 写作规则 v4（单一镜头）

- 唯一生效来源：vault `元文件/00-系统模板/写作规则.md`；项目内副本在启动迁移时删除。
- 内置 5 个版本收敛为唯一 v4.0.0 模板；设置页删除版本下拉与漂移告警，改为「唯一来源 + 版本 + 在 Obsidian 中打开」。
- 核心锚点「单一镜头——每章只从一个视角人物观察世界」置顶；心法改为提问式。
- 删除全部数值禁令；唯一禁止只剩「不以作者身份写作、不写镜头外信息」。
- 长篇连载 / 短篇单元 / 剧本分镜三段附录由 `RulesService` 按项目模式拼进同一份规则文本。

### 2. 提示词同步

- V1–V4 正文删除 `${craftConstraints}` `${negativeList}`，增加 `${lensDeclaration}`。
- 信息规划/情节蒸馏删除条数与密度数值；分析报告强制提取改为引导；质量控制 14 项改为六块引导式复盘（旧标题兼容）。
- `ai-prompt-builder` 内嵌 14 条规则删除，改为调用方传入 `RulesService` 全文。

### 3. 路径与三模式设置

- 运行时跨目录引用统一为 `@/layer/file`（2,043 处）。
- `CREATION_MODE_SPECS` 新增 `rootDir`，`MODE_LIBRARY_ROOTS` 由它派生；`project-locator` 只做再导出。
- 新增「📚 创作模式」设置分区，集中展示三个模式的根目录、内容结构、单元规格。
- 写作配置默认/最小/最大字数不一致时行内提示。

## 验证

- 单测 529 文件 / 5,876 用例通过。
- 新增规则注册表/结构解析/镜头与模板消费/质控校验等 20+ 处回归。
- 三份分模式说明：`docs/audits/v4.26-mode-long.md`、`v4.26-mode-short.md`、`v4.26-mode-script.md`。

## 影响与迁移

- 破坏性变更：项目内写作规则副本会被删除，以 vault 唯一来源为准。
- 配置/数据迁移：启动时自动迁移；自定义数值禁令不再生效。
- 回滚建议：回滚前备份 `元文件/00-系统模板/写作规则.md`。
