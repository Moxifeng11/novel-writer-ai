# 小说工坊 AI v4.12.2

> 发布日期：2026-10-25 · 上一版本：[v4.12.1](v4.12.1.md)
> 主题：M1 Foundation — CSS 预算门禁 / 批量 7 步口径 / long-novel 规格校准

本版是工具链与口径补丁，不改变写作行为。目标是把后续 CSS 治理与长篇演进变成可度量、可阻断的工程流程。

---

## 一、改动

### 1. CSS 预算检查

`scripts/check-css.js` 从「只查括号、永不失败」改为：

- 保留括号匹配检查；
- 新增体积、`!important`、硬编码 hex、rgb/hsl、唯一类、非 `nw-` 前缀类、最大选择器深度指标；
- 违规或超过 `.css-baseline.json` 即 `exit(1)`；
- `--update-baseline` 仅在指标下降后收紧。

### 2. 内联样式基线

新增 `scripts/check-inline-styles.mjs`：

- 统计 `ui/` 下 5 种内联写法（`style: '` / `style: "` / `style: \`` / `style="` / `setAttribute('style'`）；
- 区分静态与动态（含 `${` 记为动态）；
- 生成 `.inline-style-baseline.json`，任何文件新增/回涨即失败。

### 3. 门禁接入

`check:css` 与 `check:inline-styles` 已接入：

- `npm run preflight`
- CI 的 verify job
- Release 流水线

### 4. 批量步骤口径

- 命令描述与弹窗文案统一为实际 **7 步**：信息规划 → 情节蒸馏 → 大纲摘要 → 情绪规划 → Scene 展开 → 正文 → 分析报告；每章结束自动结算。
- 新增 `batch-targets-contract.test.ts`：锁定 `BATCH_STEP_KEYS` 均存在于 `ALL_FULL_STEPS`、顺序为子序列、无重复。

### 5. long-novel spec 校准

- 状态改为 **Scoped Phase 1 进行中**；完整 R1–R8 未启动。
- 基线更新到 v4.12.1 / 330 文件 / 4225 用例。
- 新增 §3.0.1：记录 R2/R1/R4/R5/R6 五个本轮缺口，R3/R7 明确不启动。
