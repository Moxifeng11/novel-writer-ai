# v4.30.0 — 资产总览、全模式注入、用量账本与备份中心

发布日期：2026-11-05

## 为什么发这一版

M1–M3 把门禁、入口、短篇/剧本闭环补齐后，剩下的是“可解释性”与“可运营性”：

1. 用户无法回答“这一章为什么写成这样”——规则/模板/指纹/知识库分散在五个入口；
2. 短篇/剧本单元写作完全没用上知识库与指纹，而长篇 11 步已经在用；
3. 没有任何跨会话的真实 token 统计，用户不知道成本花在哪；
4. 版本快照、步骤产物、配置备份散在三处，没有统一查看/恢复入口。

这一版把四件事收口，并完成第一批大文件切片。

## 主要变化

### 1. 资产总览（AssetRegistry）

- `engine/asset-registry.ts` 只读聚合五类资产：
  - 写作规则（vault 唯一来源 + 内置模板）；
  - 提示词模板（`元文件/00-系统模板/prompts/` 覆盖 + PromptManager 自建）；
  - 文笔指纹（项目级/全局，启用状态）；
  - 知识库（拆解状态决定是否可检索）；
  - 写作配置。
- 每条资产带来源（builtin/vault/project/global/custom）、版本/时间、影响范围说明。
- 「🧩 资产总览」弹窗按种类分组展示“当前生效”摘要，可跳转文件；主页与命令面板均可进入。

### 2. 全模式知识/指纹注入

- `engine/mode-injection.ts`：
  - 知识库走 `retrieve()` + `formatRetrievalHits()`（与长篇同一套 RAG 管线）；
  - 指纹走 `selectFingerprintsForInjection()`（上限 3，>3 时按 V2 相似度挑最相关）；
  - 任何失败降级为空串，不阻塞写作。
- 短篇/剧本单元写作提示词新增【参考知识】【文笔指纹】块；上下文与长篇 11 步对齐。

### 3. AI 用量账本

- `services/usage-ledger.ts` 在 `AIApiClient` 三个入口（非流式 / 流式 / 异步迭代器）统一记账：
  - 模型、prompt/completion/total tokens、耗时、状态（ok/error/aborted）；
  - 落盘到 `<configDir>/plugins/novel-writer-ai/data/usage-ledger.json`（不进用户 vault），上限 500 条。
- 「💰 AI 用量账本」弹窗：总量卡片、按模型表格、最近 50 条调用；支持清空。

### 4. 版本与备份中心

- `services/backup-center-service.ts` 按项目聚合：
  - `_versions/{contentType}/{key}/versions.json` 版本快照；
  - `03-大纲与章节/步骤结果/` 的结算表/质控/分析报告等产物；
  - 插件 `data.json.bak`（设置迁移备份）。
- 「🗂 版本与备份中心」弹窗：
  - 版本条目可直接回滚：当前内容自动保存为 rollback 版本后再写入；
  - 产物/备份可打开查看；显示回滚记录数。

### 5. 大文件切片（第一批）

- `ui/co-writing-view.ts` 5440 → 5393：Markdown 工具条抽到 `ui/co-writing/markdown-toolbar.ts`。
- `engine/co-writer-engine.ts` 3911 → 3750：本地模型判定/Ollama 探测抽到 `engine/co-writer/local-model-utils.ts`，原入口 re-export 保持兼容。
- 顺手清理未用导入，lint 警告 1892 → 1890（上限同步下调）。
