# v4.36.0 — 切片收尾、Notice 第二批与 ui 覆盖率爬坡

发布日期：2026-11-05

## 为什么发这一版

v4.35.0 留下三个尾巴：renderConfigTab 因可写状态未切、Notice 只铺了第一批 6 文件、ui 覆盖率停在首期 ~6%。本批由四个实现子代理并行收口，其中覆盖率子代理还顺带用行为测试锁定了三个疑似 bug 的现状（未改源码，单列报告）。

## 主要变化

### 1. 切片收尾

- `engine/co-writer-engine.ts` 3,747 → 3,556（-191）：
  - AI 响应解析簇 → `engine/co-writer/ai-response-parse.ts`（4 个导出纯函数）；
  - 剧情节点提取簇 → `engine/co-writer/plot-nodes.ts`（`extractPlotNodes` 快照字段显式参数化，三级回退逐行保留）；
  - 9 处调用点直调模块函数；`parseValidationResponse` 保留薄委托（既有测试经实例访问）。
- `ui/views/knowledge-base-view.ts` 3,368 → 3,226（-142）：
  - `renderConfigTab` → `kb-config-panel.ts`（228 行）：**分类切换/流派选中的写入留视图**（经 `switchCategory`/`selectGenre` 宿主回调），DOM/事件逐行等价；`selectedGenreId` 的 mouseleave 守卫用实时回调 `isSelectedGenre(id)`（不能用快照）。
- 大文件现状：co-writing-view 4,986 / co-writer-engine 3,556 / knowledge-base-view 3,226。

### 2. Notice 第二批铺开

- 7 个文件替换 30 处（写章 1、续写 2、重建 3、大纲树 9、补全 5、扩写 10），例外口径与第一批一致（前置守卫 8、进度 4、📋 预检 1）。
- 两个文件迁移后 `Notice` 无引用，同步移除 obsidian 导入。

### 3. ui 覆盖率爬坡

- 新增 113 个带真实断言的行为用例：四个指定模块（质检报告解析/章节匹配/写作建议/Notice 降级）+ 追加覆盖 svg-charts、wizard-checker、template-vars、suggestion-history、empty/error-state 等。
- `ui/**` lines **5.99% → 12.04%**；per-glob 棘轮按「实际值-2」纪律收紧为 10/9/10/8。

### 4. 主流程修复（子代理协作中发现）

- `engine/co-writer/plot-nodes.ts` 的跨目录相对导入 `'../scene-expander'` 破坏 path-alias 测试 → 改 `@/engine/scene-expander`。

### 5. 行为测试锁定的疑似 bug（未改源码，待确认后单开批次）

- `quality-report.ts`：⚠️ 剥离残留 U+FE0F 变体选择符；「第N段」定位文档与实现不符（实际回落为问题文本前 20 字）。
