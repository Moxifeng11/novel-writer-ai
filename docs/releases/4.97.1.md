# v4.97.1 — 社区插件目录上架准备

> 标签 `4.97.1` · 2026-11-20 · 上一版 [4.97.0](4.97.0.md)

## 为什么发这一版

4.97.0 已经准备好功能与双语界面，但按 Obsidian 社区目录的[插件上架要求](https://docs.obsidian.md/Plugins/Releasing/Submission%20requirements%20for%20plugins)，有两处必须先改：

1. **用了 Node/Electron API 就必须声明桌面端专用。** 插件有三处这类调用——后台 Worker 线程、系统级「保护元文件」（`shared/desktop-shell.ts` 动态 import `node:child_process`）、MCP 本地文件与 stdio 传输（`shared/mcp-file-browse.ts` 的 `require('node:fs')`、`engine/agent/harness/mcp-stdio-transport.ts` 的 `require('node:child_process')`）。这些路径在移动端本来就有降级，但目录要求是「只要用到就设 `isDesktopOnly: true`」。
2. **描述要短、要以动作开头。** 原描述是名词短语开头、204 字符，目录要求 ≤250 字符、句末带句号、不用 emoji，并建议以动作陈述开头。

这一版**不改任何功能代码**，只改 manifest 与文档。

## 影响与迁移

- **移动端用户**：本版起在移动端不可安装（Obsidian 会按 `isDesktopOnly` 过滤）。原有 vault 数据、设置不受影响；如需移动端，后续把三处 Node 调用改为纯 vault API 实现，再发一版恢复。
- 桌面端用户：行为无变化，插件 ID、命令 ID、设置键名均未改动。
- 升级方式：正常更新即可，无需迁移数据。
