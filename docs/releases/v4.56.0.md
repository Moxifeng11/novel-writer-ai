# v4.56.0 — chapter-state 失效标脏补测

发布日期：2026-11-06

## 为什么发这一版

`chapter-state-manager` 决定「哪些步骤需要重做」，判错会让用户重跑已完成步骤或漏跑必要步骤。v4.53.0 补了失效标脏主链，本版补齐状态机与降级路径（+7 用例，零源码改动）。

## 主要变化

### chapter-state 状态机补测（10 → 17 用例）

- `invalidateSteps`：降级与标脏路径；
- `updateStepState`：分级更新与 `forceComplete`；
- `reset`：整体复位；
- `migrateLegacyStepIndex`：旧索引迁移；
- 历史 `source=ai-generated` 兼容。

单文件覆盖率：st **73.13% → 87.56%**、br **63.12% → 74.46%**、fn **66.66% → 100%**、lines **74.19% → 89.24%**。
