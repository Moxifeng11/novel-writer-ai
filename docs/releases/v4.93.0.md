# v4.93.0 — 拆解补维度 + 语义词表注册表

发布日期：2026-11-13 · tag：`4.93.0` · 上一版本 v4.92.0

## 这一版解决什么

v4.92.0 把谓词压成枚举，换来可确定比对；但 100→200 章规模评测暴露了两类新问题：

| 问题 | 实例 |
|---|---|
| 同一事件内不同里程碑被误判矛盾 | 「十三岁开悟」vs「三十岁才进不惑」 |
| 抽取归属错误 | 「你虽然才不惑…」（对六师兄说的）被归成宁缺 40 岁 |
| 边界值与精确值混比 | 「未满二十」vs「十八」被判 20→18 倒退 |

## 改动一：拆解产物补维度

### slot 子维度

```json
{ "subject": "大师兄", "predicate": "年龄", "slot": "开悟年龄", "value": "十三" }
```

- 同一主体的不同**侧面**用不同 slot（当前年龄 / 开悟年龄 / 职务身份…）
- R1 按 `(主体, slot)` 分组、R2 按 `(主体, slot, 章节)` 分组
- 唯一 slot 数 2396（3258 条事实），说明维度确实被用起来了

### 归属约束

prompt 明确：只抽取关于 subject **本人**的事实。
对别人说的话、成语/比喻式表达、他人的情况，都不抽成本人的事实。

### 精确值守卫

`未满 / 不到 / 将近 / 约 / 左右 / 上下…` 等边界值不参与「倒退/不相容」比较。

## 改动二：A 类语义词表统一注册表

关键词审查发现 47 个文件、158 个词表。按输入来源分三级后，只有 A 类
（用词表判断自由文本含义）必须改造。

新增 `shared/semantic-keywords.ts`：

| 导出 | 用途 |
|---|---|
| `DRASTIC_CHANGE_GROUPS` | 死亡/重伤/能力变化 |
| `INJURY_WORDS` / `ACTION_WORDS` / `MODERN_WORDS` / `LOCATION_WORDS` | 各类语义词表 |
| `KEYWORD_FALLBACK_SOURCE` | 告警标注「词表兜底命中」 |
| `mergeKeywordOverrides` | 合并用户扩展词（去重） |
| `findKeywordHits` | 返回命中词，告警可展示证据 |

**设计约束（写入模块注释）**：判定顺序必须是
`结构化字段 → 词表兜底 → 不判定`。词表不是主判据。

`conflict-detector` 与 `logic-consistency-checker` 已迁移。

### 完整演化（同一份 200 章数据）

| 阶段 | 误报 | 召回 |
|---|---|---|
| 自由谓词（100 章） | 0 | 7/7 |
| 规范谓词（100 章） | 427 → 21 | 9/10 |
| + event 事件锚 | 0 | 8/8 |
| 规范谓词（200 章） | 3 | — |
| + 精确值守卫 | 2 | — |
| **+ slot 子维度** | **0** | **10/10** |

> **规律：每一次"压成枚举"都会丢一个维度，必须显式补回来。**
> 谓词压成枚举 → 丢事件区分 → 加 `event`；
> 谓词压成枚举 → 丢侧面区分 → 加 `slot`。
