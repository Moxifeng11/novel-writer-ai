# v4.95.0 — 词表治理收尾

发布日期：2026-11-13 · tag：`4.95.0` · 上一版本 v4.94.0

## 这一版做了什么

关键词审查把 158 个词表按输入来源分三级后，这一版收尾：

### A 类：plot-divergence 结构化优先

```ts
new PlotDivergenceEngine({
    structuredContradictions: ['世界观：无魔法', '势力：青云门已覆灭'],
})
```

设定一致性判定顺序改为：**结构化矛盾 → 词表模式兜底**。
`SETTING_CONTRADICTION_PATTERNS` 是正则词表，换个说法就漏；有结构化数据时不该再猜。

至此 A 类三处全部完成：

| 模块 | 结构化输入 |
|---|---|
| `conflict-detector` | `lifeState` / `injuryLevel` / 事实库等级序 |
| `logic-consistency-checker` | `injuryLevels` |
| `plot-divergence-engine` | `structuredContradictions` |

### C 类：统计词表可配置

| 词表 | 设置入口 |
|---|---|
| 语义词表（伤情/行动/现代/地点/剧变） | ✅ 5 个输入框 |
| AI 高频词 | ✅ |
| 正面/负面/高强度情绪词 | ✅ 3 个输入框 |

用户发现某个说法没被识别时，自己加词即可，无需改代码。

**定位说明**：C 类只影响统计口径（情绪分布、风格画像），不影响对正文的正确性判断，
所以只做可配置，不做结构化替代。
