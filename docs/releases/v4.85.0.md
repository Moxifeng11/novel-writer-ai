# v4.85.0 — 静默失效大扫除：27 处真 bug + 测试标准

发布日期：2026-11-13 · tag：`4.85.0`（无 `v` 前缀，Obsidian 社区目录规则）· 上一版本 v4.84.0

## 为什么发这一版

这一版不新增功能。它做的是一件事：**把「用户以为生效了、其实没生效」的地方逐条挖出来修掉。**

起因是一次对抗性审查（8 个子系统并行、约 27 万行源码），专门找同一类缺陷——
代码跑通了、没有报错，但用户以为完成的事实际没发生。共确认并修复 **27 处**。

版本性质：无破坏性变更；但**修掉的都是会让人白干活或丢数据的缺陷**，建议尽快升级。

## 主要修复

### 🎯 同人约束全线失效（5 处，最严重）

`shared/paths.ts` 自己写着：`.project` 是点文件，Obsidian 不把它纳入 vault 索引，
`getAbstractFileByPath('.project')` **恒为 null**。但有 5 处代码仍然这样读：

| 位置 | 后果 |
|---|---|
| `shared/fanfic-rules.ts` | 永远返回空规则 → 同人约束在生成人物/势力/地点/物品、11 步流水线、`diagnose_flow` 里**全部静默失效**，且因为 `isFanfic=false` 连「加载失败」警告都不弹 |
| `ui/full-writer/wizard-step-validators.ts` | 「故事结构」「同人」两个向导步骤**永远判为未完成**，用户无法通过向导 |
| `ui/full-writer/fanfic-settings-utils.ts` | 永远走 `vault.create`：对已有项目抛「文件已存在」，或把整份 `.project` 覆盖成最小模板 |
| `ui/full-writer/wizard-step-renderers.ts` ×3 | 已保存的故事结构不显示；同人步骤永远空表单；已绑定的设定重复出现在候选列表 |

**为什么一直没发现**：测试替身不忠实——mock 的 `getAbstractFileByPath` 对点文件也返回 `TFile`，
测试因此「认证」了一个生产环境不可用的实现。**修完替身后立刻有 3 个用例变红**，暴露了同类缺陷。

### 💾 数据丢失（5 处）

「读失败 → 返回空 → 合并空 → 整份覆盖写」：一次同步冲突/文件占用就能抹掉真实数据。

| 位置 | 丢失什么 |
|---|---|
| `engine/knowledge-base-config.ts` | 用户自定义题材 / 性格标签 / 能力类型 / 技法 |
| `services/quality-history-store.ts` | 最多 200 条质量历史（趋势与基线永久失效） |
| `services/synopsis-store.ts` | 简介版本元数据（正文还在但再也列不出来） |
| `engine/style-learner.ts` | 已学习的作者风格偏好 |
| `engine/step-result-saver.ts` | **整章正文**（读旧稿失败 → 半章覆盖完整章） |

修法统一：区分「不存在」与「读失败」→ 读失败不覆盖磁盘 → 损坏文件先 `.corrupt-<ts>` 留档。

### 🌊 流式输出（3 处）

- **流被截断仍按成功返回**：网关断流时把半截正文当完整章节落盘、报成功、继续结算
- **重试导致内容重复**：生成中途超时重试 → 落盘正文出现两轮文本拼接
- **协议错误帧被当成正常结束**：`responses` 协议的 `error` 事件被映射成 `finishReason:'stop'`

### 🔧 拆解（2 处）

- **维度失败算完成**：8 个维度全失败仍弹「拆解完成 100%」，目录下一个报告都没有
- **维度写盘失败被吞**：进度显示完成，但风格/节奏/技巧/结构等 `.md` 一个都没写出来

### 🎨 风格指纹库（6 处）

保存/删除/启停/强度/迁移全部「提示成功但重启回滚」；全局强度配置读失败会把其他指纹的强度
（含 0=禁用）洗成默认 1.0，被禁用的风格重新全量注入。

### 📤 导出与结算（5 处）

- **EPUB 投稿包信息丢失**：`description`/`subject`/`identifier` 被白名单拷贝吃掉，
  `dc:description`/`dc:subject` 永远不写入——而 TXT/Markdown 版却带着它们
- **结算静默漏写**：强制揭示找不到伏笔、GROWTH 找不到人物卡、关系互信息区块缺失、
  快照读取失败不标 partial —— 全部「报完成但没写」

### 🗄 向量（1 处）

向量落盘失败被吞 → 界面显示「向量化完成 ✅」，重启后向量消失、RAG 恒召回为空。

## 工程改进：测试标准

这一版的根因是「没有测试标准」，所以同时立了标准并机械执行：

- `docs/handbook/05-testing.md` 新增 **7 条硬标准**：测试替身必须忠实、失败路径与成功路径同权、
  修 bug 必须留「改回旧代码会红」的回归锁、禁止 `.only`/无理由 `.skip`/空断言……
- 新增 **生产环境测试**章节：三层验证矩阵（L1 逻辑 / L2 集成 / **L3 真实 Obsidian**）、
  四种手段、**发版前 10 条手工验收清单**
- 新增门禁 `check:test-standard` 并接入 preflight（28 → 29 步）
- 新增替身忠实性契约测试（行为级，不只是标记检查）
