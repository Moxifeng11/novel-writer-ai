# v4.22.0 — 版本治理、上下文体检与全插件排查

> 发布日期：2026-10-31 · 上一个版本：[v4.21.1](v4.21.1.md)
> 测试基线：**481 文件 / 5506 用例** · 真实 Electron E2E 23 条 · 常规门禁全绿（含 Trae 结构重构整合）

本轮把「提示词/规则能不能改出更好的人味」这条长线实验收口，并首次做全插件系统排查。四组结论：

1. **外部检测不是提示词能解决的**：6 组规则消融 + 11 组规则/模板组合，朱雀判定全部不变；规则与模板能改纹理（短叙述占比 0.16–0.74），改不了判定。
2. **规划链有真实断链**：信息规划提示词与解析器脱节、场景卡丢感官字段、V1 无台词骨架、配角灵魂丢 3 个字段——「规划白跑」的根因，已全部接上。
3. **反馈闭环缺失**：质量控制只出报告、`fix/finalFix` 已废弃。本版补上「质控 → 定向修订 → 闸门 → 复检 → 可回滚」，并默认自动。
4. **数据正确性有系统性风险**：同章双正文文件、结算写错文件、归因字段静默丢失、迁移失败被盖章——已修，并在真实链路（第 1 章）上逐条验证。

## 一、写作规则与提示词模板版本化

- 规则 5 版并存、同时只生效一个：`3.6.0`（默认）、`3.6.0-legacy`、`3.7.0-anchor`、`3.8.0-scene-beat`、`3.9.0-voiceprint`；设置页可切，哈希漂移告警。
- 正文模板 V1/V2/V3（节拍先行）/V4（对话主干）；`activeBodyTemplate` 可强制切换。
- 归因：注入账本、执行时间线、步骤 frontmatter 记录模板/规则/人味版本与哈希。
- 规则正文下沉 `shared/`（services 只能依赖 shared），引擎侧保留兼容 re-export。

## 二、上下文体检（防污染）

- 重复段（2-gram ≥0.85）自动清空、保留权威版本；规则 × 文笔风格冲突可检出并剔除冲突行；步骤结果串章告警。
- 注入账本输出「【上下文体检】」行；设置 `contextHygieneAutoFix` 默认开。

## 三、规划链数据契约

- 信息规划输出补「开头承接 / 章末钩子」、伏笔操作改「需回收的旧伏笔 / 需埋下的新伏笔」——章纲硬要求块从恒为空变为有数据。
- 场景卡摘要补「感官 / 身体 / 情绪弧」；V1 模板补 `${dialogueSkeleton}`；Scene 展开底稿补 `dialogue_beats` 并校验条数；骨架为空给兜底文案。
- 配角灵魂补齐 9 字段；移除 V2 的 emotionPlan 双注入；`${chapterHook}` 升级为可注入块。
- 记忆写侧自动化：角色灵魂后自动生成主角记忆碎片；分析报告的实体事实进待确认队列。

## 四、修订闭环

- 质控报告 → 定向修订（最多 8 条高/中优先级）→ 闸门（长度 ±10% / 锁定人物 / 对话占比 / 非 JSON）→ 采纳前存章节版本 → 复检（AI 味/对话/短叙述 + 未消化线索）。
- 默认自动：`autoRevisionAfterQC`、`autoRecheckAfterRevision`；新命令 `novel-writer-targeted-revision`。
- QualityGate 首次接入正文路径（第一/二层零 AI），结果进时间线与执行登记表。

## 五、数据正确性

- 结算幂等：关系值按「章名+原因」、时间线按三列结构化去重、出场记录用数字章号。
- 连续性账本写进人物卡：`已知信息 / 伤势 / 持有物品`，追加 + 来源章；快照三列不再为空。
- 上一章状态快照过期检测（正文 mtime > 快照 mtime 时不再注入旧快照）。
- 分卷查找按「正文实际所在卷」优先；`chapPlan` 卷内限定；切章清跨卷快照残留。
- BodyWriter：patch 写前合成（归因字段不再丢）、覆盖前自动备份（5 分钟节流）。
