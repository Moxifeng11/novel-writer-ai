# 小说工坊 AI v4.11.0（内部版本 v8.14）

> 发布日期：2026-10-19
> 主题：全面技术审计落地 —— 安全收口 / 内存生命周期 / UX 断点 / 死代码清理 / CSS 体系 / lint 接入

本次版本为一次完整的工程质量升级：对插件全库执行安全、内存、交互、样式四路审计，按风险等级分批修复，并补齐自动化防线。**功能用法保持不变**，但 API 密钥加密机制有重要变化，请先阅读「升级须知」。

---

## ⚠️ 升级须知

1. **API 密钥加密升级（F4）**
   - 新的加密格式为 `aes256v2:`，采用「用户口令 + PBKDF2-SHA256（210,000 次迭代）+ 每条密文独立随机 salt」派生 AES-GCM 密钥。
   - 首次保存 API 密钥时会提示设置口令（至少 6 位）。口令仅保存在当前会话内存中，不写入任何文件。
   - 旧格式（`aes256v1`）密文**永久兼容读取**，无需手工迁移。
   - **请务必记住口令**：口令丢失后无法解密已有密钥，需要重新设置口令并重新填写全部 API 密钥。
   - 选择取消设置口令时，密钥将以明文保存并在界面提示（保持向下兼容，不阻塞使用）。

2. **兼容性**
   - `minAppVersion` 维持 **1.5.0**，未抬升。
   - 旧项目数据、旧版报告、既有设置键名全部保持可读。

## 🔒 安全

- **路径穿越防护（F5）**：新增统一名称净化函数，剥离控制字符、替换非法字符、消除 `..` 路径段；章节、地点、势力、物品、同人、知识库六类实体路径全部收口。AI 生成的实体名不再可能写出 vault 目录。
- **XSS 收口（F1/F2/F3）**：章节列表插值与知识库详情 SVG 文本统一走 `escapeHtml`（覆盖 `& < > " '`）。
- **密钥加密升级（F4）**：见「升级须知」。
- **依赖清理**：移除知识库 `undefined/` 遗留目录等历史脏数据。

## 🧠 内存与生命周期

- 插件卸载/禁用时现在会真正释放引擎资源（Worker 池、重资源），此前 `disposeAll()` 在生产路径从未被调用。
- 修正 `HeavyTaskWorkerManager` 的释放契约（`dispose()` 缺失，导致即使调用也无法清理）。
- 删除无上限的增量上下文缓存与 4 个连带死方法，长会话不再持续堆积内存。
- 持久进度通知在所有退出路径都会关闭，不再残留、不再叠层。
- 进度通知改为按 key 隔离，并发流程互不吞没。

## 🎛 交互与体验

## 📦 安装

1. 下载本 Release 附带的 `main.js`、`manifest.json`、`styles.css`。
2. 放入 `<你的 vault>/.obsidian/plugins/novel-writer-ai/`。
3. 在 Obsidian「第三方插件」中重新加载或启用「小说工坊 AI」。

> 升级覆盖前建议备份 `data.json`（其中包含加密后的 API 密钥与全部设置）。
