# v4.26.3 发布说明

> 2026-11-03 · 项目来源统一与 Agent 全权限

## 项目来源统一

- 新增 `shared/project-catalog.ts`，项目列表/身份/删除只有一个实现。
- `listProjects()`、`detectProjects()`、`getActiveProject()`、重命名查重全部委托同一份目录扫描。
- 项目身份只认 `作品信息.md`、`世界观总览.md`、`写作配置.md`、`00-系统模板`、`01-世界架构`、`短篇创作`、`剧本创作`、`.project`；单独的 `03-大纲与章节` 不再算项目。
- `BodyWriter` 写入前校验项目身份；项目已删除时拒绝写入，避免协同/工作台自动保存重建 `03-大纲与章节` 与 `_versions`。
- 协同保存命中「项目已删除」时清空章节绑定并提示，不反复失败。

## Agent 工作台

- 监听 vault `create/delete/rename`，实时刷新左栏项目、项目 chip、文件树与 `AgentContext.projects`。
- 新增全权限工具：
  - `write_file`（创建/覆盖/追加文本文件）
  - `delete_file`（默认回收站，可永久删除）
  - `move_file`（移动/重命名）
  - `delete_project`（彻底删除项目目录）
  - 已有 `run_command` 继续覆盖全部插件命令
- `delete_file` / `delete_project` 保留危险操作二次确认；执行后立即刷新会话项目快照。

## 验证

- 全量单测：**532 文件 / 5900 用例**。
- 新增回归：项目目录单源（`_versions`、`.hidden`、空目录、`03-大纲与章节` 残留）、BodyWriter 删除保护、Agent 写/删/移动/删项目。
- `preflight` / `preflight:release` 全绿；真实 Obsidian E2E 待本次改动后重跑。

## 说明

vault 中仍可能存在删除项目后残留的目录（例如只剩第 3 章正文与 `_versions` 备份）。它现在不会出现在任何项目列表/Agent 工具结果里；如需彻底清理，可让 Agent 执行 `delete_project`（需确认）或手动删除。
