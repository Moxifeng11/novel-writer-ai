# 小说工坊 AI v4.13.0

> 发布日期：2026-10-26 · 上一版本：[v4.12.4](v4.12.4.md)
> 主题：A2/A3 CSS 治理 — 知识库 / 设置 / 向导 / 监控页面内联样式迁移

本版把运行时已恢复后的 A2/A3 CSS 迁移落地。目标不是“重做 UI”，而是在不改变视觉的前提下，把散落在 19 个文件里的内联样式收敛为可组合的 `nw-u-*` 工具类，并清理历史死 CSS。

---

## 一、改动

### A2 · 知识库页面集群（4 文件）

- `ui/views/book-detail-renderer.ts`
- `ui/views/knowledge-base-view.ts`
- `ui/views/knowledge-base-modals.ts`
- `ui/knowledge-detail-modal.ts`

内联样式 **685 → 140**，提取 **220** 个声明级工具类；内联样式中的硬编码颜色全部替换为 `--nw-*` token。

### A3 · 设置 / 向导 / 监控集群（15 文件）

`settings-tab`、`batch-import-modal`、`mini-settings-modal`、`monitor-panel-b`、`wizard-step-renderers`、`prompt-manager-settings`、`knowledge-detail-modal`、`context-panel`、`writing-fingerprint-view`、`fingerprint-detail-modal`、`outline-expand-modal`、`chapter-outline-tree-modal`、`scene-outline-controller`、`refill-modal`、`polish-editor`。

内联样式 **1,231 → 227**，新增 **355** 个声明级工具类。

### 死 CSS 清理

移除 **297** 条未被任何源码引用的历史规则（约 **39.7KB**）；二次扫描 0 候选。

### 颜色 token

- 新增 `--nw-danger-soft`、`--nw-danger-soft-bg`、`--nw-danger-bright-bg`。
- A2/A3 文件内联样式中的 hex/rgb 字面量已清零；图表/SVG 数据色仍保留具体值（需要由图表 API 消费，不在本次范围内）。

## 二、指标

| 指标 | 迁移前 | 迁移后 |
|---|---|---|
| 全局内联 | 2,617 | **1,068** |
| 静态内联 | 2,332 | **840** |
| `styles.css`（LF） | 338,203 B | **321,817 B** |
| `!important` | 260 | **190** |
| 唯一类 | 1,413 | 1,771（新增工具类） |
| CSS + TS 内联总负载 | 528,973 B | **413,384 B（-21.8%）** |

> **目标校准**：原 A3 目标为 `styles.css ≤255KB`。实际工具类把内联样式从 TS 搬进 CSS：CSS 文件仅下降 16.4KB，但 TS 内联字符串减少 99KB，总样式负载下降 21.8%。因此本版将 A3 的 CSS 文件目标调整为 **≤325KB**；若后续仍要求 255KB，应单独引入 CSS 压缩/源码-产物分离（不在本版范围）。

## 四、升级说明

- **无破坏性变更**：仅样式实现方式变化，不改变设置键名、项目目录与数据结构。
- **类名可组合**：新增 `nw-u-*` 工具类；自定义主题若覆盖旧的 `.nw-*` 组件类，仍可继续生效。
- **CSS 体积**：`styles.css` 较 v4.12.4 下降 16.4KB；新增工具类会随页面继续增加，后续新增内联样式会被 `check:inline-styles` 拦截。
- **发布包**：`main.js`、`manifest.json`、`styles.css` 与 `workers/`。
