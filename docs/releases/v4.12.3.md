# 小说工坊 AI v4.12.3

> 发布日期：2026-10-25 · 上一版本：[v4.12.2](v4.12.2.md)
> 主题：M2/M3 非 CSS 收口 — 预算遥测 / 跨视图同分 / 检索下限 / 浮窗契约

本版是代码级补丁，不包含 CSS A2/A3 的页面迁移。A2/A3 需要 Obsidian 运行时截图验收，当前本机 Obsidian 1.12.7 的 CLI 对 `plugin:reload` / `dev:screenshot` 返回 127，无法完成三主题验收，按计划风险约束暂不落盘。

---

## 一、改动

### 1. 预算遥测（R1）

- 新增 `shared/budget-telemetry.ts`：进程内环形缓冲最近 20 条预算快照。
- 记录点：`ai-api-client`（api）、`ai-prompt-builder`（chapter）、`knowledge-injector`（scene）、`prompt-builder`（cowrite）。
- 快照包含模型、输入/可用/窗口 token、丢弃/截断片段、是否超预算。
- 「流程诊断」新增「📊 最近预算」区，展示最近 5 条；本地 8K 窗口被裁剪时可直接定位。

### 2. 本地 Ollama 端口（R1）

- `normalizeOllamaEndpoint` 覆盖 `localhost` / `127.0.0.1` / `[::1]` 的任意端口，自定义端口与 LAN 转发也能改写到原生 `/api/generate`。
- 补 `ai-api-client` 单测，默认 `:11434` 行为不变。

### 3. 跨视图同分（R4）

- 新增 `quality-score-engine-cross-view.test.ts`：同一正文、同一上下文下，仪表盘/协同/Panel B 的 WQE 口径总分与六维一致。
- 移除 `MonitorPanelB#setQualityOptions`（零调用死配置）。

### 4. 检索下限与评估（R6）

- `selectFingerprintsForInjection` 向 V2 检索传 `minScore`，默认 `RETRIEVAL_ABSOLUTE_MIN_SCORE(0.15)`；调用方可显式覆盖。
- 新增 `npm run eval:fingerprint -- --input <fixture.json>`：输出每条 hit@k、整体 hit@k 与 MRR；无输入时退出 0，不阻塞 CI。

### 5. 浮窗契约（R5）

- 新增 `co-write-floating-panel-contract.test.ts`：锁定浮窗保存走 `new BodyWriter(...)`，携带 `project/volume/chapterNum/chapterName` 与 `writingMode: 'co-writer'`，禁止保存路径直接 `vault.modify`。
