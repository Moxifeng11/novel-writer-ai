# v4.79.1 — 社区目录自动审核修复

发布日期：2026-11-09

## 为什么发这一版

v4.79.0 已提交 Obsidian 社区目录，自动审核给出 2 个 Error 与 2 个 Warning。本版逐条修复，**无功能新增、无数据迁移**。

## 主要变化

### 1. 移除插件自禁用/自启用（审核 Error）

- 审核判定 `app.plugins.disablePlugin` + `enablePlugin` 属「静默执行新下载代码」的禁止行为。
- 设置页「🔄 热重载插件」与工作台 Tab 栏「🔄」按钮改为**提示用户手动**在「设置 → 第三方插件」关闭再启用；`_pendingReloadState` 仍在点击时写入，手动切换后 `onload` 会恢复工作台项目/章节。
- 全仓生产代码已无 `disablePlugin` / `enablePlugin` 调用（E2E 测试内的调用不进入发布产物）。

### 2. CSS 漏分号（审核 Error）

- `.nw-u-fwr-gap-4px{flex-wrap:gap:4px}` → `{flex-wrap:wrap;gap:4px}`（`styles-src/10-entity-and-utilities.css:340`）。

### 3. 审核 Warning

- `authorUrl` 改为个人主页 `https://github.com/Moxifeng11`（不再指向插件自身仓库）。
- README 首段改为英文简介（H1 后直接给出），中文简介保留；目录要求 README 必须含英文描述。

## 验证

- `preflight:release` EXIT=0（603 文件 / 6,647 用例）。
- `check:secrets`：0 命中；`check:obsidian-api`：五规则 0。
- 包体：main.js 因移除自禁用逻辑略降（基线按实测收紧）；styles.css 随 CSS 修复 1 字节级变化。

## 影响与迁移

- 行为变更：「热重载」按钮不再自动重载，改为提示手动操作（审核硬性要求）。
- 配置/数据迁移：无。
