# v4.19.0 — 长篇 / 短篇 / 剧本三模式创作体系

发布日期：2026-10-26

## 为什么发这一版

插件此前只有长篇小说模式。短篇与短剧是两套不同的商业内容形态：短篇要求 5–10 万字、快开篇、高密度反转与强情绪兑现；短剧要求分集、场次、3 秒钩子、每集爽点与付费卡点。直接把长篇 11 步套过去会产出“短篇长度、长篇节奏”或“小说式剧本”，无法直接对接番茄短篇与红果短剧。

本版新增独立的创作模式层，同时保留长篇全部行为不变。

## 三种模式

| 模式 | 单元 | 字数 | 核心规格 |
|---|---|---|---|
| 长篇小说 | 章 | 10 万+ | 原有分卷、11 步、长篇导出完全保留 |
| 短篇小说 | 节 | 5–10 万 | 番茄短篇分类、前 3 段钩子、每 1000–1500 字推进、3–5 个反转 |
| 短剧剧本 | 集 | 5–10 万 | 红果短剧、40–120 集、单集 60–120 秒、3 秒钩子、每集冲突/爽点/结尾钩子 |

## 主要变化

### 1. 番茄短篇分类
- 新增 24 个平台分类与性别频道：婚姻家庭、女生生活、男生生活、都市日常、女性成长、现言甜宠、青春虐恋、虐心婚恋、男生情感、宫斗宅斗、古风世情、古言甜宠、古言虐恋、历史古代、年代、民国旧影、玄幻仙侠、悬疑惊悚、女频脑洞、男频脑洞、女频衍生、男频衍生、纯爱、其他。
- 创建短篇项目时必须选择分类，分类决定提示词中的读者期待、情绪承诺与节奏约束。

### 2. 红果短剧规格
- 内置 12 类短剧类型：都市逆袭、战神归来、甜宠、虐恋、复仇、家庭伦理、古装权谋、悬疑、脑洞、年代、民国、萌宝。
- 每类包含核心钩子、核心冲突、兑现方式。
- 规格：40–120 集，单集 60–120 秒，单集 3–6 场；前 3 集强钩子与付费点铺垫，第 10–15 集设置强付费卡点。
- 剧本格式：集-场标题、人物、动作/画面、对白、必要 VO/字幕；对白驱动，禁止小说式大段心理描写。

### 3. 项目创建与元数据
- 新建项目新增「创作模式」选择：📖 长篇 / 📄 短篇 / 🎬 短剧。
- 短篇显示 24 分类下拉；短剧显示类型、目标集数、目标字数。
- `.project` 新增：
  - `## 创作模式`（long/short/script）
  - `## 短篇分类`
  - `## 剧本类型`
  - `## 目标字数`
  - `## 目标集数`
- 项目内自动生成 `00-系统模板/创作模式指南.md`，可手工修改。
- 写作配置同步保存模式、分类、目标字数/集数；旧项目缺少字段按长篇兼容。

### 4. 模板与提示词
- 新增 `shared/creation-mode.ts`：三模式规格、24 分类、12 短剧类型、模式元数据、创作指南、提示词覆盖块。
- `template-vars-builder` 读取项目模式，生成 `creationModePrompt`。
- `getStepTemplateAuto` 在短篇/剧本模式下把模式硬约束追加到 system prompt；长篇没有覆盖块，原提示词完全不变。
- 协同写作初始化时读取 `.project`，把同一模式约束注入续写/联想/改写/迭代 prompt；长篇为空块，原协同行为不变。
- `BatchCreateModal` 在短篇/剧本模式下不依赖分卷大纲，可直接按目标节数/集数创建单元骨架，并默认当前选中项目。
- 短篇/剧本正文骨架使用「第N节 / 第N集」显示；内部文件命名仍保持 `第N章_正文.md`，避免破坏既有章节索引。

### 4.5 独立入口与前期调研
- 通用「新建项目」收敛为长篇/同人；短篇、剧本使用独立命令与快捷工具入口。
- 新增短篇/剧本「前期调研」模块：先完成分类、故事核/商业钩子与目标规格，再创建项目。
- 调研结果写入 `00-前期调研/`：`调研数据.json`、`调研报告.md`、`五维分类.md` 或 `剧本定位.md`，不写入长篇 11 步状态。
- 项目卡片选中后自动识别模式，右侧快捷工具与项目操作按长篇/短篇/剧本切换。

### 4.6 左侧分类与独立内容
- 新增左侧「长篇小说 / 短篇小说 / 剧本」分类导航，三类项目按模式过滤，列表互不混入。
- 短篇内容写入 `短篇创作/`：故事核、分节大纲、正文、质检、导出。
- 剧本内容写入 `剧本创作/`：人物与场景、分集大纲、剧本、分镜、质检、导出。
- 新短篇/剧本项目不再创建长篇 `03-大纲与章节`；批量建节/建集只写模式正文目录。
- 短篇/剧本卡片使用「前期调研 / 写作 / 全部节/集」等专属操作，移除长篇向导/句级协同等按钮。
- 新增故事核、分节大纲、场景圣经、分集大纲、分镜表专属编辑入口。

### 4.7 API 连通性与思考强度
- 设置页 API 区域新增「🔌 测试连通性」：验证端点/鉴权/模型/延迟，401/404/429/5xx/超时/空响应分级告警。
- 探测使用 `requestUrl` 最小请求，不记录密钥；本地端点允许无密钥。
- 全局思考升级为极速/标准/深度/极限四级 + 0–100% 拖拽滑杆；任务级可选等级覆盖。
- 思考预算按强度缩放；旧 `thinkingMode/thinkingBudget` 未设置新字段时保持原行为。
- 新增流程设计文档：三类流程细化、短篇三步快速流程、剧本分镜场全流程。

### 4.8 三域隔离与 Harness MVP
- 新增 `domains/` 命名空间：长篇/短篇/剧本各自拥有工具目录与领域逻辑。
- 长篇工具与创建弹窗移除短篇/剧本入口与字段；短篇/剧本创建由独立 `DomainProjectFactory` 承担。
- 新增模式库：`长篇小说/`、`短篇小说/`、`剧本/`；项目 ID 使用库内路径，检测、激活、导出、批量均支持。
- 新增 legacy 项目迁移服务与设置页「项目库迁移」，支持 dry-run、备份清单与冲突检测。
- 新增 Harness MVP：规则引擎、上下文聚合器、结构化输出契约、单次调用 Runner、调用账本。
- 长篇 AI 消痕、迭代精修、定向修订改为一次逻辑调用完成；本地校验失败不隐藏二次调用。

### 4.9 AI 辅助创作前期调研
- 短篇/剧本前期调研弹窗新增「🤖 AI 前期调研」与「🎲 随机灵感」。
- 调研服务结合配置的搜索 provider（Bing/Brave/Serper/Tavily）检索热点素材；未配置时退回模型调研草稿并显式标记“未经实时核实”。
- 固化创作框架：番茄短篇“高密度单线框架”与红果短剧“3 秒钩子分场框架”，阶段、交付物、校验节点程序化。
- 多层真随机因子：CSPRNG 随机源驱动前提/结构/质感/差异化四层因子，附加禁用套路清单，避免同质化。
- AI 输出 3 个差异化候选方向，可一键应用到调研表单；候选区分不同主角身份、冲突类型与情绪曲线。
- 「随机灵感」升级为统一种子卡片：种子值可查看/复制/重置，分组 chips 展示四层因子与禁用套路；短篇/剧本共用同一组件。
- 调研产物写入 `00-前期调研/`，新增「五、AI 前期调研」章节：来源、未核实标记、固化框架、随机种子与因子；保存前自动备份旧报告。

### 4.10 Harness M1 契约
- 新增 `PromptArtifact`：模板版本、变量、context/rule/contract id、预算与稳定 hash。
- 新增 `ContextPack`：typed fragments、required 片段不被裁剪、预算超限记录 dropped。
- 新增 `RetrievalPlan` / `RagCitation`：结构化/语义/关键词/外部查询与可信度标记。
- 新增 `MemoryStore`：项目内 `Harness/memory/{pending,confirmed,rejected}`，AI 记忆默认 pending。
- 新增 `ToolRegistry`：按模式过滤、权限校验、危险工具确认、结构化错误。
- 新增三域 `HarnessProfile`：长篇/短篇/剧本的内容 schema、必备上下文、规则集、工具与质量门。
- `SingleCallRunner` 支持可选 PromptArtifact；未提供时保持原调用路径。
- 设计文档包：`docs/design/v4.22-harness/`。

### 5. 项目与章节管理
- 项目卡片显示模式与分类徽章。
- 项目概览使用「总节数/总集数」「已完稿 N 节/集」「下一节/集」。
- 短篇/剧本项目卡按模式单元统计与打开正文；长篇仍走章节向导。
- 导出使用模式单元标签；短篇/剧本不输出卷标题。

### 6. 导出适配
- 短篇：`项目名-短篇-日期.txt/.md`，标题按「第N节」。
- 剧本：`项目名-剧本-日期.txt/.md`，标题按「第N集」，保留场次/人物/动作/对白。
- 长篇导出逻辑与文件命名保持不变。

### 7. 指纹库与知识库
- 两个视图改用容器查询响应式布局，窄面板自动改为纵向；修复指纹列表计数重复累积。
- 新增九维规则自动分类（节奏/语言/情绪/对话/结构/题材/技法/商业/受众），指纹与书籍显示分类徽章。
- 指纹支持单条“自动归类”，知识库支持“维度归类”与“批量归类”；标签统一 `分类:` 前缀、去重、上限 30 条。
- 修复指纹统计：分号不再算句末、网文单行按段统计、英文引号对话不再重复计数。
- 混合检索：指纹叠加关键词/标签重排；知识检索按 90% 向量 + 10% 关键词覆盖率打分并去重。
- 列表/详情加载失败显示原因与重试入口。

### 8. 执行流程与错误交互
- 主区域新增执行时间线，按时间展示上下文加载、步骤开始/完成/失败、警告与 AI 进度。
- 一键完成与逐步完成共用同一套结构化失败模型（节点、原因、缺失项、处理建议）与“重试本步”入口。
- 移除章节执行过程中的浮动 Notice；错误卡直接显示在失败步骤位置。
- 新增固定执行日志窗口：展开/收起、级别筛选、滚动、复制、堆栈查看；事件 300 条、日志 800 条上限。
- 系统/用户提示词默认折叠；执行结果移动到提示词之前，提供预览与折叠编辑区；模板骨架不再显示为结果。
- 步骤页新增置顶操作栏（状态、生成/重新生成、跳过、温度），按钮改为紧凑胶囊样式；正文页移除大块协同营销卡，改为两个紧凑入口。
- 信息规划提示词改为逐项 Markdown 标签，并强制输出独立的“冲突强度：N/5”行。
- 信息规划校验接受“冲突强度 4/5”等写法；合并规划提示词补齐 `INFO_PLAN` 结构标签，减少一键模式格式性中断。
- 长篇项目新增五套故事结构（起承转合/三幕式/五幕式/英雄之旅/序破急）与九组创作前设定；创建弹窗与长篇向导第一步都能配置。
- 智能随机组合使用 CSPRNG，并对力量体系、金手指、人物原型、基调做冲突校验；随机结果写入 `.project`、故事结构指南与创作模式指南，作为后续提示词硬约束。
- 项目卡片显示故事结构徽章；长篇向导新增「故事结构」步骤，旧项目可随时补配。
- 章节状态栏新增叙事结构下拉，五套结构可自由切换；切换写入项目元数据并立即影响后续步骤，生成中禁止切换。
- 新增 CSS 设计系统 v2：统一表面/输入/焦点/触控令牌，故事结构面板改为双栏分组 + 阶段比例轨道，并补齐 960/760/520 响应式与 reduced-motion。
- 整章正文模板新增场景描写硬约束；协同写作新增「🎬 场景描写」动作，description 方向强制使用当前 Scene 卡。
- 新增对话引导 Agent：命令面板/项目与章节页进入，最前端先选长篇/短篇/剧本；长篇再分原创/同人两条路径。
- 短篇引导补齐平台分类、故事核、冲突、情绪承诺、反转、结尾与角色核心；剧本补齐类型、logline、3 秒钩子、冲突、兑现、角色、场景、集数与付费卡点。
- 短篇/剧本通过 DomainProjectFactory 直接创建并写入 `00-前期调研`，无需打开长表单；长篇创建后衔接项目向导、故事结构或项目与章节。
- 新增项目创建服务，表单弹窗与 Agent 共用模板复制与元数据写入；自由文本优先 AI 槽位解析，失败回退 chips/序号。
- Agent 关键节点改为选择卡，展示预期效果、适用场景、风险与操作预览。
- 新增引导/自动双模式：自动模式用 CSPRNG 自洽随机与默认值填完剩余参数并直接创建；可随时切换。
- 自动链路从类型选择覆盖到创建并打开工作区；长篇仍进入原有项目向导，短篇/剧本写入前期调研。
- 项目与章节页顶部新增固定「🤖 对话引导」入口；空态、命令面板、项目页三处可达。
- 新增人类写作节奏提示：句长/段长起伏、具体细节、情绪行为化、去总结/排比/比喻链；注入正文、协同写作与 DEAI 改写。

## 已知边界

- legacy 项目在迁移前仍位于根目录，通过兼容路径访问；迁移后进入三库。
- 共享内核保留 AI 客户端、设置、日志、文件 IO、提示词预算、导出文件写入与项目定位。
- 功能级单调用不等于章节级单调用；一键成章仍是显式编排。
- 合并规划隐藏回退、批量写章调用数优化、co-writer snapshot 持久化列入 harness 路线图。
- 未配置搜索 API 时，热点调研为模型草稿并显式标记“未经实时核实”；用户需人工核实。
- “真随机”指 CSPRNG 非确定性采样；不保证绝对不可能重复，但消除固定 prompt/种子导致的同质化。
- 短篇/剧本复用现有 11 步执行器与章节文件命名，显示与导出映射为节/集；没有另建一套流水线。
- 短剧的镜头、分镜、演员调度仍由作者/制作方细化，本版保证剧本结构、节奏与商业化钩子。
- 短篇分类来自平台分类页，平台新增/调整分类时需要同步 `shared/creation-mode.ts`。
- 长篇模式的模板、提示词、导出、章节命名与 v4.18.0 完全一致。
