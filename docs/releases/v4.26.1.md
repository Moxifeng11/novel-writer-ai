# v4.26.1 — 润色入口、落盘与字数统计修复

发布日期：2026-11-03

## 为什么发这一版

正文完成后，消痕/精修入口在自动推进到后续步骤时消失；迭代精修因参数 `undefined` 无法定位正文；结算后打开章节，润色编辑器因内存中没有 `bodyGeneration` 静默失效；字数统计信任 frontmatter 里可能过期的 `word_count`。这些问题共同表现为“功能看起来在，实际不工作”。

## 主要变化

### 1. 核心链路

- 消痕/精修按钮在正文完成后、所有后续步骤中保留。
- `executeIterativeRefine` 传入真实章节参数（chapDir/chapterName/volume）；入口 Promise 统一捕获，按钮防重复点击。
- 打开已结算章节时从正文文件回填 `bodyGeneration`；渲染异常显示错误与「重试加载」。
- 一键流程新增单步看门狗（默认 8 分钟），超时 abort 并抛可重试错误。

### 2. 数据与结构

- 字数统计按正文实算，不再信任 frontmatter `word_count`（仅正文读不到时兜底）。
- 修复 `extractChapterTitle` 的 `\s` 跨行匹配；标题缺失时用旧 frontmatter/章节名兜底；正文校验新增「标题完整」。
- 删除正文格式说明中残留的 2–6 句/80–220 字硬指标。

### 3. 协同写作

- 新增「🧾 剧情冗余」入口，对比前文场景/冲突/短语重复。
- 底部操作栏统一忙碌态与异常捕获；保存失败时「结算」不再提示成功。

### 4. 技术债与依赖

- Vitest 1.6→4.1.12、esbuild 0.25.12、Playwright 1.64.1、obsidian 类型 1.14.4。
- `npm audit` 39 条（3 critical / 9 high）→ 23 条（0 critical / 0 high），剩余为 `eslint-plugin-obsidianmd` 内嵌 moment 的中危。
- 删除 `engine/prompt-manager.ts` 与 `engine/prompts/writing-rules-legacy.ts`。
- 覆盖率按 Vitest 4 AST 口径重取阈值（全局 lines 64 / branches 55；shared 85/77）。

## 验证

- 单测 529 文件 / 5,879 用例通过。
- 新增标题兜底、标题完整性、字数统计、单步看门狗、润色入口参数回归。

## 影响与迁移

- 破坏性变更：无。
- 配置/数据迁移：无。
- 回滚建议：如遇润色入口异常，回退到 v4.26.0 并保留章节文件。
