# v4.66.0 — 两文件 any 清零与 Worker 消息路径测试

发布日期：2026-11-07

## 为什么发这一版

v4.65.0 之后三批：继续 any 收窄（187→179）、把 worker-manager 的 Worker 侧消息路径补上测试、并给 `check:automation` 补两条防漂移校验。**无运行时行为变更**：`main.js` 逐字节不变。

## 主要变化

### 1. `scene-outline-controller.ts` / `command-registry.ts` any 各 4→0

- 场景卡：下拉值用 `ConflictType`/`PleasureType` 断言；新增 `SceneTextFieldKey` 映射类型（只收类型恰为 `string` 的字段，排除 `boolean`/`number`/字面量联合），文本输入写回不再需要 `as any`。
- 命令注册：`ctxManager` 收为 `unknown`（全类零调用，注释保留注入点）；两处 `(plugin as any).worldviewCacheService` 改为直接取（`main.ts` 已 public 声明）；`editorCallback` 返回 `void`（3 个注册点均返回 void）。
- **取舍记录**：首版用 `options.find` 白名单做运行时校验，`main.js` +72B，违反「零运行时」约束；改为联合类型断言后体积恢复。门禁类派工要求 bundle 不变时，运行时校验不能进。

### 2. Worker 侧消息路径测试（6→11 用例）

- `worker:ready` 后 `task:progress`/`task:complete` 驱动结果且空闲 Worker 复用（实例数不增）；
- 可恢复 `task:error` 降级主线程执行；
- 网络关键词 `task:error` 拒绝并释放 Worker；
- `worker:error` 回收且禁用降级时拒绝当前任务；
- `worker:warning` 注入降级通知。
- `FakeWorker` 增加 `emit` 与握手辅助；清理用 `restoreAllMocks`。

### 3. `check:automation` 边界加固

- `params.typeWeights` 必检键补 `v5-product`——此前漏检了 v5 使命新增的权重。
- 新增轮次三处一致性校验：顶层 `round` ↔ `lastRound.round` ↔ `rounds` 末条；字段缺失时跳过，不误伤旧台账。
- `handbook/13-dual-automation-ops.md` 校验清单同步。
- 验证方式：正向 `EXIT=0` + 临时夹具负向 `EXIT=1`（两条 error 精确命中），夹具已清理。
