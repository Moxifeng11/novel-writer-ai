# v4.91.0 — 项目标准约束 + 事实库可编辑 + 长篇评测

发布日期：2026-11-13 · tag：`4.91.0` · 上一版本 v4.90.0

## 为什么发这一版

v4.90.0 让事实库「自动维护 + 可浏览 + 三处第二意见」。但它还有两个缺口：
**项目结构没有标准可依**、**事实库只能看不能改**；而"这些能力在真实作品上到底靠不靠谱"
也从未被系统测量过。

这一版补齐三件事：项目标准约束、事实库编辑、长篇端到端评测。

## 新增：项目化标准约束

### 单一标准源

12 个必备目录（`01-世界架构/{人物,势力,地点,物品}`、`02-时间线与伏笔`、
`03-大纲与章节/{正文,分卷大纲}`、`04-项目总控/{剧情记忆,故事台账}` 等）、
必备文件（`.project`）、命名规范、标准版本号。

**运行时实现只在 `scripts/lib/project-standard-lib.mjs` 一处**，
TS 侧（`shared/project-standard.ts`）只是类型门面——避免两套标准并存。

### 7 类结构校验

| 类型 | 严重度 |
|---|---|
| 缺必备目录 / 缺必备文件 | error |
| 事实库损坏 | error |
| 命名不符 / **摘要缺失** / 事实库版本缺失 / 标准落后 | warning |

**摘要缺失**这条直接对应历史踩坑：没有章节摘要的项目跑审核会得到 0 产出，
用户会误以为"没问题"。

### 门禁与手册

```bash
node scripts/check-project-standard.mjs [--vault <path>] [--json]
```

退出码 0/1/2；**vault 内没有项目不算失败**（新库/纯素材库属正常）。
手册见 `docs/handbook/07-project-standard.md`。

## 新增：事实库视图内编辑

| 操作 | 说明 |
|---|---|
| 改值 / 改有效区间 | 行内编辑 |
| 标记忽略 | 保留事实与引文，但排除出第二意见 |
| 删除 | 误抽的条目直接删 |

**写入前整批校验**：空主体/空谓词/空值/区间倒置/置信度越界一律拒绝，
失败弹提示说明原因，**绝不静默丢弃用户编辑**。

## 新增：能力等级序第二意见

修为/能力**天然是合法变化**（练气三层 → 筑基一层是进阶）。按字符串比较会全是误报。

```
境界 rank×100 + 层数：练气三层=1003、筑基一层=2001
筑基一层 > 练气九层（跨境界优先于层数）
新序数 ≥ 旧 → 不报（合法进阶）
新序数 < 旧 → 报（倒退需要理由）
无法解析 → 不猜
```

已接入正文生成后的质量验收链路（真实生产调用方）。

## 新增：长篇端到端评测

数据源：《将夜》前 30 章真实拆解事实 456 条（复用已有数据，不额外产生 LLM 费用）。

| 指标 | 结果 |
|---|---|
| **真实数据误报** | **0 / 456 条** |
| **合法变化误报** | **0 / 10**（能力进阶） |
| 当前年龄类注入召回 | **2 / 2 = 100%** |

### 评测中发现并修复的真实缺陷：R1 年龄规则

| 阶段 | 问题 | 修法 |
|---|---|---|
| 首轮 | 谓词要求恰好 `=== '年龄'`，LLM 的「年龄约」「年纪」变体整类漏报 | 改为包含匹配 |
| 二轮 | 包含匹配吞进回溯限定谓词，产生假矛盾 | 改为**前缀锚定** |

被排除的回溯谓词实例（已核对原文）：

```
第6章「桑桑才八岁的时候你就开始提亲」
  → LLM 抽成「被提亲起始年龄=八岁」（抽取没错）
  → 但这是回溯叙述，不是当前年龄 → 不应参与「11岁→8岁」比对
```

**教训：中文谓词限定词常前置于核心名词（被提亲起始年龄 / 请求远嫁时年龄 / 入初境年龄），
包含匹配会吞进局部语义，前缀锚定才是正确边界。**
