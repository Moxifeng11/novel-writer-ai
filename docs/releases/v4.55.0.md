# v4.55.0 — B3 出版事实纯函数化

发布日期：2026-11-06

## 为什么发这一版

v5 B3 要求对短篇/剧本的严格出版阻断做真实导出回归。无 GUI 测试环境下无法点击真实弹窗，因此把弹窗内联的「章节 → 出版事实」抽成纯函数，既完成回归口径，又把商业化判定与 UI 解耦。

## 主要变化

### B3：`buildPublicationFacts` 抽取

- `shared/publication-profile.ts` 新增 `buildPublicationFacts(units, base)`：
  - frontmatter 剥离后判空（空单元列表）；
  - 标题归一后重复计数（duplicateTitleCount）；
  - CJK 字数汇总（与导出口径一致，仍含 frontmatter 字数）；
  - `unitCount` / `writtenCount` / `emptyUnits` 由事实推导。
- `ui/export-manuscript-modal.ts` 改为调用纯函数构建事实，**零运行时行为变化**（纯搬运）。
- 用例 7→11，覆盖 B3 回归：
  - 导出单元计数（章/节/集口径）；
  - 短篇 EPUB「缺作者 + 空节」= blocker；Markdown 缺作者不阻断；
  - 短篇字数 3 万 = warning、2 万 = blocker（下限一半规则）；
  - 剧本 30 集仅 unit-count-low warning；全空集触发 no-body + empty-units。

### 口径（未变，待用户拍板）

- 严格模式阻断项保持现方案：**缺作者仅 EPUB/DOCX 阻断；字数低于下限一半才 blocker；集数仅 warning**。
- `COMMERCIAL-GUIDE §2` 的阻断/建议清单与代码逐条核对一致。
