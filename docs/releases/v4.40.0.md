# v4.40.0 — 多实例收敛、轻量结算写锁与第四批切片/提示

发布日期：2026-11-05

## 为什么发这一版

审计 P1-6「多实例状态源」一直没动；轻量结算的正文 frontmatter 写入还独立于 `BodyWriter` 的写锁；协同引擎与 Notice 也还有可收口空间。本版三项并行推进。

## 主要变化

### 1. StyleIntensityEngine 单例收敛（5 → 1）

- `engine/style/style-intensity-engine.ts` 新增 `getStyleIntensityEngine()`（懒加载共享实例）。
- 5 个消费方统一取用：`knowledge-injector`、`prompt-builder`、`style-fingerprint-library`、`style/dynamic-injection-engine`、`ui/polish-editor`。
- 该类无可变状态（所有方法纯计算），共享不改变行为；新增 2 例测试锁定「同实例 + 与新建实例结果一致」。
- `check-engines` 基线按棘轮收紧：`StyleIntensityEngine` 5 → **1**。

### 2. 轻量结算正文写锁

- `settleLight` 末尾的 `processFrontmatter` 补 `withWriteLock(bodyFile.path, …)`。
- 与 `BodyWriter.write()` 的整篇覆盖共用同一路径锁：轻量结算与协同自动保存并发时，不再出现「读旧 frontmatter → 覆盖新状态」。
- 文件查找仍在锁外；异常仍只 `log.warn`，不改变失败语义。

### 3. 协同引擎切片第四批

- `co-writer-engine.ts` 3,479 → **3,407**（-72）。
- `getCoWriteOptions` 及 `getCoWriteModel`/`resolveLocalProvider` 抽到 `engine/co-writer/co-write-options.ts`；`settings` 与 `resolveModelLimits` 显式入参，云/本地分支、`disableFallback`、`numCtx` 下限 2048、本地无 provider 的阻断文案逐行保留。
- 引擎保留同名薄委托，测试经实例访问不受影响。

### 4. Notice 第四批

- 6 个文件替换 **34 处**（成功 18 / 失败 14 / 告警 2）：API 设置 8、Agent 工作台 1、知识库详情 4、知识库视图 9、写作工作台 5、指纹视图 7。
- 守卫/进度/预检/带操作引导提示保留；eslint 135 → 135，0 新增。
- 累计铺开 **127 / 约 990 处**。
