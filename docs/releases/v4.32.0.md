# v4.32.0 — 模型单价、Agent 细粒度归因与协同切片（M4 第三批）

发布日期：2026-11-05

## 为什么发这一版

M4 第二批交付了用量账本与归因，但留了三个尾巴：账本只有 token 没有「花了多少钱」、Agent 归因只到回合级、协同视图仍有 5,389 行。本版继续由三个实现子代理并行收口。

## 主要变化

### 1. 模型单价与费用估算

- 新增 `shared/model-pricing.ts`：
  - 单价来自 `CustomProvider.modelMeta.inputPricePerM/outputPricePerM`（**单位：元/百万 tokens**），按 model 精确匹配；
  - 不内置价格表（价格随官方调整，猜错比不填更糟）；未配置 = 不计费。
- 模型编辑弹窗（设置 → API 配置 → 编辑模型）新增「输入/输出单价」输入，留空不计费、0 视为免费、负值拒绝。
- 用量账本：
  - `UsageRecord.costYuan` 与 byModel/byProject/bySource 全维度累计；
  - 汇总卡「费用(元)」、按模型表费用列、单条记录 `¥x.xxxx`；
  - 未配置单价时不显示 0 元，避免误导。
- 口径说明：按请求 model 计价（与账本 model 字段一致），fallback 后实际模型差异与缓存命中不单独区分；老记录无 costYuan 按 0 计入。

### 2. Agent 归因细化

- 回合内模型调用：`stepKey: 'turn:<step>'`；
- 工具执行：`stepKey: 'tool:<name>'`（嵌套 scope 重述 source/project——scope 栈顶整体生效）；
- 当前 host tools 均不调 AI，此归因为未来「会话内生成类工具」预留精确计费口径；新增行为级测试（fake 工具在 execute 内读 `currentUsageScope` 断言）。

### 3. 协同视图切片（第二批）

- `ui/co-writing-view.ts` 5,389 → 5,152（-237）：
  - 知识库参考卡 → `ui/co-writing/kb-reference-card.ts`（10 成员宿主接口，DOM 归一化 diff 验证等价）；
  - 写作建议 → `ui/co-writing/writing-advice.ts`（纯函数化，无 DOM 无状态写入）。
