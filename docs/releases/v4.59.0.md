# v4.59.0 — B3 三档交付级别与导出范围

发布日期：2026-11-06

## 为什么发这一版

v4.58.0 的严格模式只有一个布尔开关，同时承担「自存草稿 / 交编辑审阅 / 平台投稿」三种意图；且导出恒为整包，批量建章留下的空骨架会让严格模式永久阻断。本版按用户拍板实施 **方案 A：三档交付级别 + 显式导出范围**。

## 主要变化

### 1. 三档交付级别（`PublicationLevel`）

| 级别 | 阻断（blocker） | 建议（warning） |
|---|---|---|
| `draft` 草稿 | 书名空、完全没有正文 | 空单元、字数不足、作者缺失 |
| `finished` 成品（默认） | 书名空、无正文、空单元（未排除时） | 字数不足、TXT/MD 作者缺失、单元数不足、重复标题、EPUB 无标题 |
| `submission` 平台投稿 | 以上 + **作者全格式必填** + **字数低于下限一半** | 字数低于下限、单元数不足、重复标题、EPUB 无标题 |

### 2. 导出范围（`PublicationScope`）

- `全部单元（整包）`：空单元参与判定。
- `仅已写单元`：**实际过滤空骨架**，不写入导出文件，并豁免空单元阻断（仅成品档；平台投稿强制整包）。
- 成功的导出提示会显示「已跳过 N 个空章/节/集」。

### 3. 实现与兼容

- `shared/publication-profile.ts`：新增 `PUBLICATION_LEVEL_LABELS`、`splitUnitsByBody`；`PublicationFacts` 增 `level/scope/excludeEmptyUnits`。
- **向后兼容**：不传 `level` 时保持 v4.58.0 旧矩阵（旧调用与既有测试不变）。
- 导出弹窗：交付检查/导出范围下拉；投稿档强制显示作者行；成品档遇空单元阻断时提示切换范围。
- 联动锚点 `strictPublication` → `publicationLevel`；USER-GUIDE / COMMERCIAL-GUIDE 更新判定矩阵。

## 影响与迁移

- 行为：默认检查强度由「关闭」变为「成品」（用户已在方案中确认）；草稿档可恢复只提示。
- 配置/数据：无迁移；`level` 为可选入参，回滚时旧调用矩阵不变。
- 回滚建议：revert 对应提交；弹窗恢复布尔开关。
