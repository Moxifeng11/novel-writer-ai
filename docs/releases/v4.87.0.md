# v4.87.0 — 跨章一致性审核（从"写得好不好"到"前后对不对"）

发布日期：2026-11-13 · tag：`4.87.0`（无 `v` 前缀，Obsidian 社区目录规则）· 上一版本 v4.86.0

## 为什么发这一版

v4.85.0 修的是"用户以为生效、其实没生效"的**代码缺陷**。这一版补的是另一类问题：
**作品自身的前后矛盾**——AI 忘了自己写过什么，用户却要为此返工。

调研支撑（见 `docs/analysis/2026-11-13-consistency-bottleneck-research.md`）：
ConStory-Bench（arXiv 2603.05890）实测「**事实与细节**」「**时间线与情节逻辑**」
是长篇小说的主导失效模式，且错误**集中在中段**、出现在**高熵片段**。

而插件此前把 90% 的质量检查投在单章表面质量（文笔/节奏/情绪），跨章语义比对几乎空白。

## 新增功能：一致性审核

命令面板 → **「一致性审核」**（也可从工具分组进入）。

### 能查什么（9/19 个子类）

| 类别 | 已覆盖 |
|---|---|
| 事实与细节 | 命名混淆 · 数量不符 · 外貌不符 |
| 时间线与情节逻辑 | 绝对时间 · 时长 · 同时性 · **无因之果** · **因果违规** · 废弃情节 |

### 每条问题都带证据链

```
数量不符   张三 · 年龄   置信度 92% ｜ 规则判定
第1章「张三」20 岁，到第40章反而变成 18 岁——年龄不可能倒退。
A 第1章「张三今年二十岁」[跳到正文]
B 第40章「张三今年十八岁」[跳到正文]
```

**没有双侧引文与位置的判定一律不产出**——这是可信度的底线，不是可选项。

### 成本设计（关键）

**两级判定**：

| 层 | 成本 | 覆盖 |
|---|---|---|
| 规则层（R1–R9） | **零 token，全量跑** | 年龄倒退、同章数值冲突、化名冲突、时长不相容、同章两处地点、因果冲突、因果倒置 |
| LLM 复核层 | 仅复核**疑似项**，默认上限 10 对 | 名称仅差一字、废弃伏笔仍有提及 |

另含**风险定位**（`risk-targeting`）：中段加权 0.4 + 字符熵 ×0.35 + 罕见字密度 ×0.25，
只挑高风险段送复核——本地统计，零 API 成本。

实测一例仅有规则命中的项目：`模型复核 0 次`，未产生任何模型费用。

### 指标：CED

采用 ConStory-Bench 的 **CED（每万字符错误数）**，用于证明"这一版比上一版好"：

```
CED 204.08 处/万字符（1 处 / 49 字）
注意：字符数只统计参与比对的正文；章节摘要缺失时数字会偏高。
```

## 修复的真实缺陷（生产环境实测发现）

| 缺陷 | 影响 |
|---|---|
| **原子写用 rename 覆盖已存在文件** | Obsidian 抛 `Destination file already exists!` → 第一次成功、**第二次起全部失败**（审核"有时好使有时不好使"） |
| **字数统计台账同款问题** | `persistNow` 一律 tmp+rename → 目标存在即抛 → 被 catch 后只 warn，**此后字数统计永不持久化** |
| **命令执行体缺失静默失效** | `exec(id)` 无对应 `r.register` 时命令"显示已执行但什么也没发生" |
| **Modal 焦点下 `getActiveProject()` 为空** | 命令提前 return，同样是"点了没反应" |

前两项的测试替身也不忠实（`rename` 允许静默覆盖），已一并修正——否则回归锁永远绿、上线必炸。

## 新增门禁：`check:command-handlers`

`preflight` **29 → 30 步**。拦"命令显示已执行但什么也没发生"：

- 每个 `exec(id)` 必须有 `r.register`（**光有 executor 分支不算**）
- 走 UI 端口批量注册的，执行器必须有对应 `case`
- 量具自检：解析不到任何 `exec` → exit 2（防正则失效后永远绿）

当前 75 个 exec 命令全覆盖。

## 升级说明

无破坏性变更。升级后在任一项目内运行「一致性审核」即可。

首次运行会建立 `04-项目总控/一致性审核/断言.json`，之后逐章增量累积。
若章节摘要缺失，结果会偏少——视图空态里已明确说明该边界。
