# v4.57.0 — B2 阶段面板竞态修复

发布日期：2026-11-06

## 为什么发这一版

B2 工作台真机回归时确认了一个真实竞态：`refreshStagePanel` 先记录 `activeProject` 再 `await port.getProjectStatus`，返回后未复检项目——快速切换甲乙项目时，甲的快照可能晚到并覆盖乙。本版修复该缺口，并把读取失败降级抽成可测 seam。

## 主要变化

### 1. 竞态修复

- `ui/agent-workbench-view.ts`：`await` 后以 `this.activeProject !== project` 丢弃过期结果（-19 行，删除两处失效类型导入）。
- 视图改用新 seam，不再内联 try/catch。

### 2. `fetchStagePanelModel` seam

- `ui/agent-workbench/stage-panel.ts`（+33 行）：`fetchStagePanelModel(project, getStatus)` —— 读取失败（抛错或 null）时返回占位模型，不向调用方抛出；无 port 环境直接占位。

### 3. 测试 8 → 16

- 有项目渲染 / 未选项目不请求 port；
- 切换项目晚到旧结果仍带原项目标识（竞态回归）；
- port 抛错与 null 均占位；
- 三条接线契约：过期丢弃、初次渲染+列表刷新+切换三处刷新、点击阶段只 `prefillComposer` 不提交。
