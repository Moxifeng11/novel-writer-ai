# v4.81.1 — 协同/Agent/更新检查与设置体验收口

发布日期：2026-11-09

## 为什么发这一版

本轮集中处理四个日常使用反馈：协同写作顶栏重复入口、Agent 工作台固定开场与窄输入框、检查更新 403、API 配置页过长与设置页签过杂。均为体验与可靠性修复，无数据结构迁移。

## 主要变化

### 1. 协同写作去重

- 顶栏移除「剧情」「实时质量」入口；「实时质量」整条评估链路下线，质量能力由自动打开的 MonitorPanelB 与「质量仪表盘」继续提供。
- 「剧情」浮窗保留，因为「更多工具 → 质检」仍复用同一浮窗展示质检报告与 AI 味检测。
- 「精准模式」按钮保留（该模式的唯一开关）。

### 2. Agent 创作工作台

- 会话快照新增项目上下文签名；恢复前与当前项目集合/活动项目校验，旧存档引用已删除项目时不再回放旧欢迎语。
- 启动占位「（会话开始…）」不再作为用户气泡回显。
- 输入区宽度自适应：左/右栏加最大占比，中栏最小 420px；输入框初始高度 ≥40px，保持 Enter 发送 / Shift+Enter 换行。
- 新增图片附件：选择、粘贴、拖拽；图片写入 `.sessions/agent/attachments/<项目>/`，发送时以路径引用，用户气泡与历史恢复显示缩略图。本轮不做多模态 content blocks。
- Agent 返回的 `pickedProject` 会校验仍在项目列表中，避免把会话写到已删除项目。

### 3. 检查更新修复

- GitHub 请求补 `User-Agent` 与 `Accept: application/vnd.github+json`，修正公开仓库被 403 误判为「无访问权限」。
- 15 秒超时 + 有限重试；403/429 读取限流头与响应 message，区分 Token 无效、主限流、次级限流。
- API 失败时回退 `releases.atom` → raw `manifest.json`，公开仓库在 API 限流时仍可检查。
- 失败不覆盖上次成功结果；About 页显示「上次成功版本 + 本次错误」，并增加在途锁与 15 秒手动检查间隔。

### 4. API 配置与设置页

- 「测试连通性」上移到 API Key 之后、模型列表之前；错误信息可换行。
- 模型列表限高 240px 内部滚动；API 详情区 70vh 内滚动。
- 任务级模型参数、同人考据、密钥加密改为可折叠；删除冗余「保存设置」footer（字段已即时保存）。
- 18 个设置页签拆为「常用 / 高级」两组，高级默认折叠并记忆展开状态；迷你设置弹窗同步。

## 验证

- `preflight` EXIT=0（608 文件 / 6,699 用例）。
- 真实 Obsidian E2E 42 条通过：Electron 27 条 + full-journey / mode-journey / button-states / view-lifecycle / lifecycle / review-fixes 15 条。
- 构建产物体积：main.js 4,861,602B、styles.css 548,391B；CSS/bundle/JSDoc/引擎基线按实际变化登记。

## 影响与迁移

- 用户可见行为：协同顶栏更简洁；Agent 开场按真实项目状态生成；输入框更宽且支持图片附件；检查更新在 API 限流时仍可用；API 与设置页更短。
- 数据/配置迁移：无。旧 Agent 会话若与当前项目不一致会被忽略（不会删除磁盘存档）。
- 图片仅以路径引用发送给模型；视觉模型的多模态请求留待后续版本。
