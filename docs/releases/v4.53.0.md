# v4.53.0 — 出版检查、Agent 阶段面板与 any 收口

发布日期：2026-11-06

## 为什么发这一版

本版把三条并行线合并发布：①商业化出版检查与导出严格模式；②Agent 工作台「创作阶段」面板（统一 creation-flow 快照，不复制阶段常量）；③两批技术债收口（engine 与 smart-chart 的 any 全部清零），并补上自动化配置一致性门禁。

## 主要变化

### 1. 出版检查与导出严格模式

- 新增 `shared/publication-profile.ts`（纯函数）：判定出版阻断/建议分级——缺作者、空正文、严重字数不足、重复标题等；规格复用 `CREATION_MODE_SPECS`，不产生第二套口径。
- 导出弹窗新增「**严格出版检查（阻断导出）**」开关：默认仅提示；勾选后阻断项中止导出并给出可读原因（job 标失败并展示原因）。
- 新增 `docs/guides/USER-GUIDE.md` / `COMMERCIAL-GUIDE.md`。

### 2. Agent 工作台「创作阶段」面板

- 新增 `ui/agent-workbench/stage-panel.ts`：由统一 `CreationFlowSnapshot` 构建左栏阶段模型，**不复制阶段常量**。
- `agent-port` 采集 flow 快照并挂到项目状态（失败降级不影响基础进度）；工作台随活动项目刷新阶段面板。

### 3. 自动化一致性门禁

- 新增 `scripts/check-automation.mjs` 并接入 preflight：校验 HANDOFF 快照行数、版本一致性、信箱可解析——防「双份自动化台账」漂移。
- 新增 `docs/handbook/13-dual-automation-ops.md` 记录双工具自动化契约与排障。

### 4. any 收口（两批）

| 文件 | any | 做法 |
|---|---|---|
| `engine/deconstruction-scheduler.ts` | 22 → **0** | AnalysisResult 联合、8 个维度方法具体返回类型、`analyzeWithSegments<AnalysisResult>` 显式泛型、structure stats 精确断言 |
| `ui/components/smart-chart.ts` | 16 → **0** | ChartData（13 形态）联合 + ChartRenderOptions + `chartRenderer` 单点泛型适配 |

- 全仓 any **298 → 260**，`.any-baseline.json` 两轮收紧（276→260）。

### 5. 覆盖率与稳定性

- `chapter-state-manager` 失效标脏链补测 7 例（定向 br 72.86%→87.14%）。
- 修复 `engine-registry` listEngines 微基准的**负载敏感假失败**（预热 + 3 次取最小值 <5ms，保留防 O(n²) 原意）。
