# v4.74.0 — 「转为指纹」死读取修复

发布日期：2026-11-08

## 为什么发这一版

第 106 轮类型收口暴露了一个真实行为 bug：知识库详情弹窗的「转为指纹」按钮读取 `plugin.settings.activeProject`——该字段在 `NovelWriterSettings` 上**不存在**（恒 undefined），导致该功能必然提示「请先打开一个项目」，从未可用。本版修复它。

## 主要变化

### 1. knowledge-detail-modal「转为指纹」死读取修复（行为修复）

- **根因**：读取 `plugin.settings.activeProject`，但 `NovelWriterSettings` 无此字段（真实访问器是 `main.ts:691` 的 `getActiveProject()`，活动文件 → 工作台上下文回退）。
- **修复**：改为 `plugin?.getActiveProject()`——与插件其余代码使用的唯一真源一致。bundle −5B。
- 第 106 轮类型收口时按外科手术原则保留了原语义（未改行为），本轮补行为修复。

### 2. knowledge 模态 any 3→0

- `knowledge-detail-modal`：`getPlugin()` → `NovelWriterPlugin`、`ensureScheduler` 断言；
- `knowledge-rebuild-action`：`plugin: unknown` 以 `KnowledgeVectorStore` 形状断言；
- any 基线 136→133（74 文件）。

### 3. 文档

- `v5-acceptance` 过期证据纠偏：证据哈希先 `git hash-object` 实测（host-tools `265b99721ec6`、package.json `da18733c008b`），§四 round 104 / §六 ahead 链补全。
- `COMMERCIAL-GUIDE` §4 剧本流程纠正（分镜表是分集写作的强制前置）；§5 投稿检查表补「剧本：每集分镜表已完成」。
