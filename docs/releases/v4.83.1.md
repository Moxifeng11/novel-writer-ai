# v4.83.1 — 三条链路自证 + 静默失效修复 + agent 自愈第一步

发布日期：2026-11-12 · tag：`4.83.1`（无 `v` 前缀，Obsidian 社区目录规则）· 上一版本 v4.83.0

## 为什么发这一版

v4.83.0 把「可验证」定为长期方向，本版是它的第一笔兑现：**把「用户以为生效」的三条数据链路（知识 / 风格 / 约束）变成可自证的端到端事实**，并修掉审计确认的 5 个静默失效缺陷——这类缺陷的特征是「代码执行成功、用户以为生效的没生效」，任何一条门禁都查不到。

版本性质：无破坏性变更；新增 2 道门禁（覆盖率棘轮、空扫描拦截）与 1 个 agent 自愈工具（带审批）。

## 主要变化

### 1. 三条链路自证（阶段 A）

- 新增三条数据流**端到端测试**（知识 5 / 风格 7 / 约束 6 用例）与三个界面的**链路状态区块**（24 例）：链路断在哪一环直接可见，不再靠「看起来有内容」猜。
- `diagnose_flow` 自诊断工具：agent 能回答「我配了/拆解了，为什么写作时没用上」。判定与界面共用 `shared/link-status-compute` 同一口径——**界面看到的断点与 agent 诊断出的断点永远一致**，不会各说各话。
- 发版前追加：`scripts/verify-three-flows.mjs` 运行层验证脚本（读真实磁盘数据 + 探测本机 Ollama，退出码 0/1/2），报告见 `docs/audits/three-flows-runtime-verification.md`。真实 vault 验证发现 1 个 P2：**知识库索引 0 本但向量库仍有 1 本孤儿向量**——界面会显示「检索已加载 1 本」的假绿，待单独治理。

### 2. 静默失效修复（5 项）

| 缺陷 | 修复 |
|---|---|
| 拆解向量进不了 RAG | injector 要求参考书非空 + `bookIds: []` 被当成「一个都不要」；改为空 = 不限制范围 |
| 向量化静默成功 | samples 为空时只 log 后 return，调用方却标记 done；改为抛错如实标 failed |
| 嵌入不可用时检索整体失败 | 默认本地 Ollama 未装即抛错；新增关键词兜底检索 |
| 指纹消费链路首跑恒空 | `StyleFingerprintLibrary` 读取前自愈 `reloadIfChanged` |
| 同人设定审核闸门被向导绕过 | 未审核设定不再直接写入正式目录 / 绑定 |

### 3. agent 自愈（阶段 E 第一步，发版前追加）

新增 `repair_flow` 工具（`engine/agent/harness/repair-tools.ts`），agent 不只说「断在哪」，还能就地修：

- 两种修复：`revectorize_book`（单本重算向量，不重拆解、不调生成模型）、`reload_fingerprints`（按磁盘重载三层指纹）。
- 安全契约：`sideEffect: 'write'`；审批 **fail-closed**——无审批回调一律拒绝（连回合层已批准也不放行）；修复失败 / 抛异常 / 结果不可解析一律 `ok:false` 带原因，绝不静默成功；成功后用同一套采集器**复诊**并把修复后的链路状态一并返回。
- 审批优先走引擎 `requestApproval`，其次宿主 `confirmDangerousAction` 弹窗。UI 侧接线（传入真实修复能力）留待下一版。

### 4. UI 可测性（发版前追加）

- `ui/views` 行覆盖 **8.14% → 12.95%**（整体 ui 15.22%）：抽出 4 个纯逻辑模块（book-detail-logic / kb-view-logic / fingerprint-detail-logic / kb-config-import-logic，均 <200 行、不碰 DOM）。
- 5 个既有 DOM 构建器补假 DOM 单测（kb-book-card / kb-stats-panel / link-status / capability-banner / fingerprint-v2-detail），夹具 `tests/unit/ui/support/fake-dom.ts` 不引 jsdom。

### 5. 门禁加固

- 新增 `check:coverage` **覆盖率棘轮**：count-weighted 聚合、首期基线（ui 14.71% / ui/views 8.14%）、gitHead provenance（祖先提交同源豁免）、下调双确认；接入 `preflight:release`。只升不降——本版发版时基线已随实测上调至 ui 15.22% / ui/views 12.95%。
- `check:view-tests` 假阳性修复（断言字符串曾被当成 import）。
- `check:obsidian-api` **空扫描假通过**修复：扫描 0 个文件默认失败，`--allow-empty` 显式豁免。
- `check:program` 改为校验真实基线与版本一致性。

### 6. 协作机制

- 信箱升级三元身份（zcode / trae / dsh）；新增文件系统任务板（原子领取 + 写范围租约 + 租约超时），替代 30 分钟轮询的延迟与抢单。
