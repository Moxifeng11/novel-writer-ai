# v4.31.0 — 注入全链路、用量归因与备份对比（M4 第二批）

发布日期：2026-11-05

## 为什么发这一版

M4 第一批把资产、账本、备份中心立了起来，但留了四个口子：模式文档生成没吃注入、账本不知道“这次调用是谁发起的”、备份中心只能盲回滚、知识库视图仍是 3,732 行大文件。本版由四个实现子代理并行收口，主流程只做 scope 基础设施与统一回归。

## 主要变化

### 1. 模式文档生成接入注入

- `ModeDocumentGenerateOptions` 新增 `injectionDeps`；`generateModeDocument` 内部用 `collectModeInjection` 检索知识库 + 指纹（查询取编辑区现有内容 → 前期调研 → 大纲，截断 1200 字）。
- 提示词在【文笔风格】后追加【文笔指纹】与「参考知识」（后者由 `formatRetrievalHits` 自带表头，不重复包裹）；注入失败降级为空串，不阻塞生成。

### 2. 用量账本全链路归因

- 新增 `UsageScope`（source/project/stepKey）与 `pushUsageScope()/currentUsageScope()`（Obsidian 单线程，栈式嵌套）。
- 三条 AI 调用链挂接：
  - 步骤：`executeCurrentStep` 拆薄壳+执行体，按步骤挂 `source:'step'`，所有 return/异常路径保证退出；
  - 单元：`runAI` 按 `单元名#动作` 挂 `source:'unit'`；
  - Agent：`runHarnessTurn` 按回合挂 `source:'agent'`；模式文档生成挂 `source:'document'`。
- `AIApiClient` 三入口自动合并当前 scope；未挂 scope 的调用进「(未归因)」桶，作为归因覆盖率的一手观测指标。
- 账本 UI：新增「按项目」「按来源」汇总表；调用记录显示来源/项目/stepKey。

### 3. 备份中心：从盲回滚到可对比

- 版本条目新增「📜 历史」：打开现有 `ChapterVersionModal`（行级 diff、并排/内联视图、字符粒度），`onRollback`/`onSaveVersion` 完整接线到 `ChapterVersionService`。
- 回滚成功后刷新备份列表；「回滚」快捷按钮保留。

### 4. 大文件切片（续）

- `ui/views/knowledge-base-view.ts` 3732 → 3627：`createBookCard`（126 行）抽到 `ui/views/kb-book-card.ts`，宿主接口注入选中态/格式化/详情回调；DOM 结构与类名逐行等价。

### 5. M5 平台化评估（不实施）

- 新增 `docs/audits/m5-platform-assessment.md`：公共插件 API / MCP / 模板市场 / 云协作**均不实施**，明确各自的代价与风险，并给出 5 项量化重评条件（外部需求信号、契约稳定、安全基线、M4 收尾指标、专人维护）。
