# v4.82.0 — 安全加固 r3 收口 + 上下文/记忆/一致性三链落地

发布日期：2026-11-11

## 为什么发这一版

v4.81.1（2026-11-09）之后，仓库累积了 **175 个提交**却没有版本节点：安全审计维度③ 的 r3 八轮修复（S3-1 ~ S3-16）、上下文预算与抽取压缩、故事台账与关系记忆、人物一致性校验，以及多窗口/触屏/移动端一批稳定性修复，全部只存在于本地工作树。

后果是**「同版本号、两份不同代码」**：本地构建的 `main.js` 为 4,962,909 B，而 GitHub Release `4.81.1` 的资产是 4,862,268 B，相差约 98 KB。插件检查更新时因为「Release 最新也是 4.81.1」而正确显示「已是最新」，但用户装到的代码与仓库实际代码并不一致。本版把这段积压收口成一个正式版本节点。

同时修正发布规范脱节：`release.yml` 要求 Release tag 与 `manifest.version` **完全一致且不带 `v` 前缀**（Obsidian 社区目录规则），而本地积压了一批 `v` 前缀 tag 从未推送。本版按规范以 `4.82.0`（无前缀）打 tag。

## 主要变化

### 1. 上下文与记忆

- **上下文预算计划 + 抽取式压缩**：按步骤预算裁剪并显式报错，超限不再静默截断；压缩输入对工具轮次加围栏。
- **故事台账单源化**：章节引用、实体索引、属性标签底座；关系 5 维增量、待确认队列与章节摘要。
- **调用时关联查询**：接入步骤执行、协同写作与内容单元，检索结果带来源。

### 2. 质量与一致性

- **只读故事一致性校验**：结算后触发，纯读不改写正文。
- **人物一致性统一规则**：接入门禁与质量看板，避免多套判定口径并存。
- 同章摘要按章去重，索引读改写加锁（D2-2）。

### 4. 数据一致性（D3 系列）

上下文注入锁内重读（D3-4）、结算 settled 回写加锁与涉及人物重读、版本索引损坏归档与索引锁（D3-5/6）、内容指纹与 no-table 置 partial（D3-9）、统计台账原子写与改名迁移（D3-10/11）、迁移完成标记（D3-12）、协调器 onClose 屏障（D3-13）、Agent append/改名同步加锁（D3-14）、追加标记字段化与跨卷快照加锁（D3-15/16）、信息债看板统一写入器与写作规则覆写前备份（D3-17/18）。

### 5. 多窗口、触屏与生命周期

- 主题/字体/拖拽按宿主 `Document` 注入，popout 不再误查主窗口（M3-2）。
- 浮窗触屏拖动、390px 视口夹取、知识卡操作常显（M3-6）。
- 触屏上下排序与场景 drop off-by-one 修复（M3-3）。
- 卸载：`UnloadBarrier` + detach 后有界等待视图保存（L2-1）；`onOpen` 代次守卫与 KB `viewClosed` 复位（L3-1）。
- 移除 `app.plugins` 私有 API，改走构造注入与 `executeCommand`（M3-4/5），门禁补 `private-api` 规则。

### 6. 平台与体验

- 移动端 `requestUrl` 兜底传输（O-1）；热重载状态交接（O-3）；`.bak` 明文形态判定与文案（SEC-11）。
- 协同写作本地模式未选本地模型时自动切云端，并区分「已自动切换」提示（M-2）。
- 知识库/指纹库补能力边界说明；检索向量范数缓存；弹窗边界样式收口。

### 7. 协作基础设施

- `novel-mailbox` 升级为 **zcode / trae / dsh** 三元身份（服务端 v1.1.0），`to:"all"` 广播不变。
- `handoff.mjs` 新增 `--from dsh` / `--next-dsh`，快照新增「下一步（DSH）」字段。

### 8. 发布纪律

- **`git push` 放行**（2026-11-11 用户拍板）；`tag` / `Release` 仍需用户明确确认。同步 6 处现行规范（AGENTS.md ×2、PROJECT-RULES.md、PLAN.md、handbook 06/13、ROADMAP、v5-acceptance）。
- 历史 release notes（v4.48–v4.77）保持原样，不改写历史记录。
