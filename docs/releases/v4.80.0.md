# v4.80.0 — 社区目录样式合规重构

发布日期：2026-11-09

## 为什么发这一版

Obsidian 社区目录自动审核把两类样式写法判为 **Error**，v4.79.1/4.79.2 因此无法进入通过列表：

1. 运行时动态创建 `<style>` 元素（`obsidianmd/no-forbidden-style-element`）——本仓库初查 11 处；
2. 字面量内联样式（`obsidianmd/no-static-styles-assignment`）——初查 **558 处**，分布在 85 个文件。

本版只做样式承载方式迁移，**无功能新增、无数据迁移、无 API 变更**。

## 主要变化

### 1. 动态 `<style>` 清零（批次 A）

- 写作步骤弹窗（去 AI 味/精修/版本选择）、章节大纲树、场景大纲、黄金开篇、灵感、AI 规划、润色编辑器、全屏写作共 11 处注入迁入 `styles-src/20-runtime-modals.css`。
- 主题变量不再拼整段 CSS：优先 `documentElement.setCssProps`（Obsidian 1.5+），1.4.x 运行时探测后回退 `style.setProperty`；`dispose` 对称移除全部 `--nw-*`。
- 顺手修掉 ideation 末尾重复的 `.nw-btn-secondary/.nw-btn-danger`（此前打开弹窗后会全局串色），并把 plan-book 的通用类收在 `.novel-writer-plan-book-modal` 根类下。

### 2. 字面量内联样式 558 → 0（批次 B1–B4）

| 批次 | 范围 | 数量 |
|---|---|---|
| B1 | 步骤弹窗控制器 + 导出下载锚点 | 16 |
| B2 | progress-bar / step-list / task-card / loading-overlay | 37 |
| B3 | 30 个 Modal 重复的 margin / width / overflow | 111 |
| B3a | 角色/势力/物品/地点/世界观生成弹窗 | 55 |
| B3b | 实体向导 / 实体管理 / 扩写编辑器 | 132 |
| B4 | 55 个文件的零散样式（含指纹视图、知识库、模板、设置页） | 207 |

- 状态一律 `nw-is-*`（active/done/running/pending/selected/dragover/…），显隐统一 `nw-u-d-none`。
- 动态尺寸/坐标保留 `style.setProperty`，但值来自变量或模板插值（官方规则不判违规）。
- 新增样式文件：`20-runtime-modals`、`21-progress-components`、`22-modal-layout`、`23-generate-modals`、`24-unified-entity`、`25-outline-expand`、`26-cleanup-utilities`。

### 3. 门禁与文档约束（防止回流）

- `check:obsidian-api` 新增两条棘轮规则：
  - `style-element`：`createElement/createEl('style')` 即失败；
  - `static-style-assignment`：对齐官方 ESLint 的字面量判定——`el.style.x = 'v'` / `cssText` / `setProperty(字面量, 字面量)` / `setAttribute('style', …)` 失败；变量与含插值模板不误报。
- 新增「故意违规必须报错」自测（含动态值不误报断言）。
- `docs/handbook/06-gates-and-release.md` §3 写明允许/禁止写法、状态类约定与基线纪律；`docs/README.md` 真相源表、`docs/PLAN.md` 单一入口同步。

## 验证

- `preflight:release` EXIT=0（604 文件 / 6,652 用例，覆盖率门禁通过）。
- `check:obsidian-api`：`style-element 0`、`static-style-assignment 0`（累计 558 → 0），其余规则 0。
- `check:css`：体积 543,390B；硬编码 hex 161、rgb 188 **未增加**；`!important` 19 → 24（仅拖拽面板固定定位/尺寸 5 行，替代原 `setProperty(...,'important')`）。
- 全量测试每批均跑；B4 后 604/604 文件、6,652/6,652 用例通过。
- 真实 Obsidian E2E（mock AI）：full-journey 1 + button-states 4 + view-lifecycle 3 + lifecycle 2，共 10 条通过。

## 影响与迁移

- 用户可见行为不变；此前「打开某弹窗后才生效」的样式现在随插件加载常驻，但选择器均带 `nw-`/`novel-writer-` 作用域。
- 配置/数据迁移：无。
- 若使用自定义 CSS 片段覆盖插件内联样式，需改为覆盖对应的 `nw-*` 类（内联样式已不存在）。

## 已知边界

- 拖拽面板的 `position/z-index/resize` 仍使用 `!important`（5 行）：该浮窗需要压过 Obsidian 工作区布局，属必要例外，已在 `check:css` note 登记。
- `attr: { style: … }` 不是社区目录规则命中项，但本版已同步清理主要弹窗；剩余历史用法不影响审核。
