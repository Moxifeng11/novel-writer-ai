# v4.92.0 — 拆解结构化：从「猜关键词」到「读字段」

发布日期：2026-11-13 · tag：`4.92.0` · 上一版本 v4.91.0

## 为什么发这一版

v4.91.0 的规则层靠**关键词匹配**判断谓词。这在真实长篇上暴露了两种 bug：

- **严格等值** `=== '年龄'` → LLM 给「年龄约」「年纪」时整类漏报
- **包含匹配** `includes('年龄')` → 「被提亲起始年龄」这类回溯叙述被当当前状态，产生假矛盾

修一个引入另一个，是死循环。这一版从**拆解产物**下手，让规则层不再猜。

## 核心改动：拆解产物结构化

| 字段 | 作用 |
|---|---|
| `predicate` **规范枚举** | 年龄 / 位置 / 持有 / 能力 / 关系 / 时间 / 规则 / 认知 / 记忆 |
| `isCurrentState` | 当前状态 `true`；回溯/回忆（「我那年才四岁」）`false` |
| `event` **事件锚** | 这条事实属于哪个事件（「渭城春雨」「宁缺入楼」） |

解析侧**强制归一化**：模型给自由谓词也映射到枚举值。

## 规则层：统一匹配器 + 按事件分组

```ts
matchesPredicate(predicate, 'age')   // 唯一入口
```

- **前缀锚定**（不是包含）：「年龄约」✅ /「被提亲起始年龄」❌
- **别名表**：每概念列全变体
- **回溯限定词排除**：起始/当年/曾/之前/旧称/少时…
- **R5 改为按 `event` 分组**：修复同一主体的不同事件被判时长矛盾

## 三个真实案例（都已核对原文）

| 案例 | 原文 | 修复前 | 修复后 |
|---|---|---|---|
| 桑桑 11岁→8岁 | 「桑桑**才八岁的时候**你就开始提亲」 | 假矛盾 | 排除（回溯） |
| 宁缺 16岁→4岁 | 「我**那年才**四岁」 | 假矛盾 | `current=false` |
| 宁缺 入楼17日 vs 苦求10年 | 两个不同事件 | 假矛盾 | 按 event 分组不报 |

## 评测：三组同 100 章真实数据

| 组 | prompt | 事实数 | 真实误报 | 有效召回 | 成本 |
|---|---|---|---|---|---|
| A 旧 | 自由谓词 | 1576 | 0 | 7/7 | ¥1.03 |
| B 新 | 规范谓词 | 1656 | **427 → 21** | 9/10 | ¥1.11 |
| **C 新+event** | 结构化 | 1622 | **0** | **8/8 = 100%** | ¥1.25 |

**B 组 427 条误报的因果链**（本版最值钱的教训）：

```
规范谓词 → 时间类全归一为「时间」
        → R5 按 (主体,谓词) 分组
        → 同一主体的不同事件混在一起比
        → 427 条假矛盾
加 event 事件锚 → R5 按事件分组 → 0 条
```

> **规范化不是免费的**：把自由文本压成枚举会丢掉"天然区分度"，
> 必须补回被丢掉的维度，否则规则层失去分组依据。

## 升级说明

无破坏性变更。
- 旧事实库没有 `isCurrentState` / `event` 时，规则自动回退到引文启发式与按主体分组，行为与升级前一致
- 新拆解的事实才带新字段
- 项目标准校验只读，不修改用户文件
