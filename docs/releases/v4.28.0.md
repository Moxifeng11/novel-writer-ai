# v4.28.0 — 统一创作主页、任务中心与首启向导

发布日期：2026-11-04

## 为什么发这一版

v4.27 解决了“写不稳”和“门禁假绿”，但入口仍然是六个 Ribbon 图标、147 条命令，新用户不知道从哪开始；长任务（批量、一键跑章、导出、拆解）各自维护进度与取消，关掉弹窗就看不到，失败也无法统一重试。

这一版把入口和长任务收成两个明确概念：**创作主页**负责“从哪开始”，**任务中心**负责“正在跑什么、卡在哪、能不能重试”。

## 主要变化

### 1. 创作主页

- 三个模式卡片：长篇/短篇/剧本，显示项目数与单元类型（章/节/集）。
- 最近项目：按当前项目优先 + 名称排序，点击直接进入创作流程。
- 下一步建议：未配置 Key → 去设置；无项目 → 导入示例/新建；有项目 → 继续创作或交给 Agent。
- 主 Ribbon 收敛为：创作主页、任务中心、Agent、项目速览。其余入口保留命令深链。

### 2. 任务中心与 JobService

- `services/job-service.ts` 统一任务状态机、进度、取消、重试、订阅与 `waitFor`。
- 任务中心显示进行中/已完成/失败/取消，支持取消与重试；失败保留错误原因与结果现场。
- 已接入：
  - 批量生成章节：原 `AbortSignal` 直接复用，进度映射到任务；
  - 章节一键完成：取消同步到 `ChapterOrchestrator`；
  - 成稿导出：收集/编译/写入阶段检查取消；
  - 批量拆解：每个文件一个任务，取消透传到拆解 controller。
- 关闭弹窗会取消当前任务（与旧行为一致），但任务中心保留记录并可重试；任务状态不写用户 vault。

### 3. 首启向导

- 5 步：选择提供商 → 填写 Key → 连通性测试 → 导入示例项目 → 进入主页/流程/工作台。
- 新装欢迎弹窗主按钮改为「3 分钟开始」；保留「直接进入工作台」。
- Key 保存走现有 `providerKeys` + `saveSettings` 加密策略；连通性测试复用 `testProviderConnectivity`。
- 完成或跳过写入 `firstRunComplete`。

### 4. 项目体检

- 四类问题：重复正文、未结算、frontmatter 未闭合/重复键、正文目录孤儿文件。
- 只报告不自动修改；每条可跳转文件，支持重新体检。
- 新增 `ui/components/error-state.ts`，体检失败等场景统一为“原因 + 修复动作”。

## 验证

- `preflight:release`：通过（提交前执行）。
- 单测：**539 文件 / 5,925 用例**（最终数字以 `preflight` 输出为准）。
- mock AI E2E：全旅程/按钮/视图/生命周期（提交前执行）。
- CSS：新增主页/任务中心/向导/体检样式，基线 +7,046B，已按门禁流程更新 note。

## 影响与迁移

- 破坏性变更：主 Ribbon 不再直接提供项目/流程/协同/知识库/指纹库入口；这些命令仍在命令面板。
- 配置/数据迁移：无；`firstRunComplete` 仅新增写入，旧配置不受影响。
- 回滚建议：回滚到 v4.27.1 后，任务中心记录（内存）消失；不影响 vault 数据。

- 任务记录不跨 Obsidian 重启持久化（M4 版本/备份中心再评估）。
