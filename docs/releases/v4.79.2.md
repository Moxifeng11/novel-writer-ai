# v4.79.2 — 社区目录建议项清理

发布日期：2026-11-09

## 为什么发这一版

v4.79.1 通过后，Obsidian 社区目录的自动审核还给出若干**非阻断建议**（CSS `!important`/`:has`/滚动条、Release 额外文件、构建来源证明）。本版逐项清理，**无功能变更、无迁移**。

## 主要变化

### 1. CSS 建议项（styles.css 476,809 → 472,781，−4,028B）

- **`!important` 183 → 0**：全部规则都以 `.nw-` / `.novel-writer-` 类作用域，类选择器本身足以覆盖默认样式；删除后由插件自有的类优先级决定。
- **`:has(input:checked)` → `nw-is-active` 状态类**：4 处开关（设置页 2 + 提供商弹窗 2）在初始化与 change 时同步类名，避免 `:has` 的广域失效与性能告警。
- **`::-webkit-scrollbar` → 标准 `scrollbar-width` / `scrollbar-color`**：协同面板、审核面板、Tab 栏统一；旧版 Obsidian 回退为系统默认滚动条（内容仍可滚动）。
- 删除重复 `background`/`border` 声明与未被使用的 `webview` 类型选择器。

### 2. Release 资产

- worker 文件不再作为独立资产上传（审核提示「额外不支持的文件」），仅打入 `novel-writer-ai-<version>.zip`；Obsidian 本就不下载额外资产，手动安装解压 zip 仍包含 worker。
- `SHA256SUMS.txt` 调整为实际上传资产清单；`check:release` 增加「worker 不得出现在 ASSETS」的校验。

### 3. 构建来源证明

- 发布流水线新增 `actions/attest-build-provenance@v2`（SHA 锚定），为 `main.js` / `styles.css` 生成 artifact attestations；workflow 权限补 `id-token: write`、`attestations: write`。

## 验证

- `preflight:release` EXIT=0（603 文件 / 6,647 用例）。
- `check:css`：`!important 0`、体积 472,781（基线同步收紧）。
- `check:release`：资产一致（worker 仅入 zip）。
- 视觉回归：CSS 改动均为插件类作用域内的等价覆盖；设置页/协同面板/审核面板开关与滚动条需实机抽查。

## 影响与迁移

- 行为变更：无（热重载与开关交互不变）。
- 数据迁移：无。
- 回滚建议：revert 本版会恢复 `!important`（不建议，审核建议项会复现）。
