# 小说工坊 AI v4.12.0

> 发布日期：2026-10-25 · 上一版本：[v4.11.0](v4.11.0.md)
> 主题：2026-10 缺陷与不合理设计审计全量落地（Phase 1–4 + Rev 153–192）

本次发布不引入新的创作能力，重点是把「同一份数据在多个入口/多层缓存里各有口径、失败又被静默降级」的系统性风险收口，并把审计过程固化为可重复执行的工程门。

---

## 一、本版主线

### 1. 数据安全与状态一致性

- 正文写盘统一经 `BodyWriter` 并加跨写入者锁；切章先取快照，消除「旧文本写进新章」的窗口。
- 知识向量按 `bookId` 判定书籍是否仍存活；书籍改名时同步重写向量与索引，重启后不再检索「幽灵书」。
- 同一本书的拆解任务串行化，向量与索引写入改为「临时文件 + rename」，中断不会留下半写 JSON。
- 批量建章支持真正取消；被 abort 的结果不再被当成成功保存。
- 规划步骤变更后，正文、质量、分析、结算会正确标记为失效，不再出现「改了细纲但旧正文仍算完成」。
- `ObsidianFileSystem` 对 `.obsidian` 插件数据目录增加 adapter 回退，索引外 IO 不再静默失效。

### 2. 检索与注入口径

- embedding 增加模型指纹与维度校验，切换 provider 后不一致可见；缓存签名纳入模型，切模型无需重启。
- 合并检索改为按维度阈值过滤，低分维度不再整段消失；节奏检索不再按位置排序。
- 指纹注入上限在协同写作与 11 步正文生成中统一；强度 0 真正禁用样本片段。
- 知识注入统一走预算闸门，「必须层」固定在最终 prompt 中；「已注入 N 条」按预算裁剪后的实际保留数计数。
- V2 指纹向量在「重向量化」时同步重建，不再永久回退全量。

### 3. 质量评分与监控

- 明确单一评分内核：注入 `v1Engine` 后不再叠加失效的分析器与校准系数；看板与协同使用同一六维口径。
- 质量基线按「章」聚合（同章多次评估只取最后一次），并排除当前章自身，避免「和自己比」。
- 偏离检测缓存纳入大纲、人物、前文等上下文指纹，规划就绪后不会继续复用空大纲结论。
- 协同实时质量与仪表盘共用同一次评估结果并写入同一份历史，基线不再长期缺样本。

### 4. 工程门与可维护性

- 新增 `npm run preflight`：typecheck → test → 模板一致性 → 依赖分层 → 引擎实例化，接入 CI 与发布流水线。
- 架构守卫以 `.arch-baseline.json` 做棘轮，只允许违规数量减少，新增即失败。
- `step-runner` 拆分顺序执行、重试、特例、结算与 prompt 装配；命令注册表改为 UI 端口注入，core 不再依赖 ui。
- 设置对象改为深合并并在 `schemaVersion` 不符时自动回写，升级用户不再丢嵌套字段。
- 项目身份显式传递，润色与无参打开协同时不再跨书绑定。

### 5. 流程与体验

- 章节流程与信息流重构：阶段导航完成性按结构校验，上下文输入清单可见，规划成果真正进入正文。
- 快捷工具三层对齐，全章节选择器支持排序、分卷、搜索与状态图例；新增时间线/伏笔关联索引。
- 实体与设定模块统一统计口径（`shared/entity-stats.ts`），AI 生成器、实体仪表盘与章节选择器补齐样式与响应式。
- 新增「成稿导出」：按卷/章顺序编译为 Markdown、纯文本或可打印 HTML。

## 四、升级说明

1. **直接覆盖安装即可**：`manifest.json` 最低版本仍为 Obsidian 1.5.0，旧项目目录与旧版设置键名保持兼容。
2. **模板不会被覆盖**：`元文件/` 只补缺失文件；本版新增的 Scene 展开、情绪规划、角色灵魂、质量控制与文笔风格预设，会在首次启用或新建项目时补齐。
3. **发布包内容**：`main.js`、`manifest.json`、`styles.css` 与 `workers/`。若手动安装，请把 3 个 Worker 放入 `workers/` 子目录，否则重任务会降级到主线程。
4. **质量历史**：旧记录中缺失维度以 0 占位，不参与基线与维度结论；样本不足 3 章时不会给出「偏离基线」判断。
5. **密钥口令**：行为不变。口令仅存内存，丢失后需重置并重新填写密钥。
