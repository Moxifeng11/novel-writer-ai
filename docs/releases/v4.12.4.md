# 小说工坊 AI v4.12.4

> 发布日期：2026-10-26 · 上一版本：[v4.12.3](v4.12.3.md)
> 主题：CSS 预算基线跨平台归一化

本版只修工具链口径，不改变插件运行行为与 `styles.css` 内容。

---

## 一、修复

`scripts/check-css.js` 原先按工作树文件字节记录基线：

- Windows checkout 为 CRLF：349,451 B
- Linux / GitHub Actions checkout 为 LF：338,203 B

这会导致在 Windows 上完成 CSS 迁移并更新基线后，CI 按 LF 口径判定超限。现在读取 `styles.css` 后统一 `CRLF → LF`，基线重置为 **338,203 B**；`!important`、硬编码颜色、唯一类等指标不变。
