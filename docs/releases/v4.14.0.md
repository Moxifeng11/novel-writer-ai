# 小说工坊 AI v4.14.0

> 发布日期：2026-10-26 · 上一版本：[v4.13.0](v4.13.0.md)
> 主题：协同写作 Markdown 编辑器 — 工具条 / 段落工具 / 一键小说排版

本版把协同写作中间的裸文本域升级为 Markdown 文档编辑器，并让它直接消费项目「写作规则.md」的正文格式契约。

---

## 一、Markdown 编辑器

编辑区顶部新增工具条，底部新增状态栏：

- **Markdown**：加粗（`Ctrl+B`）、斜体（`Ctrl+I`）、二级标题（`Ctrl+Alt+2`）、引用（`Ctrl+Alt+Q`）、无序列表（`Ctrl+Alt+L`）、分隔线、行内代码（``Ctrl+` ``）。
- **段落工具**：首行缩进/取消（`Ctrl+Alt+I`）、增加/减少段落缩进（`Ctrl+]` / `Ctrl+[`）、合并选中段落、在光标处拆分段落、选中文本转中文引号。
- **状态栏**：显示 `Markdown`、当前格式契约、字数、段落数与快捷键提示。
- 原有 `Tab` 生成 AI 建议、`Ctrl+1/2/3` 接受建议、`Ctrl+S` 保存等快捷键保持不变。

## 二、一键小说排版

点击「⚡ 一键排版」或按 `Ctrl+Alt+F`：

1. 读取当前项目 `00-系统模板/写作规则.md`，推导分段方式（单换行 / 空行）与段首缩进（空两格 / Tab / 无）。
2. 保留 frontmatter 与首行 `# 第N章 标题`。
3. 剥离模型元叙述（「好的，我将…」等）与多余空行。
4. 按契约统一段首缩进与段落间距。
5. 结束时显示本次使用的契约；无写作规则时回退默认「单换行分段 · 首行空两格」。

文本变更优先通过 `execCommand('insertText')` 应用，保留原生撤销栈；失败时回退为直接赋值并触发 `input`，自动保存与实时预览链路不变。

## 四、升级说明

- **无破坏性变更**：编辑器仍是 Markdown 源码编辑，原有 AI 建议、自动保存、预览、质量监控链路不变。
- **格式契约**：项目有 `00-系统模板/写作规则.md` 时按规则排版；没有时使用默认契约。修改规则后重新打开章节即可生效。
- **Markdown 标题**：一键排版会保留首行章节标题，其他 Markdown 标题按正文标题剥离；正文仍以纯文本小说格式为主。
- **发布包**：`main.js`、`manifest.json`、`styles.css` 与 `workers/`。
