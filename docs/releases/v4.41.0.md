# v4.41.0 — 质量引擎作用域收敛、协同引擎第五批切片与 Notice 第五批

发布日期：2026-11-05

## 为什么发这一版

审计 P1-6「多实例状态源」在 v4.40.0 只完成了 `StyleIntensityEngine`；`WritingQualityEngine`（5 处直接 `new`）与 `PlotDivergenceEngine`（4 处）仍然分散构造，评分历史、告警冷却与章节上下文无法从代码上保证隔离。v4.38.0 的「未完成」清单里还压着 `buildEvaluationPrompt` 的参数化前置。本版三项并行推进。

## 主要变化

### 1. 有状态质量引擎构造收敛（P1-6 收口）

- 新增 `engine/quality/quality-engine-factory.ts`，提供两类入口：
  - `createWritingQualityEngine()` / `createPlotDivergenceEngine()`：每个视图/监控面板一份独立实例，评分历史互不串；
  - `getScopedWritingQualityEngine(scope)` / `getScopedPlotDivergenceEngine(scope)`：长期消费者按 scope 缓存（heavy-task 管理器、Worker 线程各自一份）。
- 5 个直接构造点全部替换：`heavy-task-worker-manager`（'heavy-task'）、`quality-worker`（'quality-worker'）、`co-writing-view`、`quality-dashboard-modal`、`monitor-panel-b`。
- 工厂内部只有 1 个构造点（scoped 走 create），引擎守卫 `PlotDivergenceEngine` 4 → **1**、`WritingQualityEngine` 5 → **1**，`engineOverLimit` 已清空。
- 新增 8 例测试：create 返回不同实例、scoped 同键复用/异键隔离、两类引擎缓存不串、reset 后重建。

### 2. 协同引擎第五批切片

- `engine/co-writer-engine.ts` 3,407 → **3,299**（-108）。
- `computePlotProgress` / `getCurrentPlotTarget` 抽到 `engine/co-writer/plot-progress.ts`：节点列表改为显式入参，30% 信号阈值、第一个未完成节点定位、收尾文案逐行保留。
- `buildEvaluationPrompt` 抽到 `engine/co-writer/evaluation-prompt.ts`：剧情节点、章节目标、伏笔库全部显式入参——这是 v4.38.0 记录的前置条件，完成后该方法可独立测试。
- 新增 10 例测试：节点完成阈值、空节点进度、目标提示三种分支、正文 1500 字窗口、大纲 500 字截断、伏笔 10/5 条上限。

### 3. Notice 第五批

- 5 个文件替换 **30 处**（成功 17 / 失败 8 / 告警 5）：供应商管理 7、批量导入 4、文笔蒸馏 6、世界观生成 5、全书规划 8。
- 守卫/进度/预检/带操作引导提示继续保留原 `Notice`；eslint 0 error / 1,870 warnings，无新增。
