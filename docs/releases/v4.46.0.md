# v4.46.0 — 指纹 V2 直存与 Notice 收敛收官

发布日期：2026-11-06

## 为什么发这一版

v4.45.0 把 V2 十二维特征接入了蒸馏报告；本版打通最后一环——**蒸馏出的十二维统计可以一步入库为结构化 V2 指纹**，不再依赖"先存 V1、等迁移"。同时 Notice 存量经逐条核对确认收敛终点。

## 主要变化

### 1. 指纹 V2 直存（`addV2Fingerprint`）

- `StyleFingerprintLibrary` 新增 `addV2Fingerprint({ scope, name, source, tags?, samples?, sourceText?, analysis })`：
  - 磁盘直接写 `version:'v2'` 全量 12 维（含逐维 description/samples/status），不再"先 V1 落盘、等迁移"；
  - 合成 `v1Backup`（投影 + 时间戳），V1 消费方加载即还原 7 维视图，与 `saveBlendedFingerprint` 的合成方式一致；
  - `stats` 由分析结果推导（`avgSentenceLength`/`avgParagraphLength`/`dialogueRatio`/`descriptionRatio`/`wordCount`）；
  - 入库同时直建 **V2 逐维向量**（`StyleVectorStoreV2.addOrUpdateVectors`），新指纹即时可被 `searchSimilarStylesV2` 命中，无需整体重建；embedding 降级不影响入库；
  - project 作用域无项目时抛错拒绝，**不做半写**（V2 缓存与 V1 表均无残留）。
- 提取视图（`writing-fingerprint-view`）：「从文本提取」完成后走 `saveExtractedFingerprintWithLocalV2`——本地十二维统计成功即 V2 直存（成功提示"指纹提取成功（含 12 维结构化特征）"）；统计或落库失败回落既有 V1 通道，**两处降级都有可见提示**（`check:silent-failures` 门禁抓一轮后补齐）。
- 新增 `tests/unit/engine/style/fingerprint-v2-create.test.ts` 3 条：
  1. 创建后立即具备 V2 条目（12 维）+ V1 投影一致 + V2 向量可检索；
  2. 重载后形态不降级（磁盘文件即 `version:'v2'`）；
  3. project 无项目拒绝且不留半写。
