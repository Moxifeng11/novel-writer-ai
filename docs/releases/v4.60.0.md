# v4.60.0 — 四文件 any 清零与剧本阶段面板回归

发布日期：2026-11-07

## 为什么发这一版

v4.59.0 之后连续四个纯类型批次（第 40–43 轮），把 UI 与 services 层剩余的 any 高点逐个清零，any 基线从 251 收紧到 222。同时补上剧本阶段面板四态的真实回归。**无运行时行为变更**：`main.js` 与 v4.59.0 逐字节一致。

## 主要变化

### 1. `ui/views/knowledge-base-modals.ts` any 9→0

- 导入回调与构造函数参数 `(book: any)` → `BookBasicInfo`。
- `vault.adapter as any` → 本地窄接口 `MkdirCapableAdapter`（`mkdir`/`write`），保留桌面端 mkdir 与移动端回退。
- `channelValue: string` → `GenreChannelKey | ''`（复用 `BookBasicInfo['genreChannel']`），4 处 `as any` 自然消失。
- 批量操作数组显式字面量 key 类型，删除 `op.key as any`；`attr.disabled` 的 `null as any` 删除（`DomElementInfo.attr` 本就允许 `null`）。

### 2. `ui/manage-providers-modal.ts` any 7→0

- 新增只读投影 `ProviderSummary` 替代 `getAllProviders(): any[]`。
- `settings: NovelWriterSettings`、`updateProvider(id, updates: Partial<CustomProvider>)`、`getRawProvider(): CustomProvider | undefined`。

### 3. `ui/golden-opening-modal.ts` any 6→0

- 6 处 AI 返回 JSON 的解析回调改用既有类型：`Partial<ChapterOutline>`、`unknown` 类型谓词、`Partial<HookResult['hooks'][number]>` 等。
- `Math.max` 夹取、`Array.isArray` 与默认值兜底一律未改。

### 4. `services/worker-manager.ts` any 7→0

- `TaskState<P = unknown, R = unknown>`、`executeTask<P = unknown, R = unknown>`、`reject(reason: unknown)`、`resolveTask(result: unknown)`、`rejectTask(error: unknown)`。
- 调用点零扩散：`deconstruction-worker-manager` 显式传泛型不受影响，`heavy-task-worker-manager` 既有 `as CancelablePromise<T>` 仍成立，`engine/**` 未改动。

### 5. 剧本阶段面板四态回归（+4 用例）

- 冷启动阻塞链、分镜表完成但无骨架（提示「创建 12 集骨架」）、12/12 完成 85%、旧剧本无分镜表跳过前置。
