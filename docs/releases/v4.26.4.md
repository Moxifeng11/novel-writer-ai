# v4.26.4 发布说明

> 2026-11-04 · 模板流转单一入口与正文路径统一

## 模板流转

- 新增 `engine/prompt-resolver.ts#resolveStepPrompt`，优先级固定：**vault 自定义 > 用户覆盖 > 内置**。
- 返回 `source / templateId / templateVersion / templateHash / unresolved`，供步骤归因与排障。
- 统一渲染 `${var}` 与 `{{var}}`；未解析变量显式提示，不再静默发给模型。
- 接入范围：交互单步、批量流水线、继续生成、合并规划（检测到自定义自动改分步）、情绪规划、Scene 展开。
- 步骤结果写入实际模板 id/version/hash（正文不再固定 V1）与规则版本/hash；新增 `step_template_hash`。
- `TemplateService` 缺模板兜底使用构建期 assets + 骨架 frontmatter；清空模板保存会删除覆盖文件，导入 0 片段不再提示成功。

## 正文路径与规则

- 新增 `resolveBodyFilePath()`：先命中已存在的标题化正文，再回退裸路径。
- 协同视图/浮窗、结算、审查、导出、续写、批量续跑全部接入；导出不再漏标题化章节。
- `BodyWriter` 格式契约改读 vault 唯一写作规则；上下文差异检测同步监听 vault 规则路径。
- `RulesService` 支持显式 project，模式附录缓存不再串项目。
- `onunload` 清理 PromptCache 与 RulesService 单例。

## 验证

- 全量单测：**534 文件 / 5910 用例**。
- 新增回归：模板 resolver 优先级/半段覆盖/正文变体元数据、模板执行器单源约束、标题化章节目标。

## 已知边界

- `services/prompt-templates-default.ts` 仍保存 PromptManager 的历史默认副本；它只在用户主动创建 custom 副本时生效，主流程已由 resolver 接管，后续可迁移到同源常量。
- 实体/世界观生成器的自定义提示词仍由 `TemplateService.getCustomPrompt` 读取（同一 vault 目录），尚未接入变量渲染；已在模板生命周期文档登记。
