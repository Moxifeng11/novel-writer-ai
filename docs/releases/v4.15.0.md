# v4.15.0 — AI 参数路由、截断状态机与本地 Ollama 链路

发布日期：2026-10-26

## 为什么发这一版

这一版不处理向导，集中修复“长文生成被截断、半成品被当成完成、步骤信息不往下游走”的链路问题，并把 AI 参数设置、URL 供应商识别和本地 Ollama 接入补齐。

## 主要变化

### 1. 任务级模型与预算
- 规划/正文/分析/质量分别解析模型与输出上限，不再让全局 `maxOutput` 被最后选择的模型覆盖。
- 优先级：用户覆盖 → 本地探测 → 自定义供应商显式上限 → 静态能力表。
- 输出上限不会超过模型能力；过大的全局值会被按模型收窄。

### 2. 截断不再算完成
- `finishReason=length` 强制标记 `partial`，不进入 `stepCompleted`。
- 步骤文件写入 `step_truncated`、`step_finish_reason`、`step_model`、`step_usage`。
- 正文截断且已有完整稿时，保留原正文，把截断内容写到 `_截断草稿.md`。
- 批量流水线遇到截断/半成品直接失败并停止结算，不再基于半章继续。

### 3. 步骤信息流
- “继续生成剩余”改用真实模板 prompt，不再空 prompt 空跑。
- 合并规划重新生成后会失效正文/质量/分析/结算。
- 批量续跑按 v4 `pjBodyFile` 读取正文。
- 分析报告剥离完整 frontmatter，记录真实执行模型。
- 角色灵魂步骤结果优先于 context 旧快照，手动编辑可进入下游。

### 4. 设置与供应商识别
- 保留原有 API 设置窗口，新增任务级参数表：模型 / 最大输入 / 最大输出 / 思考模式 / 思考预算。
- 新增 URL 自动识别：火山、DeepSeek、SenseNova、CatCat、OpenAI、DashScope、Gemini、OpenRouter、SiliconFlow、Moonshot、Groq，以及 localhost/私有网段/Ollama 原生端点。
- 识别结果可一键应用，也可开启“手动指定”只提示不覆盖。
- 思考参数按供应商协议下发：Ollama `think`、OpenAI o 系列 `reasoning_effort`、火山/DeepSeek/SenseNova `thinking`；未知供应商不下发。

### 5. Ollama 本地链路
- 协同写作按模型所属本地 provider 路由；找不到本地 provider 时明确报错，绝不静默回退云端。
- `num_ctx` 按模型窗口/用户配置，不再固定 32768。
- 共享 `EmbeddingService` 自动注入指纹库、知识库、协同写作和指纹转换器，修复 V2 指纹检索为空。
- embedding 回退默认 `local-only`：只允许回退到本地 Ollama，禁止静默把本地文本发到云端。
- Ollama embedding 输入按 6000 字符截断，避免本地模型静默截尾。
- 向量任务/LLM 增强在 Worker 不可用时切主线程，避免“深度模式”静默丢失增强。
- 拆解 LLM、分析报告、指纹提取支持本地端点与任务预算。

## 验证

- `typecheck` / `lint` / `test` / `preflight` / `build` 全绿。
- 344 个测试文件、4314 个用例通过。
- 新增任务预算、截断保护、继续生成、批量续跑、分析报告模型、URL 识别、思考参数、embedding 回退、协同本地路由等回归测试。

## 兼容性说明

- 全局 `maxContext/maxOutput` 仍保留为旧版兼容默认值，但生成链路已改为任务级解析。
- 已有 Ollama/local provider 配置可直接使用；如果本地模式找不到对应 provider，会明确报错而不是偷偷走云端。
- 向量模型切换后，旧的向量索引可能因模型/维度不一致被跳过；建议在知识库中执行一次“重向量化”。
