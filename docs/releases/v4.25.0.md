# v4.25.0 — 生产环境兼容性与空闲功耗修复

发布日期：2026-11-02

## 为什么发这一版

v4.24 声明的最低 Obsidian 版本是 1.5.0，但代码里用了 1.5+ 才有的 API，且桌面宠物在空闲时持续重绘。这一版把“能装”变成“在声明的最低版本上真的能跑”，并把空闲 CPU 压到可接受范围。

## 主要变化

### 1. Obsidian 1.4 兼容

- 批量导入的文件/文件夹选择弹窗改用 `titleEl.setText()`，不再依赖 1.5+ 的 `Modal.setTitle()`。
- `manifest.minAppVersion` 下调到 1.4.0。
- `shared/file-system-port.ts` 不再调用晚于 1.5 的 `Vault.getAllFolders()`，改为沿 `TFolder.children` 递归。
- 用 `obsidian@1.4.0` / `1.5.7` 类型分别执行 `tsc --noEmit`，无 API 缺失。

### 2. 桌面宠物空闲功耗

- 移除 SVG 内层常驻的尾巴/眨眼/浮动动画，改为外层 `transform` 浮动（合成层）。
- 实测空闲主线程开销 10.22% → 0.21%–0.23%，JS 堆增量约 24–30 MB。
- 新增 `perf-smoke` 与生命周期 E2E（重复禁用/启用、移除插件目录后重启）。

### 3. 正文与结算修复

- 模拟流按段落切分保留 `\n\n`，拼接后不再段落粘连。
- `shared/frontmatter.ts` 新增 `setFrontmatterValue()` / `dedupeFrontmatterKeys()`；结算遇到重复 YAML 键自动去重后重试。
- 分析报告角色状态/时间线检测上限 5,000 → 12,000 字；字数判定改用写作配置的每章上下限。
- 强制揭示名字兼容 bullet/单行建议/显式行三种格式；纯提示行不再误报。
- 项目列表排除 `_versions` 等 `_`/`.` 前缀目录，要求存在项目标志。

### 4. 设置整理

- 写作配置按五组重排；写作规则版本下拉移到「写作规则」页。
- 实验分组标签移到「写作规则」；页签改名。

## 验证

- 单测 527 文件 / 5,885 用例通过。
- 真实 Electron E2E：27 条主旅程 + 2 条生命周期 + 1 条性能冒烟通过。
- 运行时依赖 0；开发依赖审计 39 条（Vitest/Vite 链，不随插件发布）。

## 影响与迁移

- 破坏性变更：无。
- 配置/数据迁移：`minAppVersion` 下调；旧项目无需迁移。
- 回滚建议：如遇 1.4 专属问题，回退到 v4.24.0 并保留 `data.json`。
