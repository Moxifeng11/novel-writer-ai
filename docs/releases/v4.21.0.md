# v4.21.0 — Obsidian 原生能力接入、RAG 检索管线与 Agent 会话运行时

发布日期：2026-10-31

## 为什么发这一版

v4.20.0 之后还有两轮大改动堆在 Unreleased：一轮把插件的数据面接入 Obsidian 原生能力（属性/标签/Bases/右侧速览），一轮补齐 RAG 工程与 Agent 会话运行时（dsh 吸收）。在此之前，知识注入散落在 9 个注入点各自 `search()` + 硬截断，同一句 query 重复嵌入 9 次，检索失败静默返回空串；Agent 无法读文件、无法记住上次会话，一个长工具结果会永久占住上下文；「写出来像不像人写的」看不见、改不动。

本版把这些收成一条可观测的链：统一 RAG 管线 + 注入溯源遥测、Agent 文件工具与落盘、会话按项目持久化、Obsidian 属性/标签/看板零维护联动。

## 主要变化

### 1. 统一 RAG 检索管线（`engine/rag/` + `shared/rag/`）

- 9 个知识注入点收敛为一条管线：**查询计划 → 并行检索 → 合并去重 → 邻块扩展 → 阈值 → MMR → 预算打包 → citation**。
- 四个纯函数模块：`query-plan`（场景目标/上一场结尾/情绪弧/章纲/正文/出场人物拆成带权重多查询）、`neighbors`（同书同维度 position ±1 拼回完整场景）、`diversity`（2-gram MMR，避免近重复占满预算）、`budget-pack`（按性价比装预算，最高分必保、尾条可截断）。
- 向量库新增查询向量 LRU 缓存（模型指纹 + query 为键，上限 100）与 `getNeighbors()`（读内存 samples，零 I/O）。
- 失败不再静默：返回 `{hits, telemetry, error}`，遥测（查询/命中/去重/邻块/丢弃/缓存）累计进 `KnowledgeInjector.lastInjectionMeta.retrieval`，再并入 `prompt-ledger`——执行时间线可回答「这次生成检索了什么、丢了什么」。

### 2. Agent 会话运行时（dsh 吸收）

| 能力 | 说明 |
|---|---|
| `read_file` / `search_vault` | 按行分页读取（200 行/8192 字符，offset 续读）、关键词检索 `path:行号:摘要`；路径守卫拒绝绝对路径/盘符/`..`/隐藏目录（`.sessions/` 白名单除外） |
| 大结果落盘（spill） | 超过 6000 字符的结果原文写 `.sessions/spill/agent/<项目>/`，日志只留定位符 + 头尾摘要，模型用 `read_file` 无损取回；7 天清理；写盘失败保留原文 |
| `@` 文件引用 | 输入框改 textarea（Enter 发送 / Shift+Enter 换行 / 输入法不误发），`@` 弹库内路径候选，支持 `@"带 空格.md"`；只注入路径清单不塞正文 |
| 引用消息 | 消息悬停「❝ 引用」→ 引用条 → 发送时以 `> 原话` 前置 |
| 时间上下文 | 每回合按分钟去重注入「当前时间（周X）」 |
| 会话持久化 | `.sessions/agent/<项目>.jsonl` 节流追加快照，重开自动恢复历史，头部显示会话标题，新增「🆕 新会话」 |
| token 计量 | 投影字符 ÷1.5 估算上下文 token，按当前模型 `maxContext` 算窗口占用，遥测显示「上下文 / 窗口 / 落盘」 |

### 3. Obsidian 原生能力接入

- **右侧「项目速览」面板**：跟随活动笔记，三段可折叠——本文件属性（按模板内联编辑）、标签 chips（`nw/*` 高亮、点击复制检索式）、快捷动作（按文件类型直达工作台/协同/结算/看板）。
- **双标签并存**：插件标签保留原名并追加层级标签（`nw/正文`、`nw/实体/*`、`nw/设定/*`、`nw/步骤/*`），覆盖 26 处写入点；存量用命令「🏷️ 补齐分层标签（先预览）」迁移，只加不删。
- **Bases 看板**：命令「📊 生成/刷新项目看板」在 `<项目>/.看板/` 生成章节进度/人物状态/物品归属/地点与势力四个原生看板，数据源就是结算回写的 frontmatter，零维护。
- **属性模板与补齐**：`shared/frontmatter-schema.ts`（10 类文件 × 属性/必填/候选值）作为面板渲染与看板列的单一来源；命令「🧩 补齐笔记属性（先预览）」只补空值不覆盖。

### 4. 记忆与反 AI 增量

- 长篇记忆去重 + 相关度排序（`shared/memory-rank.ts`）：同名/近重复事实合并，再按「2-gram 相关度 + 新近度」排序，协同写作把当前章纲/前情提要作为 query。
- 注入影响溯源账本（`shared/injection-ledger.ts`）：正文模板 31 个注入段登记影响矩阵（事实记忆/风格指引/流程约束），指纹预算可配置（`fingerprintInjectionBudget`），截断/丢层显式标红。
- 结算回写加固：人物 `修为等级/当前位置` 白名单补齐、四类实体字段守卫、重复结算幂等、归属字段自动 wiki-link（Obsidian 图谱零维护）、物品「当前状态」。
- 数据级反 AI：章纲「开头承接/章末钩子」字段、伏笔「回收≥1 + 埋设≥1」自动核对、角色按章行为摘要合并进出场记录。
- 反 AI 痕迹 v3：吸收 251 章实战规则的标点硬上限/排比禁令/描写配额。

## 升级说明

- 从 v4.20.0 直接升级，无数据迁移。首次打开 Agent 工作台会按项目创建 `.sessions/agent/<项目>.jsonl`（会话存档）与 `.sessions/spill/agent/<项目>/`（大结果存档），均在隐藏目录，不参与标签/Bases/搜索；spill 存档 7 天自动清理，「🆕 新会话」清空当前项目会话档。
- 知识注入行为变化：检索从「每点独立查一次」变为「多查询 + 邻块 + MMR」，同样强度下注入内容更完整；若需回退观察，把知识库注入强度设为 0 即可整体关闭。
- 存量项目建议各执行一次「🏷️ 补齐分层标签（先预览）」与「🧩 补齐笔记属性（先预览）」，Bases 看板才有完整列。

## 已知边界

- `buildKbStyleInjection` 保留 style/original 双维度独立检索（配额不同），未并入统一管线，仍复用查询向量缓存。
- token/窗口占用为字符估算（÷1.5），无独立 tokenizer；用于量级判断，不用于硬切预算。
- 会话恢复只回填用户/助手消息，工具行不重放；工具结果需要时由模型 `read_file` 读 spill 存档。
- 短篇/剧本的 AI 生成仍共用长篇 11 步 runner（三模式流程页与单元工作台已就位，执行层收口列入后续版本）。
