# v4.81.0 — 社区目录审核阻断项清零

发布日期：2026-11-09

## 为什么发这一版

4.80.0 在 Obsidian 社区目录账号审核中仍为 **Failed**，因此没有进入官方
`community-plugins.json`，应用内市场搜不到。审核报告里的四类 Error 在本地
lint/门禁中都没有被复现——本地规则与官方审核规则不是同一套。本版做三件事：

1. 清零审核报告中的四类 Error；
2. 把官方审核规则接进 `npm run lint`，防止再次「本地全绿、审核失败」；
3. 把最低支持版本从 1.4.0 提到 1.4.4，使 API 声明真实。

## 主要变化

### 1. API 兼容：1.4.4 下限与 leaf 前台化（审核 `no-unsupported-api`）

- `manifest.minAppVersion` 1.4.0 → **1.4.4**；`versions.json` 新增 `4.81.0 → 1.4.4`。
  依据：`FileManager.processFrontMatter` 自 1.4.4 起可用（唯一直接调用点在
  `shared/file-system-port.ts`）。
- `Workspace.revealLeaf` 实际为 **1.7.2** API。新增
  `shared/workspace-reveal.ts::revealLeafCompat`：先按需 `leftSplit/rightSplit.expand()`，
  再 `setActiveLeaf(leaf, { focus })`（0.16.3 起可用）。15 处调用全部迁移。
- 1.6+ 多窗口 API 补运行时守卫：
  - `ui/draggable-panel.ts` 的 `onWindowMigrated` 用 `typeof` 判断；
  - `el.win` 统一改 `shared/dom-window.ts::resolveNodeWindow`（回退 `doc.defaultView` / `window`）；
  - `ui/story-linkage-modal.ts`、`ui/components/categorization-review-panel.ts` 同步。

### 2. HTML 注入清零（审核 `no-unsanitized/property|method`）

- 新增 `ui/rendering/safe-html.ts`：`setSanitizedHtml` / `appendSanitizedHtml`，
  内部只走 `sanitizeHTMLToDom` + `appendChild`，不再直接摸 `innerHTML`。
- 50 处 `innerHTML = / +=` 赋值全部迁移（另有 8 处清空改 `empty()`）：
  图表面板、知识库详情、智能图表、空状态、写作宠物、拖拽面板、实体管理、
  分类审核、批量导入、章节选择器等。
- `ui/polish-editor.ts` 的实体标记改为 DOM 构建
  （`buildEntityMarkedFragment`：TextNode + `dataset` + `contentEditable=false`），
  因为 `sanitizeHTMLToDom` 会剥离 `contenteditable`。实体颜色改用
  `--nw-entity-color/--nw-entity-bg` CSS 变量，不再拼内联样式。
- 顺带修 popout 粘贴：选区与文本节点改用编辑器所属窗口/document。

### 3. Modal 渲染宿主（审核 `no-plugin-as-component`）

- `ContinueChaptersModal`、`UnifiedEntityManagerModal` 各自持有
  `private renderHost = new Component()`，`onOpen → load()`、`onClose → unload()`；
  `MarkdownRenderer.render` 不再把 `this.plugin` 当组件传入。

### 4. 残余静态样式（审核 `no-static-styles-assignment`）

- `FingerprintIntensityModal` 预览区块的 `attr: { style }` 与
  `setAttribute('style', ...)` 迁入 `.nw-intensity-preview*` 类；
  `updatePreview` 改为复用 `fillPreview`，不再手工替换节点。

### 5. 门禁与文档（防止回流）

- `eslint.config.mjs` 启用 `projectService: true`，以 **error** 运行：
  `obsidianmd/no-unsupported-api`（按 manifest 读取 1.4.4）、`no-plugin-as-component`、
  `no-static-styles-assignment`、`no-forbidden-elements`、`no-unsanitized/property|method`；
  `@microsoft/sdl/no-inner-html` 保持 warn（与官方审核一致）。
- 新增 `tests/unit/architecture/official-review-rules.test.ts`（配置不得降级 +
  源码不得回流）、`workspace-reveal` / `safe-html` / `modal-render-host` 单测。
- `check:obsidian-api`：下限文案改 1.4.4，补 `revealLeaf/ensureSideLeaf/getFileByPath`
  检测，并修正文档里的规则名（`no-forbidden-elements`，不是 `no-forbidden-style-element`）。
- `docs/handbook/06-gates-and-release.md` 新增 §3.4（API/HTML/Modal 审核约束）；
  README/PLAN/真相源表同步。

## 影响与迁移

- 最低支持版本变为 Obsidian **1.4.4**；1.4.0–1.4.3 不再声明兼容。
- 用户可见行为不变；数据与配置无迁移。
- 若自定义 CSS 覆盖过润色编辑器实体颜色，可改用 `--nw-entity-color` 变量。
