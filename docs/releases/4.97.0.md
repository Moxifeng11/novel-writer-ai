# v4.97.0 — 双语界面 + 文面体检 + 视觉重构收口

发布日期：2026-11-20 · tag：`4.97.0` · 上一版本 v4.96.0（含 4.96.1 未单独发版的内容）

## 为什么发这一版

上一版（4.96.0）解决的是「链路断链」——数据进了表单却进不了 prompt。这一版解决的是**「看得懂、点得动、写得完」**：

- 界面只有中文，英文用户无法使用 → 全量双语（命令面板命令名与分组名 + 设置页全部分区 + 写作主流程 + 知识库 + 全部弹窗）；
- 发布前只能靠肉眼找错别字和标点 → 内置 7 条规则的**文面体检**，可定位、可跳转；
- 视觉层大面积依赖工具类与内联样式，暗色主题下按钮渲染成白底黑字 → **25 个切片（Slice A–Y）语义化**，用 before/after 像素快照逐场景校正；
- 真实点击验收（不是脚本调用）发现 14 条界面缺陷，逐条修复并复验。

## 视觉重构收口（Slice A–Y，25 个切片）

- 25 个切片全部完成，每个切片都用 **before/after 像素快照 + 结构/尺寸/样式探针**验收；绝大多数场景 **0 像素差**，差异项均在模块文档里逐条解释（如按设计意图恢复被覆盖的按钮配色）。
- 工具类 `nw-u-*` 只剩 46 个类 / 137 次引用（Slice Y 之后无存量大户），`check:utility` 拦截新增；内联样式按切片清零，`check:inline-styles` 为 474（静态 410 / 动态 64）。
- `styles.css` 805,893 字节 / 4,340 个唯一类，全部走 `styles-src/` 拼接，`transition: all` 由测试硬拦。

## 交互与稳定性（审计 C 清单 + 真实点击验收）

- **防重复扣费**：`withButtonBusy` 接入 AI 生成按钮（plan-book / ai-builder / 世界观 / 协同控制面板），双击不再触发两次付费调用。
- **防丢改动**：`ModalDirtyGuard` 覆盖 8 个弹窗（计划书 / 文笔风格 / 同人设定 / 黄金开篇 / 文笔蒸馏 / 模板编辑 / 书籍编辑 / 题材编辑），Esc 或点外关闭前二次确认。
- **撤销栈共享化**：`shared/edit-history.ts` 从协同写作抽到共享层，单元写作台获得撤销/重做（Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z，800ms 节流 + 失焦强制落点）。
- **真实点击验收 F-01–F-14 全部修复**：含写作台横向溢出、窄高窗口状态栏被裁、英文阶段名、设置页开关压字与四边虚线、体检静默 401、供应商侧栏名称截断等；每条都有复验脚本与截图。
- **启动噪音清理**：按设计不注入的分析器不再报警、缺失「.sessions」目录降为 debug；干净启动仅剩「API key 无效」这一条真实告警。
- **破坏性下线**：旧正文写入链（4 条 internalOnly 命令 + 3 个隐藏弹窗）与协同写作悬浮面板已退役（详见 4.96.1 条目与迁移说明）。

## 升级说明

- **破坏性**：旧正文写入链命令（`WRITE_CHAPTER` / `WRITE_CHAPTER_AUTO` / `BATCH_CHAPTERS` / `AUTO_WRITER`）与协同写作悬浮面板已删除，正文统一走协同写作工作台 / 完整写作工作台 / 「批量生成章节」。
- **无数据迁移**：知识库索引、事实库、指纹库、台账格式均未变；4.96.1 的索引写入修复会自动生效。
- **语言切换**：设置 → 外观 → 语言，切换后界面即时刷新；命令面板命令名需重载插件（Obsidian 命令名在注册时固定），重载后为新语言。
- 回滚建议：回退到 v4.96.0 时，已删除命令的快捷键会失效（这些命令本就不在命令面板）。
