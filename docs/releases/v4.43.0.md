# v4.43.0 — 协同引擎切片第六批与 Notice 第十二批

发布日期：2026-11-06

## 为什么发这一版

v4.42.0 完成了协同**视图**切片，但协同**引擎**还剩最后一块强耦合：`buildDirectionalPrompt` 直读 `soulData / chapterBrief / snapshot / promptBuilder`。同时 Notice 存量按批次继续收敛。本版延续 ZCode + Trae 双线协作：引擎切片由 ZCode 完成，Notice 第十二批由 Trae 完成。

## 主要变化

### 1. 协同引擎切片第六批（co-writer-engine 3,299 → 3,254）

- `buildDirectionalPrompt` 参数化后抽到 `engine/co-writer/directional-prompt.ts`：
  - 显式入参：`soulInjection`（引擎由 soulData 计算）、`plotTarget`（plotNodes + 章节场景兜底）、`briefParts`、`writingRules`、`promptBuilder`、`inputBudget`；
  - 有 PromptBuilder → 10 个参数按序透传 `buildSuggestionPrompt`；
  - 无 PromptBuilder → 兜底模板逐字保留（第三人称限知规则、活人感规则、bodyFormat 契约、已写内容末 800 字、<10 字按本章开头处理）。
- 引擎保留同名薄委托；顺带清理引擎侧未用导入（`deriveBodyFormat/describeBodyFormat` 随切片迁出）。
- 新增 `tests/unit/engine/co-writer/directional-prompt.test.ts` 4 条（透传顺序、格式契约跟随 writingRules、装配顺序与末 800 字窗口、cursorHint 与开头指令切换）。
- 类型插曲：测试初稿误用 `'continue'` 方向值（合法枚举为 action/emotion/dialogue/description/foreshadow/conflict/resolution/surprise），由 Trae 在批次自检中抓出后修正。
