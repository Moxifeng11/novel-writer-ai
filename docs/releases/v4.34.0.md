# v4.34.0 — 体积预算、CI 加固、覆盖率扩展与会话保留（P2 治理批）

发布日期：2026-11-05

## 为什么发这一版

审计 P2 清单里剩四件「不性感但会长胖」的事：主包体积没有预算、CI 引用浮动 tag 且发布无校验和、覆盖率门禁对 ui/domains 完全失明、三套会话落点没有保留策略。本版由四个实现子代理并行收口。

## 主要变化

### 1. 体积预算门禁（`check:bundle`）

- 新增 `scripts/check-bundle.mjs` + `.bundle-baseline.json`：main.js / styles.css 只降不升（LF 口径，与 CSS 基线交叉印证一致）；接入 preflight（构建后、check:release 前）。
- 基线：main.js 4,830,770 B（路线图 ≤5MB 目标内）、styles.css 475,563 B。本版因新增会话保留代码 +2,291B，按门禁纪律在 note 中记录原因后上调。
- 「故意超限必须失败」已验证（+1 字节 → exit 1）。

### 2. CI / Release 加固

- `uses:` 全部锚定完整 commit SHA（行尾注释保留版本号）：actions/checkout v4.4.0、actions/setup-node v4.4.0、actions/upload-artifact v4.6.2（SHA 经 git ls-remote + GitHub API 双重解析，锚定当前浮动 tag 实际指向的 commit，语义不变）。
- release.yml 新增「生成发布资产校验和」：SHA256SUMS.txt 覆盖全部发布资产（含 zip）并随 Release 上传；`check-release.mjs` 的资产解析器零改动、worker+versions 校验不受影响。

### 3. 覆盖率门禁扩展

- `ui/**`、`domains/**` 纳入覆盖率统计，建立 per-glob 棘轮：domains 84/82/70/70（实测 86.9/84.0/72.4/72.7）、ui 首期诚实基线 3/3/4/3（实测 ~6%，只升不降）。
- 全局阈值移除（并入 ui 后并集失真），engine/services/core/shared per-glob 原值保持。
- 关键语义发现（已写进配置注释）：include 的 glob 是子串匹配（`services/**` 连带 ui/services），threshold 的 per-glob 是精确匹配——`ui/services` 由 `ui/**` 阈值接管。
- 覆盖率口径文档（handbook 05）与 config 逐项对齐，清除长期不一致的旧数字。

### 4. 会话保留清理

- 新增 `shared/session-retention.ts`（可注入端口 + `pruneSessions`）：
  - 分析会话（插件目录 `.sessions/*.json`）与 Agent 会话（库根 `.sessions/agent/*.jsonl`）各保留最近 30 个（mtime 降序，缺失视为最旧）；
  - 当前活跃项目的 Agent 存档永不删（keep 豁免）；
  - 单条删除失败继续、list 失败跳过该目标；删除一律走注入 port。
- onload 尾部延迟执行一次（不阻塞启动、不在卸载窗口内）；保守 MVP：只按数量、无用户可见入口，为开关/命令预留。

## 验证

- 单测：**547 文件 / 5,965 用例** 全绿。
- `check:bundle`：故意 +1 字节失败验证通过；`preflight:release` 全绿（提交前执行）。
- `check:release` 对修改后 release.yml 的资产解析实测通过。
- mock AI E2E 12 条 + 性能冒烟（提交前执行）。
- lint：0 error，维持 1,875。

## 影响与迁移

- 破坏性变更：无。
- 配置/数据迁移：无需迁移；会话修剪按固定上限自动执行，超出部分不可恢复（保守 30 个 + 活跃豁免）。
- 回滚建议：回滚到 v4.33.0 后 check:bundle 不存在、覆盖率回到全局阈值、CI 回到浮动 tag。

## 未完成（明确记录）

- `check:bundle` 未进 CI（本批只进本地 preflight；CI 批次可随后加入）。
- ui 覆盖率首期基线极低（~6%），按棘轮只升不降推进；并行开发新增 ui 文件可能压低数值——应补测试而非降阈值。
- 会话修剪无用户可见入口；分析会话按文件级（而非「每书最新会话」）保留。
- 费用估算币种固定为元、fallback 模型不区分（沿用 v4.32.0 口径）。
