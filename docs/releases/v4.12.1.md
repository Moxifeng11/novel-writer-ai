# 小说工坊 AI v4.12.1

> 发布日期：2026-10-25 · 上一版本：[v4.12.0](v4.12.0.md)
> 主题：审计待确认项收口 / 场景节奏检索接入

本版是 v4.12.0 的补丁发布，不引入破坏性变更。重点是关闭 2026-10 审计 spec 中最后 5 条 `[待确认]`，并让知识库的 `rhythm` 维度真正进入场景生成。

---

## 一、改动

### 1. 场景节奏注入接入检索

`engine/knowledge-injector.ts#buildSceneRhythmInjection` 此前只输出硬编码节奏模式，`knowledgeVectorStore` 与 `bookIds` 仅用于早退，知识库的 `rhythm` 维度从未被消费。

现在：

- 保留原有硬编码节奏模式与节奏建议，作为无向量数据时的兜底。
- 新增 `dimensions: ['rhythm']` 检索，最多取 3 条，每条截断到 160 字，按查询文本检索参考书节奏样本。
- 无检索结果、无参考书或无查询文本时，输出与 4.12.0 一致。

### 2. 两项确定性守卫

- `ALL_FULL_STEPS` 下标契约：锁定 `index === 数组下标`、key 唯一、迁移映射目标合法，防止未来插入步骤导致导航错位。
- `QualityScoreEngine#fullCache` 生命周期：同上下文 1000 次评估只触发 1 次内核计算；上下文变化后重算；`cacheSize` 上界生效，缓存不随评估次数增长。

### 3. 审计与草案收口

- 审计 spec §5 五项全部给出结论/证据：worker 隔离、fullCache、qualityCache、rhythm 注入、步骤下标。
- `prompt-management-system` 判定为已落地（PromptManager + 版本 + A/B + 统计已接入 AIEngine）。
- `style-ui-unification` 判定为部分完成：设计令牌与 `!important` 治理已落地，但 CSS 体积与内联样式未达 2026-07 目标，转入持续治理。

## 三、升级说明

1. **无破坏性变更**：设置键名、项目目录与旧数据格式保持兼容。
2. **节奏片段只在有数据时出现**：参考书完成拆解并写入 `rhythm` 向量后，场景生成会多出「参考节奏片段」；没有向量数据时保持 v4.12.0 行为。
3. **发布包内容不变**：`main.js`、`manifest.json`、`styles.css` 与 `workers/`；手动安装时请把 3 个 Worker 放入 `workers/` 子目录。
4. **审计结论**：本版关闭 spec §5 的最后 5 项；`style-ui-unification` 的剩余 CSS 治理不属于本补丁范围。
