# v4.27.0 发布说明

> 2026-11-04 · 全流程阻塞修复、数据可靠性加固、设置双 UI 收敛

## 稳定性

- 步骤执行在模板解析前先进入 busy，快速双击不再并行两次 AI 调用。
- 协同保存/外部修改检测/切章冲刷加 10–35s 超时；同步盘锁定时不再永久等待。
- 批量生成每步 8 分钟看门狗；暂停 10 分钟无操作自动继续。
- Agent 危险审批/dsh 写入确认 10 分钟无响应默认拒绝；dsh 回合超时可配（默认 10 分钟）。
- 导出异常可见；章节读取并发 6 批并让出主线程。
- `openChapter` 代次守卫、项目选择器减少重渲、后台实体重检可取消、流式槽位感知 abort。

## 数据可靠性

- 6 处 frontmatter 直写改用 `ObsidianFrontmatter`（重复键自愈）。
- 协同持久化移除整章正文；`data.json` 不再被每次编辑全量重写正文。
- 指纹库项目级单例 + `flushAll`；卸载统一冲刷。
- 实体仓储 `save()`、`.project` 读改写加锁；拆解/知识库/批量导入补 `dispose()`。
- 用户可见 Markdown 改走 `writeVaultText` 进入 vault 索引。

## 交互与设置

- `ui/button-busy.ts` 统一按钮防连点，覆盖协同工具、场景/联想/扩写/改写、结算/节点推进。
- 知识库视图 `viewClosed` 在 onOpen 复位。
- 命令面板补 `WRITING_STATS`/`TOGGLE_PET`/`CHARACTER_RECOGNITION`，硬编码 ID 改常量，新增集合一致性测试。
- `MiniSettingsModal` 由 2755 行瘦身为薄壳，与设置页共用 `settings/section-factory.ts` 的 18 个分区。

## 测试

- 单测：**535 文件 / 5913 用例**。
- 新增生产环境模拟 E2E：mock AI 全旅程、按钮忙碌态、视图生命周期；真实 API 冒烟单独运行。

## 已知边界

- macOS/Linux/移动端与 Obsidian 1.4/1.5 实机冒烟仍需发布前人工执行（清单见手册 11）。
- Agent 审批超时是安全兜底，默认拒绝；需要长审批时请在 10 分钟内响应。
