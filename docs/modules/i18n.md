# 界面文案国际化（i18n）

> 状态：doing（第一期交付 2026-11-18）　｜　最后更新：2026-11-18　｜　Owner：dsh

## 1. 定位

- **用户视角**：设置页「🎨 外观设置 → 界面语言」三选一（跟随 Obsidian / 简体中文 / English）；
  切换后设置页的标题、搜索框、6 个分组、20 个二级页签、高级开关立刻变成目标语言。
- **代码入口**
  - 运行时核心：`i18n/index.ts`（`t()` / `translate()` / `setLocale()` / `applyLocaleSetting()` /
    `onLocaleChange()` / `resolveLocale()` / `detectHostLocale()` / `interpolate()` /
    `flattenMessages()` / `placeholdersOf()` / `getCatalog()` / `hasMessage()`）
  - 资源：`i18n/messages/zh-CN.ts`（源语言，`export type MessageTree`）、`i18n/messages/en-US.ts`
  - 设置项：`ui/settings/locale-setting.ts`（`renderLocaleSetting(container, plugin, onChanged)`）
  - 导航接线：`ui/settings/section-factory.ts`（`group()` / `tab()` 构造器把 `label` 做成 **getter**）、
    `ui/settings-tab.ts`（标题/搜索占位/搜索空态/高级开关/未知页签）
  - 启动生效：`engine/engine-registry.ts` Phase 5 —— `await settingsService.loadSettings()` 之后
    紧跟 `applyLocaleSetting(plugin.settings.language)`（启动路径不经过 `plugin.loadSettings()`）
  - 门禁：`scripts/check-i18n.mjs`（`npm run check:i18n`，已进 `preflight`）
- **数据/配置**：`NovelWriterSettings.language?: 'auto' | 'zh-CN' | 'en-US'`（默认 `'auto'`，
  见 `core/settings-service.ts` 的 `getDefaultSettings()`）；棘轮基线 `.i18n-baseline.json`。

## 2. 现状（事实，不写愿望）

- **语言解析**：`resolveLocale(setting)` —— `auto` 时读 `window.localStorage.getItem('language')`
  （Obsidian 自己就是这么记的），`zh*` → `zh-CN`、`en*` → `en-US`、读不到或抛错 → `zh-CN`。
- **翻译语义**：`translate(locale, key, params)` 查找顺序「目标语言 → zh-CN → 键名本身」；
  命中不到时 `console.warn('[i18n] 缺少文案键：' + key)` **每个键只警告一次**，界面不炸。
  插值走 `/{placeholders}/g`（源码为 `\{(\w+)\}`，未提供参数的占位符原样保留）。
- **资源规模**：zh-CN 与 en-US 各 **42 条**（`common` 5 / `settings.group` 6 / `settings.tab` 20 /
  `settings.shell` 6 / `settings.appearance.language` 5），占位符逐键一致。
- **已迁移面（第一期）**：设置页导航（6 分组 + 20 页签）+ 设置页外壳 6 条。共 4 个文件
  `import { t } from '@/i18n'`：`ui/settings-tab.ts`、`ui/settings/section-factory.ts`、
  `ui/settings/locale-setting.ts`、`engine/engine-registry.ts`（后者只 import `applyLocaleSetting`）。
- **未迁移面**：`ui/` 下仍有 **269 个文件 / 11892 条**含 CJK 的字符串字面量（棘轮基线就是这个数），
  包括设置分区正文（`ui/appearance-settings.ts` 等）、命令面板、写作主流程、全部 `Notice` 文案。
  `i18n/` 本身与 `engine/`、`services/` 的中文不参与棘轮（`check-i18n` 只扫 `ui/**`）。
- **切换语义**：语言下拉的 `onChange` = 写 `plugin.settings.language` → `applyLocaleSetting()`
  → `await plugin.saveSettings()` → `onChanged()`；设置页传的是 `() => this.reopen()`（整页重开），
  因为 `t()` 是**渲染时求值**，不重开不会换文案。

## 4. 关键决策

- **不依赖 Obsidian 的 locale API**：桌面/移动/测试环境可用性不一致。只读
  `localStorage.language`，读不到就当 `zh-CN`——宁可「跟随不到就中文」，也不要启动即空白。
- **缺失键不抛错**：返回键名并在控制台警告一次。理由：一期只有 42 条，任何一处漏配键都不该
  把整页炸成白屏；键名本身在界面上可见，也自带定位信息。
- **`label` 做成 getter 而不是函数或常量**：`SETTINGS_TAB_DEFINITIONS` 被 6 处消费
  （`settings-tab.ts` / `mini-settings-modal.ts` / `settings-menu.ts` / `settings-search.ts` /
  `main.ts` / 单测），全都要 `tab.label: string`。getter 保持类型不变，同时每次读都取当前语言；
  若算成字符串，切语言后必须重建整个常量表（消费方拿到的仍是旧串）。
- **生效点放在 `SettingsService.loadSettings()` 之后**（`engine/engine-registry.ts` Phase 5）：
  那是设置加载的唯一收敛点，启动路径不走 `plugin.loadSettings()`，放别处会读到默认值。
- **切换语言 = 整页重开**（`reopen()`）：`t()` 在渲染时求值，局部 `refresh()` 只会重绘当前分区，
  分组栏/页签/标题仍是旧语言。代价是一次重绘，收益是不会出现「半中半英」的中间态。
- **棘轮而非一刀切禁止**：存量 11892 条中文不可能一次清零。基线按**文件粒度**记录，
  规则是「per-file 只许降不许升」+ 新文件默认允许 0 条；改文案导致条目下降要
  `--update-baseline` 收紧，否则棘轮会松。无基线文件时按当前状态放行并提示（首次接入友好）。
- **门禁用 `ts.transpileModule` 求值资源**：`i18n/messages/*.ts` 是 TS ESM，node 直接 `import`
  需要实验开关；降级成 CommonJS 再 `new Function` 求值，跨 node 版本稳定。
- **`check-i18n` 只扫 `ui/**`**：引擎/服务层的中文多是日志、提示词、数据字段，不是界面文案，
  一刀切会逼人给日志加 `t()`（那才是错）。界面文案的真正边界就是 `ui/`。

## 8. 交接备注

- **硬约束**：新增界面文案必须同时写进 `i18n/messages/zh-CN.ts` 与 `en-US.ts`，键名与占位符
  逐字一致（`check:i18n` 会拦）；代码里用 `t('点分键')`，不要拼字符串键、不要在 `ui/` 新增裸中文。
- **改中文文案 = 改基线**：删/改 `ui/` 里的中文会让 per-file 条目下降，必须
  `node scripts/check-i18n.mjs --update-baseline --note="…"` 收紧，否则下次有人加回中文也不会被拦。
- **`check-i18n` 的 note 只从 `--note` 参数取**（与 `check:css` 同类坑，positional 参数会被忽略）；
  基线文件里 `note` 字段手工补也行，但别让 `--update-baseline` 再覆盖成默认文案。
- **语言切换后必须重开或整段重绘**：`t()` 是渲染时求值，缓存过的 DOM（`panelCache`、
  常量表里算好的字符串）不会自己变。设置页的做法是 `reopen()`，其他入口照此办理。
- **别在模块顶层调用 `t()`**：模块级常量在 import 时就求值，那时 `applyLocaleSetting()` 可能还没跑
  （`engine-registry` Phase 5 才生效），会永久定格成中文。要常量就用 getter / 函数。
