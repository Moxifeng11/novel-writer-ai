# 写作工作台首页（workbench-home）

> 状态：**Brief 待确认**（2026-11-16 盘点完成，未改代码）
> 模块入口：`ui/home-view.ts`（创作主页，Ribbon 主入口）、`ui/full-writer/project-selector-controller.ts`（工作台首页「项目与章节」）、`ui/full-writer-view.ts`（工作台宿主）
> 目标（INDEX）：信息层级、空态引导、快捷入口可发现性

## 1. 现状盘点（2026-11-16）

### 1.0 范围澄清

INDEX 旧登记的代码入口是 `ui/full-writer-view.ts`，但实际有两个「首页」：

1. **创作主页**（`ui/home-view.ts`，235 行）：Ribbon 图标唯一入口，结构 = hero（8 个次级按钮）→ 开始创作（3 张模式卡）→ 下一步（1 张建议卡）→ 最近项目（≤6 行）。
2. **工作台首页**（`ui/full-writer/project-selector-controller.ts`，907 行；宿主 `full-writer-view.ts` 2515 行）：模式卡进入后的「📋 项目与章节」页，结构 = 左侧创作分类导航 + 项目卡片网格，右侧「项目概览 + 流程摘要 + 快捷工具」常驻面板。

### 1.1 实机结构（本 vault，0 项目）

**创作主页**：sections = 开始创作 / 下一步 / 最近项目；hero 按钮 8 个（任务中心、项目体检、资产总览、规划画布、设定实体图、用量账本、备份中心、首启引导）；模式卡 3 张（新建长篇小说 / 新建短篇小说 / 新建短剧剧本）；空态「下一步」卡给出 ✨ 导入示例项目 + 新建长篇。

**工作台首页**：分类导航 📖长篇小说0 / 📄短篇小说0 / 🎬剧本0；空态 hero（创建第一篇长篇小说 + 两个 CTA，文案完整）；右栏快捷按钮 17+ 个，**前 15 个里含 3 个「（旧）」工具**（整章生成（旧）、自动写作器（旧）、批量写正文（旧））。

### 1.2 关键代码事实

- `home-view.ts renderRecent`：排序是「activeProject 优先 + 显示名 localeCompare」，**没有任何 lastOpened 记录**——「最近项目」实际是「按名称排序的前 6 个」。
- `home-view.ts renderNextStep`：有 key 有项目时永远输出「继续《项目》→ 打开创作流程」，目标取 activeProject 否则 `projects[0]`（字母序第一个），不读项目实际状态（向导是否完成、有无未写章节、任务是否在跑）。
- `home-view.ts renderModes`：短篇/剧本有项目时按钮文案是「进入短篇小说」，点击执行 `CommandIds.CREATE_SHORT` → `command-ui-executor.ts:261` 打开 **PreResearchModal（创建/定位表单）**。**现有短篇/剧本项目没有任何主页入口**。
- `project-selector-controller.ts renderRightPanel`：右栏 = 项目概览 + 流程摘要 + `renderQuickToolsPanel`（`getToolCatalogForMode` 的 groups）+ 被过滤动作提示；工具清单含「（旧）」工具，与现行工具同权重平铺。
- 项目卡动作常驻 7 个：🧙向导（或 📚前期调研）/ ✍️写作 / ✍️句级协同 / 全部章节 / ✏️重命名 / 🗑️删除。
- 空态引导（两处）现状良好：无项目时 hero + 分类文案 + 推荐 Agent 路径；无 key 时「下一步」直指去配置 API。这部分**不是**问题。

## 3. Brief（待确认）

### 3.1 目标

把两个首页从「平铺入口」升级为「以项目为中心」：进主页先看到「接着写什么」，工具按层级收纳。

### 3.2 范围（确认后实施）

1. **最近项目真排序（H-01）**：记录 `projectLastOpened`（settings 持久化，打开项目/章节时写入）；主页按此排序，无记录的排后面。
2. **「下一步」真实化（H-03）**：三态判定——向导未完成 → 继续向导；有未写章节 → 继续写第 N 章；有任务在跑 → 任务中心（带进度）。目标项目取 lastOpened 最新。
3. **短篇/剧本入口（H-04）**：模式卡有项目时改为「进入工作台 · 该分类」并自动选中该分类下的最近项目；无项目时保持新建表单。
4. **hero 分组（H-02）**：保留「任务中心（带在跑数）+ 项目体检」两个常驻，其余 6 个收进「更多工具 ⌄」下拉。
5. **右栏主操作卡（W-02）**：选中项目时顶部先渲染「继续写第 N 章 / 打开创作流程」主卡，快捷工具分组保持但收窄视觉权重。
6. **旧版工具收纳（W-01）**：「（旧）」工具折进右栏底部「旧版工具」可展开分组，默认收起。
7. **项目卡动作收纳（W-03）**：保留 向导/前期调研 + 写作 + 句级协同；重命名、删除、全部章节、封面 收进卡片右上「⋯」菜单。
8. **最近项目行增强（H-05）**：显示进度（已完稿 x/y）+「继续写作」直达下一章。
9. **INDEX 修正**：本模块代码入口补 `ui/home-view.ts`。

### 3.5 风险

- `projectLastOpened` 写入点分散（打开章节/协同/流程三处），漏写会让排序退化回旧貌——用统一入口函数兜底。
- 「下一步」三态需要读 wizard 状态与章节扫描，注意复用已有缓存避免主页变慢。
- 项目卡「⋯」菜单在触屏/移动端的可用性（Obsidian mobile）——菜单用 Menu 组件自带适配。
